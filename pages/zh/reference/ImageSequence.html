ImageSequence 模块

ImageSequence 模块遍历多帧图像(GIF、TIFF、ICO……)的每一帧。Pillow 的 Python 生成器被 AllFrames 具象化为 AHK 数组:一次调用即返回全部帧,而非惰性迭代器。

AllFrames static

Pillow.ImageSequence.AllFrames(im, fn := unset)

返回一个 AHK 数组,im 的每一帧对应一个 Image。im 可以是单个 Pillow.Image,也可以是图像数组。每个元素都是独立副本(frame.Copy()),修改返回帧不会影响原图。

im
要遍历的 Pillow.Image,或图像数组。
fn
可选的可调用对象;设置后每一帧经 fn.Call(frame) 映射并返回映射数组。

返回:帧副本数组(提供 fn 时为映射后的数组)。

遍历动画不会打乱原图的 seek 位置:结束后会恢复帧索引(finally { image.Seek(current) })。当格式提供时(如 GIF),每个复制帧携带逐帧 Info,例如 duration、loop、background 与 comment。

all_frames static

Pillow.ImageSequence.all_frames(im, fn := unset)

AllFrames 的 snake_case 别名,对应 Pillow 的 ImageSequence.all_frames 名称。

Iterator class

Pillow.ImageSequence.Iterator(image)

针对单个图像的有状态帧迭代器。与 AllFrames 不同,它直接对图像执行 seek 并返回同一个 Image 对象(不复制),因此遍历时会推进原图的帧位置。

另暴露 __Item[index] 取值器(委托给 GetFrame)以及静态辅助 IsEndError(err),用于识别 Pillow 的 attempt to seek outside sequence / no more images in file 消息。

__New constructor

Pillow.ImageSequence.Iterator.__New(image)

创建 image 的迭代器(必须是 Pillow.Image),保存该图像并把循环位置重置为 0。

参数不是 Pillow.Image 时抛 im must have seek method。

__Enum method

Pillow.ImageSequence.Iterator.__Enum(varCount)

AHK for 循环协议。支持一个循环变量(帧)或两个(索引与帧);其他数量会抛错。

GetFrame method

Pillow.ImageSequence.Iterator.GetFrame(index)

把底层图像 seek 到 index 并返回。index 必须是整数;越过末尾会抛 end of sequence。

SeekForIteration method

Pillow.ImageSequence.Iterator.SeekForIteration(index)

seek 到 index 并返回 true,到达序列末尾时返回 false。由 __Enum 内部使用。

示例

把动画 GIF 的每一帧分别保存为 PNG:

im := Pillow.Image.Open("animation.gif")
frames := Pillow.ImageSequence.AllFrames(im)   ;  array of independent copies
for i, frame in frames
    frame.Save("frame_" i ".png")
for frame in frames
    frame.Close()
im.Close()
