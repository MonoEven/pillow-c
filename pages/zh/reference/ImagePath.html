ImagePath 模块

ImagePath 模块暴露 Path 类:一组 [x, y] 坐标(以浮点存储),描述供 ImageDraw 使用的多边形轮廓。得到的坐标点经 path.Tolist() 供给 ImageDraw.Polygon/Line 绘图。它在 Pillow. 命名空间下与 Pillow 11.3.0 兼容;在本运行时中,0 是 Python None 的 AHK 对应物,unset 表示“未传参”哨兵。

对齐:Path 只保存线段,因此 Compact() 是返回 0(None 对应物)的就地空操作;可调用的 Map() 返回 0 且不改动对象;Pillow 的 C 层 ImagingTransformHandler 形态是记录在案的边界。

Path class

Pillow.ImagePath.Path(xy)

由扁平坐标序列 [x0, y0, x1, y1, …] 或 [x, y] 对的数组构造路径。坐标以浮点存储。非对象的 xy、畸形坐标对、非数值坐标或长度为奇数的扁平序列都会报错。

xy
扁平坐标序列或 [x, y] 对的数组。

返回:Path 对象。

Tolist

path.Tolist(flat := true)

将路径作为 [x, y] 坐标对的数组返回。

flat
为与 Pillow 签名对齐而接受;当前被忽略——本门面始终返回坐标对数组形式。

返回:[x, y] 对的数组。

GetBbox

path.GetBbox()

以浮点返回路径点的包围盒。

返回:[minx, miny, maxx, maxy];空路径返回 [0.0, 0.0, 0.0, 0.0]。

Compact

path.Compact(distance)

就地压缩路径。由于本路径对象只保存线段(Pillow 的 core.path 只压缩曲线段),此为就地空操作。

distance
被忽略(为签名对齐而接受)。

返回:0——已转换的段数(AHK 的 None 对应物)。

Transform

path.Transform(matrix)

对每个点就地应用 6 值仿射变换 [a, b, c, d, e, f]:x' = a·x + b·y + c,y' = d·x + e·y + f。

matrix
6 值数值序列 [a, b, c, d, e, f]。

返回:无(就地修改)。

对齐:长度非 6 时抛 Pillow 原样的 transform() argument 1 must be sequence of length 6, not N;非数值元素抛数值错误。

Map

path.Map(fn)

将可调用对象映射到路径。在本门面中,可调用形式返回 0 且不改动路径。

fn
可调用对象(接受;本门面不调用)。

返回:0(AHK 的 None 对应物)。

对齐:Pillow 的可调用 path.map(fn) 返回 None 且不改动对象;C 层 ImagingTransformHandler 形态保留为记录在案的边界。

示例

由坐标对构造路径,读取包围盒与坐标点,再对其做变换:

p := Pillow.ImagePath.Path([[10.0, 20.0], [30.0, 40.0], [50.0, 10.0]])
bbox := p.GetBbox()                 ;  [10.0, 10.0, 50.0, 40.0]
pts  := p.Tolist()                  ;  [[10.0, 20.0], [30.0, 40.0], [50.0, 10.0]]
p.Transform([1, 0, 5, 0, 1, 0])     ;  shift +5 in x, in place
pts  := p.Tolist()                  ;  [[15.0, 20.0], [35.0, 40.0], [55.0, 10.0]]
p.Compact(2.0)                      ;  0 — lines only (the None analogue)
p.Map(Func("Noop"))                 ;  0 — no mutation
