ImageMath 模块

ImageMath 模块求值图像表达式:一套类 Python 的中缀小语言被编译到原生 RPN 引擎,外加 Pillow 的 lambda_eval 辅助函数与 imagemath_* 单图像操作。由于 AHK 标识符不区分大小写,Pillow 的 eval/unsafe_eval/lambda_eval 与 imagemath_* 名称都映射到下文列出的 PascalCase 与 snake_case 成员。

variables 是 Pillow 关键字参数的 AHK 对应物:一个 name → Image 或 Number 的 Map。

求值与 lambda

Eval static

Pillow.ImageMath.Eval(expression, variables := unset)

编译并求值一个表达式字符串(Pillow 的 ImageMath.eval,与 unsafe_eval 相同)。表达式引用图像时返回新的 Image;纯标量表达式返回 Number(Integer 或 Float)。

expression
字符串表达式;非字符串抛 Pillow.ImageMath expects a string expression。
variables
name → Image(L/I/F 模式)或 Number 的 Map。其他容器抛 Pillow.ImageMath variables must be a Map of name to Image or Number;未知名称抛 'name' not allowed;非 L/I/F 图像抛 unsupported mode: <模式>。

返回:Image;纯标量表达式返回 Integer/Float。

对齐:尺寸不符抛 images do not match;位运算遇到浮点操作数抛 bad operand type for '<op>'。

UnsafeEval static

Pillow.ImageMath.UnsafeEval(expression, variables := unset)

Eval 的直接别名(Pillow 的 unsafe_eval,后者即 eval 背后的引擎)。

LambdaEval static

Pillow.ImageMath.LambdaEval(expression, options := unset, kwargs*)

Pillow 的 lambda_eval:用 ops 字典(int/float/equal/notequal/min/max/convert,加上 AHK 适配的 add/sub/mul/div/mod/neg)合并 options 与关键字值后调用 expression;Image 值变为 Operand。Operand 结果经 Eval 求值;其他结果原样返回。

expression
可调用对象(Func/闭包);否则抛 Pillow.ImageMath.lambda_eval expects a callable expression。以单个 Map(合并后的 ops + 关键字)作为参数调用。
options
可选的额外名称注入 Map;非 Map 抛 Pillow.ImageMath.lambda_eval options must be a Map。
kwargs
扁平的 name, value, … 对(Pillow 的 **kw)。Image 值被包装为 Operand(name, Map(name, value))。

返回:求值后的 Image/Number,或可调用对象的原始返回值。

表达式语法

Eval 编译器是对类 Python 中缀语言的调车场解析器。普通括号为分组——(x + 1) * 2——紧跟 ( 的函数名是调用。

运算符中文
+ - * / %位与/或/异或/移位(仅整数)。
== != < <= > >=一元取负 / 按位取反。
函数中文
abs(x) float(x) int(x)逐元素取最小 / 最大。
convert(x, 'mode')转换到 'L'、'I' 或 'F'(单引号);其他模式抛 unsupported mode: <模式>。

差异:Pillow 的 _Operand 提供 **(幂);本 AHK 构建在 Tokenize 中没有 ** 词元、Compile 中也没有幂操作码,因此表达式与 Operand 方法都不提供 **。

单图像操作

Pillow 的模块级 imagemath_* 辅助函数在此为静态成员。每个都构造 Operand 表达式(不求值),参数为 Operand 或 Number(自动包装)。

ImagemathInt / ImagemathFloat / ImagemathEqual / ImagemathNotequal / ImagemathMin / ImagemathMax / ImagemathConvert static

Pillow.ImageMath.ImagemathInt(self)            ;  alias imagemath_int(self)
Pillow.ImageMath.ImagemathFloat(self)          ;  alias imagemath_float(self)
Pillow.ImageMath.ImagemathEqual(self, other)    ;  alias imagemath_equal(self, other)
Pillow.ImageMath.ImagemathNotequal(self, other) ;  alias imagemath_notequal(self, other)
Pillow.ImageMath.ImagemathMin(self, other)      ;  alias imagemath_min(self, other)
Pillow.ImageMath.ImagemathMax(self, other)      ;  alias imagemath_max(self, other)
Pillow.ImageMath.ImagemathConvert(self, mode)   ;  alias imagemath_convert(self, mode)

构造 Operand:int(self)、float(self)、(self == other)、(self != other)、min(self, other)、max(self, other) 与 convert(self, 'mode')。mode 必须为字符串,否则 imagemath_convert 抛 Pillow.ImageMath.imagemath_convert mode expects a string。

返回:Operand(用 Eval 求值)。

Operand 类

Operand class

op := Pillow.ImageMath.Operand(expr, variables := unset)
op.Expr        ;  expression string
op.Variables   ;  merged variable Map

为 lambda_eval 包装图像操作数表达式。二元/一元运算符以方法形式暴露——AHK 2.1-alpha.30 不派发运算符元函数,故 Pillow _Operand 的运算符表面(+ - * / % ** << >> & | ^ ~ 与一元 -/~)即下列方法,lambda_eval 也以 add/sub/mul/div/mod/neg 函数收到它们。

Method中文
Add(other) / Sub(other) / Mul(other) / Div(other) / Mod(other)二元 << / >>。
BitAnd(other) / BitOr(other) / BitXor(other)一元 - / ~。

差异:缺少 **(无 Pow 方法)。OperandOps() 返回的 ops 字典把 int/float/equal/notequal/min/max/convert 映射到 Imagemath* 构造器,把 add/sub/mul/div/mod/neg 映射到二元/一元构造器——即 Pillow 运算符表面的 AHK 适配。

对齐边界:RPN 的 convert("L") 报告模式 I——已记录的差异(L 值被截断,但返回图像标记为 I)。见行为边界。

内部编译器成员

Eval 使用的词法/语法/发射器。对门面内部公开并被测试套件钉死;不属于 Pillow 风格的用户 API。

Member中文
Tokenize(expression)调车场解析 → AST 与槽表。
EmitBinary(name, output, &floatBitwiseOperator)生成一元 -/~ 节点。
EmitCall(name, output)在 AHK 中求值纯标量树。
NormalizeVariables(variables := unset)把线性化 RPN 程序打包为字节 Buffer。
SortedKeys(map)构造 (l op r),合并变量表。
OperandUnary(value, op)把 Number/Operand 归一为 Operand。
OperandFunction(name, args*)传给 lambda 可调用对象的 ops Map。
OperatorName(op)纯标量路径的二元算术。
AddConstant(value, isFloat, …)分配图像槽;记录首图尺寸。
Linearize(node, program)把 AST 展平为 RPN 操作码。

示例

对两幅图像求值表达式,并执行一次 lambda_eval 转换:

img1 := Pillow.Image.Open("a.jpg")
img2 := Pillow.Image.Open("b.jpg")
;    Eval over two images — the variables Map is Pillow's kwargs.
sum := Pillow.ImageMath.Eval("a + b", Map("a", img1, "b", img2))
;    lambda_eval: the callable gets the ops dictionary + keyword Operands.
;    Pillow equivalent: lambda_eval(lambda: convert(a, "L"), a=img1)
gray := Pillow.ImageMath.LambdaEval(
    (args) => args["convert"](args["a"], "L"),
    , "a", img1)
img1.Close(), img2.Close()
