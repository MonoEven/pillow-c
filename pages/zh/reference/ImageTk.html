ImageTk 模块

ImageTk 模块对应 Pillow 11.3.0 的 PIL.ImageTk:用于 Tk Canvas、Label 或 Button 的 Tkinter 兼容图像对象(PhotoImage、BitmapImage)。

本运行时不含 Tk 解释器,因此构造任一类都显式失败,抛出 Pillow 11.3.0 的原样报错 Too early to create image: no default root window(即根窗口尚不存在时 Tkinter 抛出的 RuntimeError)。见行为边界。

PhotoImage static

Pillow.ImageTk.PhotoImage(image := unset, args*)

Pillow 的 ImageTk.PhotoImage(image, size=None, **kw) 由 Pillow Image 构造 Tkinter 兼容的照片图像(Tk 的 PhotoImage),并按 Tk 的要求转换模式(如 RGBA → 带透明索引的 P)。

image
要包装的 Pillow Image(唯一的位置参数)。
args*
额外的 Tkinter 关键字(如 size);仅为签名兼容而接受并被忽略——构造在用到它们之前即失败。

边界:构造抛 Pillow 原样的 Too early to create image: no default root window。见行为边界。

BitmapImage static

Pillow.ImageTk.BitmapImage(image := unset, args*)

Pillow 的 ImageTk.BitmapImage(image, size=None, **kw) 为 1 位(模式 "1")Pillow Image 构造 Tkinter 兼容的位图图像(Tk 的 BitmapImage)。

image
要包装的 1 位 Pillow Image(唯一的位置参数)。
args*
额外的 Tkinter 关键字(如 size);仅为签名兼容而接受并被忽略——构造在用到它们之前即失败。

边界:构造抛 Pillow 原样的 Too early to create image: no default root window。见行为边界。

RequireTk static

Pillow.ImageTk.RequireTk()

内部辅助:抛出边界错误 Too early to create image: no default root window。两个构造函数都委托给它。
