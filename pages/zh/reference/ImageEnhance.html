ImageEnhance 模块

ImageEnhance 模块包含四个增强器类(Color、Contrast、Brightness、Sharpness),通过把图像与一幅退化版本混合来调整它。用法:enhancer := Pillow.ImageEnhance.Contrast(img),再 img2 := enhancer.Enhance(1.5)。

_Enhance base class

enhancer.Enhance(factor)

四个增强器的公共基类。构造器保存源 image 与预先算好的退化图 Degenerate;Enhance(factor) 返回 Pillow.Image.Blend(Degenerate, Image, factor)。

factor
数值混合权重:0.0 → 退化图,1.0 → 原图,>1 → 增强。非数值抛 Pillow 原样的 Pillow.ImageEnhance factor must be numeric。

返回:新 Image(混合结果)。

Color class

Pillow.ImageEnhance.Color(image)

将图像向其灰度版本混合:Enhance(factor) = Blend(灰度图, image, factor)。0.0 → 灰度图,1.0 → 原图,>1 → 夸大色彩饱和度。

image
Pillow.Image(否则抛 Pillow 原样的 Pillow.ImageEnhance.Color expects a Pillow.Image)。

返回:Color 增强器实例。

退化图:L/LA → 副本;RGB → Convert("L").Convert("RGB");RGBA → Convert("LA").Convert("RGBA");CMYK → Convert("L").Convert("CMYK")。其他模式抛 Pillow 原样的 Pillow.ImageEnhance.Color currently supports L LA RGB RGBA and CMYK。

Contrast class

Pillow.ImageEnhance.Contrast(image)

向一幅填充“四舍五入直方图均值”的均匀图像混合:Enhance(factor) = Blend(均值图, image, factor)。0.0 → 均匀均值图,1.0 → 原图,>1 → 对比更强。

image
Pillow.Image(否则抛 Pillow 原样的 Pillow.ImageEnhance.Contrast expects a Pillow.Image)。

返回:Contrast 增强器实例。

退化图:mean = 四舍五入直方图均值(GrayscaleMeanRounded),先构造该值的 L 图再转回源模式;RGBA 重新附加 alpha 通道。

Brightness class

Pillow.ImageEnhance.Brightness(image)

向黑色混合:Enhance(factor) = Blend(黑色, image, factor)。0.0 → 黑色,1.0 → 原图,>1 → 更亮。

image
Pillow.Image(否则抛 Pillow 原样的 Pillow.ImageEnhance.Brightness expects a Pillow.Image)。

返回:Brightness 增强器实例。

退化图:以源模式填充零值的图像;RGBA 保留其 alpha 通道。

Sharpness class

Pillow.ImageEnhance.Sharpness(image)

向 SMOOTH 滤波后的图像混合:Enhance(factor) = Blend(平滑图, image, factor)。0.0 → 平滑图,1.0 → 原图,>1 → 更锐利。

image
Pillow.Image(否则抛 Pillow 原样的 Pillow.ImageEnhance.Sharpness expects a Pillow.Image)。

返回:Sharpness 增强器实例。

退化图:image.Filter(Pillow.ImageFilter.SMOOTH());RGBA 重新附加 alpha 通道。

内部辅助

RequireImage、GrayscaleMeanRounded 与 ZeroColor 是增强器构造使用的模块辅助函数——对门面内部公开,不属于 Pillow 风格的用户 API。

示例

对同一源图像提亮 1.2 倍并锐化 2.0 倍。

img := Pillow.Image.Open("photo.jpg")
b := Pillow.ImageEnhance.Brightness(img)
brighter := b.Enhance(1.2)
s := Pillow.ImageEnhance.Sharpness(img)
sharper := s.Enhance(2.0)
img.Close()
