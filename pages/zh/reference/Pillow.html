Pillow entry class

Pillow 类是门面根:承载各模块类(Image、ImageDraw……)、常量枚举与 DLL 管道。

Configure static

Pillow.Configure(options := unset)

配置门面。选项:DllPath(pillow_c.dll 的路径)。使用任何图像 API 前调用一次。

Pillow.Configure({ DllPath: A_ScriptDir "\build\x64\Release\pillow_c.dll" })

AbiVersion static

Pillow.AbiVersion()

返回 DLL ABI 版本号。

CheckStatus / StatusMessage static

Pillow.CheckStatus(statusCode)      ;  raises on error statuses
Pillow.StatusMessage(statusCode)    ;  status text

CheckStatus 把原生状态码(PILLOW_C_OK=0、NULL_POINTER=-1、INVALID_LENGTH=-2、INVALID_ARGUMENT=-3、ALLOCATION_FAILED=-4)转为抛出的 Error 或空操作;StatusMessage 返回可读文本。

ModeId / ModeName static

Pillow.ModeId(modeName)   ;  "L" → 8, "RGB" → 3, "RGBA" → 4, "I" → 8(int), "F" → 9, ...
Pillow.ModeName(mode)     ;  reverse mapping

在模式字符串与原生模式 id 之间转换。

RequireDllPath / EnsureDllLoaded / WrapImageHandle static

Pillow.RequireDllPath()              ;  configured DLL path (or raises)
Pillow.EnsureDllLoaded()              ;  loads the DLL once
Pillow.WrapImageHandle(handle)        ;  native handle → Pillow.Image

内部管道:解析/加载 DLL,并把原生图像句柄包装为受管理的 Image 对象。
