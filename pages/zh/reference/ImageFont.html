ImageFont 模块

字体加载与度量,对应 Pillow 的 ImageFont:Truetype 把 TrueType/OpenType 文件加载为 FreeTypeFont 对象,其方法负责文字的度量与栅格化,并包含完整的可变字体表面(fvar 轴、命名实例、avar + HVAR 字宽增量)。

模块函数

Truetype static

Pillow.ImageFont.Truetype(font, size := 10, index := 0, encoding := "", layoutEngine := unset)

加载 TrueType/OpenType 字体。size 为磅值;index 选择字体集合中的字面;encoding 选择 Unicode cmap;layoutEngine 接受 Layout.BASIC/Layout.RAQM。

font
.ttf/.otf/.ttc 文件路径或文件句柄;文件缺失抛 cannot open resource。

返回:FreeTypeFont 对象。

LoadPath / Load static

Pillow.ImageFont.LoadPath(filename)   ;  alias: Load(filename), load_path(filename)

从路径加载字体(同 Pillow 的 load_path)。

LoadDefault static

Pillow.ImageFont.LoadDefault()   ;  alias: load_default()

加载 Pillow 的默认位图字体。

边界:内置默认字体与 Pillow 的 Aileron 不同(运行时自带默认字形集),故默认字体度量形态一致但非逐字节相同;用默认字体绘图走原生管线。见行为边界。

FreeTypeFont 对象

GetMetrics

font.GetMetrics()

返回含字面度量的 Map:ascent、descent(像素,FreeType 规则)。

GetName

font.GetName()

返回字体家族名(如 "DejaVu Sans")。

GetLength

font.GetLength(text, mode := "", direction := unset, features := unset, language := unset)

返回文字的前进宽度(像素)。多行文字遵循 Pillow 的最长行规则。

GetBbox

font.GetBbox(text, anchor := unset, mode := "", direction := unset, features := unset, language := unset, strokeWidth := 0)

返回相对锚点的墨迹包围盒 [left, top, right, bottom];strokeWidth 按 Pillow 方式扩大包围盒。

门面说明:anchor 在此为第二个位置参数(Pillow 为倒数第二个);mode/direction/features/language 接受但忽略。锚点算法复刻 Pillow 的 em-box 规则(水平 m→居中、r→右缘;垂直 a→0、t→墨迹顶、m→居中、s/b→墨迹底、d→下沉)。

GetMask

font.GetMask(text, mode := "", ink := 0, direction := unset, features := unset, language := unset, strokeWidth := 0, anchor := unset, start := unset)

把文字渲染为 Image:模式 ""/"L"/"1"/未知 → L(模式 "1" 含单色取整度量);"RGBA" → alpha 随 ink 缩放的 RGBA。

边界:字形由 GDI 栅格化(gray8 墨迹值为已记录的栅格化差异);strokeWidth/anchor/start 接受但忽略(FreeType 描边边界)。

GetMask2

font.GetMask2(text, mode := "", ink := 0, args*)

Pillow 的 getmask2:返回 [mask, offset],offset 为包围盒左上角。

FontVariant

font.FontVariant(font := unset, size := unset, index := unset, encoding := unset, layoutEngine := unset)

返回覆盖了指定属性的字体副本(Pillow 的 font_variant)。

GetVariationAxes

font.GetVariationAxes()   ;  alias: get_variation_axes()

返回可变字体 fvar 轴,为 Map 数组:name(字节)、minimum、default、maximum。

GetVariationNames

font.GetVariationNames()   ;  alias: get_variation_names()

返回命名实例(如 "Regular"、"Bold")的字节串数组。

SetVariationByAxes

font.SetVariationByAxes(axes)   ;  alias: set_variation_by_axes()

按每轴数值数组设置变体坐标(长度须精确匹配)。

对齐:完整复刻引擎——avar 分段映射、HVAR 变体数据存储(格式 0/1,FreeType 区域标量)与 26.6 定点字宽增量;报错形态与 Pillow 一致(argument must be a list、非可变字体的 invalid argument OSError)。

SetVariationByName

font.SetVariationByName(name)   ;  alias: set_variation_by_name()

选择命名实例。

对齐:未知名称抛 Pillow 原样的 b'<name>' is not in list。

TransposedFont 与 Layout

TransposedFont class

Pillow.ImageFont.TransposedFont(font, orientation := unset)

以 EXIF 方向包装字体;暴露 GetMask、GetBbox、GetLength(方向存储、精确的 (0, 0, w, h) getbbox 归一化与 90/270 宽高互换、getlength 委托)。

对齐:90/270 的 GetLength 抛 text length is undefined for text rotated by 90 or 270 degrees。

Layout constants

Pillow.ImageFont.Layout.BASIC := 0
Pillow.ImageFont.Layout.RAQM   := 1

排版引擎常量;RAQM 被接受,但本运行时为无 libraqm 构建(文字方向选项抛 Pillow 的 KeyError 形态)。

内部辅助

CheckStringLength(超长文字按 Pillow 报错拒绝)、LoadDefaultImagefont(加载内置默认位图字体)与 ResolveWindowsFont(Windows 字体路径解析)为门面内部函数——对门面公开使用,不属于 Pillow 风格的用户 API。FreeTypeFont 上的 Close、RequireHandle、DuplicateHandle 与 IsVariable 是公开表面背后的原生句柄生命周期辅助。

示例

加载可变字体、度量与渲染:

font := Pillow.ImageFont.Truetype("C:\Windows\Fonts\bahnschrift.ttf", 24)
axes := font.GetVariationAxes()          ;  e.g. [{"name": b"wght", "minimum": 300, ...}]
font.SetVariationByName("Bold")
mask := font.GetMask2("Hi")              ;  [L-image, offset]
bb   := font.GetBbox("Hi")               ;  [left, top, right, bottom]
len  := font.GetLength("Hi")
