常量

Pillow 命名空间下的枚举类,数值与 Pillow 11.3.0 常量完全一致。

Transpose

Pillow.Transpose.FLIP_LEFT_RIGHT := 0   ; 左右翻转
Pillow.Transpose.FLIP_TOP_BOTTOM := 1   ; 上下翻转
Pillow.Transpose.ROTATE_90 := 2         ; 逆时针 90°
Pillow.Transpose.ROTATE_180 := 3        ; 旋转 180°
Pillow.Transpose.ROTATE_270 := 4        ; 逆时针 270°
Pillow.Transpose.TRANSPOSE := 5         ; 沿主对角线转置
Pillow.Transpose.TRANSVERSE := 6        ; 沿副对角线转置

Transform

Pillow.Transform.AFFINE := 0
Pillow.Transform.EXTENT := 1
Pillow.Transform.PERSPECTIVE := 2
Pillow.Transform.QUAD := 3
Pillow.Transform.MESH := 4

Resampling

Pillow.Resampling.NEAREST := 0
Pillow.Resampling.BOX := 4
Pillow.Resampling.BILINEAR := 2
Pillow.Resampling.HAMMING := 5
Pillow.Resampling.BICUBIC := 3
Pillow.Resampling.LANCZOS := 1

Dither

Pillow.Dither.NONE := 0
Pillow.Dither.FLOYDSTEINBERG := 3

Palette

Pillow.Palette.WEB := 0
Pillow.Palette.ADAPTIVE := 1

Quantize

Pillow.Quantize.MEDIANCUT := 0
Pillow.Quantize.MAXCOVERAGE := 1
Pillow.Quantize.FASTOCTREE := 2
Pillow.Quantize.LIBIMAGEQUANT := 3   ; 编译期边界,抛 Pillow 原样错误

其他常量位于各自模块内:ImageFont.Layout.BASIC/RAQM、ImageFile.MAXBLOCK/SAFEBLOCK/ERRORS,以及 ImageCms 的 intent/flag 枚举(见各页面)。
