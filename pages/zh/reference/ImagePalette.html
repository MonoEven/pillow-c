ImagePalette 模块

ImagePalette 模块把调色板存为扁平的字节序列,并提供调色板构造器与索引查找,对齐 Pillow 11.3.0 的 PIL.ImagePalette。调色板序列存为 AHK Array(Pillow 接受任意整数序列),惰性 Colors 映射使用逗号拼接的字符串键——因为 AHK 的 Map 键按身份比较(没有元组键)。

表面说明:Pillow.ImagePalette(...) 直接构造实例(Pillow 的 ImagePalette.ImagePalette 类)。Random() 与 Pillow 的形状、取值范围一致,但随机流(梅森旋转)不同;Load() 与 PaletteFile/GimpPaletteFile/GimpGradientFile 解析器类为已记录的显式失败边界——见行为边界。

类与字段

ImagePalette class

Pillow.ImagePalette(mode := "RGB", palette := unset)

构造调色板。mode 为通道布局字符串("RGB"、"RGBA"……);palette 为可选的扁平字节 Array(默认空)。本门面的构造器省略 Pillow 末尾的 size 参数——字节数只由 palette.Length 决定。

mode
通道布局字符串;默认 "RGB"。
palette
可选扁平整数序列;unset 得到空调色板。

返回:ImagePalette 实例。

Fields attributes

Field中文
Mode原始模式标记;除非为原始调色板(Raw()),否则为空。
Palette0/1 标志;GetColor 分配或 Raw() 后为 1。
Colors惰性 Map:逗号拼接的颜色键 → 调色板索引(Pillow 的 getcolor 行为)。

实例方法

Copy

palette.Copy()

返回独立副本(mode、rawmode、克隆的字节数组与 dirty 标志)。

返回:新的 ImagePalette。

GetData

palette.GetData()

原始调色板返回 [Rawmode, Palette],否则返回 [Mode, ToBytes()](Pillow 的 getdata 形态)。

返回:[模式字符串, 数据]。

ToBytes / Tostring

palette.ToBytes()
palette.Tostring()   ;  alias of ToBytes (Pillow's tostring)

把调色板条目序列化为字节 Buffer。原始调色板(Rawmode 已设)抛 Pillow 原样的 palette contains raw palette data。

返回:字节 Buffer。

Save

palette.Save(fp)

写出 Pillow 风格的调色板文件:# Palette 头、# Mode: … 行,然后是 256 行索引条目(缺失条目以 0 补齐)。fp 必须为文件路径字符串。

返回:无(写文件)。

GetColor

palette.GetColor(color, image := unset)

返回某颜色的调色板索引,必要时分配新条目(Pillow 的 getcolor)。color 为通道数组,如 [255, 0, 0]。RGB 模式下 4 元素颜色必须 alpha 为 255(否则 cannot add non-opaque RGBA color to RGB palette);RGBA 模式下 3 元素颜色补 alpha 255。原始调色板(Rawmode 已设)抛 palette contains raw palette data。

color
通道数组(3 或 4 元素)。
image
可选图像;其 Info 的 background/transparency 索引作为保留项被跳过。

返回:调色板索引(0–255)。

趣味对齐事实:参考输入下经 oracle 验证的 GetColor 分配序列为 [1, 4, 15, 5, 18, 6, 21]——Pillow 无论模式一律硬编码 //3,并跳过图像的 background/transparency 保留索引,两者均逐项复刻。超过 255 种不同颜色且无空闲直方图槽时抛 cannot allocate more than 256 colors。

模块调色板构造器

Random static

Pillow.ImagePalette.Random(mode := "RGB")

构造 256 条目的随机调色板,通道值在 0–255。形状与取值范围与 Pillow 一致;逐值随机流不同(已记录边界)。

返回:新的 ImagePalette。

边界:Pillow 使用 Python 全局梅森旋转随机流;本运行时用 AHK 自身的随机源,形状与取值范围相同。见行为边界。

Raw static

Pillow.ImagePalette.Raw(rawmode, data)

包装原始调色板字节:设置 Rawmode、把 data 存为字节数组并标记为 dirty。原始调色板不可序列化,也不可做颜色查找。

返回:原始 ImagePalette。

Negative static

Pillow.ImagePalette.Negative(mode := "RGB")

构造通道值自最大值向下递减的调色板(标准渐变的反相)。

返回:新的 ImagePalette。

Sepia static

Pillow.ImagePalette.Sepia(white := "#fff0c0")

通过把三条线性 LUT 缩放到给定 white 颜色(Pillow 默认的暖白)来构造褐色调调色板。

返回:"RGB" ImagePalette。

Wedge static

Pillow.ImagePalette.Wedge(mode := "RGB")

构造灰度渐变调色板:0–255 的每个索引在模式的各通道间重复。

返回:新的 ImagePalette。

MakeLinearLut static

Pillow.ImagePalette.MakeLinearLut(black, white)

构造 256 条目的线性 LUT,自 black 到 white。black 非零时抛 Pillow 原样的 unavailable when black is non-zero。

返回:256 元素整数 Array。

MakeGammaLut static

Pillow.ImagePalette.MakeGammaLut(exp)

构造 256 条目的伽马 LUT:每个索引 i 取 round((i / 255) ** exp * 255)。

返回:256 元素整数 Array。

加载边界

Load static

Pillow.ImagePalette.Load(filename)

通过三段回退链(GimpPaletteFile → GimpGradientFile → PaletteFile)加载 GIMP 调色板、GIMP 渐变或 Teragon 风格调色板文件。文件缺失抛 [Errno 2] No such file or directory: '…';当所有解析器都拒绝内容时,回退链抛 Pillow 原样的 cannot load palette。

filename
调色板/渐变文件路径。

返回:[字节, rawmode]("RGB" 或 "RGBA")。

边界:PaletteFile/GimpPaletteFile/GimpGradientFile 解析器类不作为类暴露——只有 Load 的回退链及其内部辅助函数。渐变的非 RGB 色彩空间(cannot handle HSV colour space)与过短的段行(list index out of range)原样上抛,与 Pillow 一致。见行为边界。

以下成员实现 Load 背后的 GIMP/Teragon 调色板与渐变解析。它们对门面内部公开并被测试套件钉死,但不属于 Pillow 风格的用户 API。

示例

把 Wedge 灰度调色板挂到 P 模式图像上:

pal := Pillow.ImagePalette.Wedge("RGB")   ; 256 级灰度
img := Pillow.Image.New("P", [256, 16])
img.PutPalette(pal.ToBytes(), "RGB")
img.Save("wedge.png")
img.Close()
