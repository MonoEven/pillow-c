ImageCms 模块

ImageCms 模块是 Little CMS 2 色彩管理层,兼容 Pillow 11.3.0(PIL.ImageCms):打开与创建 ICC 配置文件、构建配置文件间的色彩转换、把转换应用于图像,并查询配置文件的 intent 支持。输入/输出模式为 Pillow 模式字符串;本门面的转换校验接受原生层实现的 RGB/LAB 组合(RGB→LAB、LAB→RGB、RGB→RGB、LAB→LAB)。

命名:主名为 PascalCase。AHK 方法查找不区分大小写,故 Pillow 的 snake_case 名(getOpenProfile、createProfile、buildTransform、profileToProfile、versions……)自动解析到同名主方法。错误文本与 Pillow 11.3.0 对齐:配置文件类型错误抛 Invalid type for Profile(Pillow 的 PyCMSError);不支持的模式/intent/flags 组合抛 cannot build transform 或 cannot build proof transform;越界的 intent/flags 抛 Pillow 原样的 renderingIntent must be an integer between 0 and 3 / flags must be an integer between 0 and 100663295。深层原生失败以 pillow_c: <status> 呈现(例如无法读取的 ICC 文件报 pillow_c: invalid argument,而非 Pillow 的 OSError)。

Oracle 对齐:ICC 字节内容、intent 支持与色彩运算均以 Pillow 11.3.0 为基准逐一验证(恒等 RGB→RGB 转换、带 SOFTPROOFING 标志的软打样,以及配置文件序列化)。

PyCMSError

Pillow 的 PyCMSError 继承 Exception;AHK 对应类继承 Error,并携带相同的消息文本(见上方模块说明)。

配置文件对象

GetOpenProfile static

Pillow.ImageCms.GetOpenProfile(profile)

从文件路径字符串、File 对象、内存字节 Buffer 或已有配置文件(引用计数重新包装)打开 ICC 配置文件。返回 ImageCmsProfile(CmsProfile 的子类,额外提供 Tobytes())。含非 ASCII 字符的路径走宽字符路径 API。

profile
路径字符串、File、字节 Buffer 或 CmsProfile;其他类型抛 Invalid type for Profile。

返回:ImageCmsProfile。

CreateProfile static

Pillow.ImageCms.CreateProfile(colorSpace, colorTemp := 0)

创建即时配置文件:"sRGB"(内置 sRGB)、"LAB"(Lab 配置文件,可选白点色温)或 "XYZ"。其他色彩空间抛 Color space not supported for on-the-fly profile creation (<colorSpace>)。"LAB" 时若 colorTemp 非数值抛 Color temperature must be numeric, `<colorTemp>` not valid。

colorSpace
"sRGB"、"LAB" 或 "XYZ"。
colorTemp
可选数值白点色温(开尔文),用于 "LAB";0 取 D50 默认。

返回:CmsProfile(无 Tobytes(),请用 Serialize())。

CmsProfile 实例

Pillow.ImageCms.CmsProfile 包装原生 lcms 配置文件句柄。每个实例拥有自己的句柄(Close() 或析构时释放)。GetOpenProfile/get_display_profile 返回 ImageCmsProfile(额外提供 Tobytes());CreateProfile 返回普通 CmsProfile。

Serialize / Tobytes

profile.Serialize()     ;  CmsProfile (all instances)
profile.Tobytes()       ;  ImageCmsProfile only (Pillow's tobytes)

把配置文件序列化为 ICC 字节表示。Tobytes() 为 Pillow 风格别名,仅存在于 ImageCmsProfile。

返回:ICC 内容的字节 Buffer。

GetName

profile.GetName()

返回配置文件名称字符串(供模块级 GetProfileName 使用)。

返回:字符串。

is_intent_supported

profile.is_intent_supported(intent, direction)

IsIntentSupported 的实例形式:委托给 Pillow.ImageCms.IsIntentSupported(this, intent, direction)。

返回:支持为 1,不支持为 −1。

色彩转换

BuildTransform static

Pillow.ImageCms.BuildTransform(inputProfile, outputProfile, inputMode, outputMode, renderingIntent := 0, flags := 0)

构建两个配置文件之间的色彩转换。先以 Pillow 原样消息校验 intent 与 flags,再校验模式对(仅 RGB/LAB 组合)。不支持的组合抛 cannot build transform。转换在构建时快照输出配置文件的 ICC 字节,且不拥有配置文件对象,因此转换构建完成后即可关闭配置文件。

inputProfile / outputProfile
两个 CmsProfile 实例;类型错误抛 Invalid type for Profile。
inputMode / outputMode
Pillow 模式字符串("RGB" 或 "LAB");有效组合为 RGB→LAB、LAB→RGB、RGB→RGB、LAB→LAB。
renderingIntent
0…3(默认 0 = PERCEPTUAL)。
flags
0 或 BLACKPOINTCOMPENSATION(8192)。

返回:ImageCmsTransform。

BuildTransformFromOpenProfiles static

Pillow.ImageCms.BuildTransformFromOpenProfiles(inputProfile, outputProfile, inputMode, outputMode, renderingIntent := 0, flags := 0)

BuildTransform 的别名(Pillow 的 buildTransformFromOpenProfiles 即 buildTransform 的别名)。

返回:ImageCmsTransform。

BuildProofTransform static

Pillow.ImageCms.BuildProofTransform(inputProfile, outputProfile, proofProfile, inputMode, outputMode, renderingIntent := 0, proofRenderingIntent := 3, flags := 0x4000)

经 proof 配置文件构建软打样转换。默认 proofRenderingIntent := 3(ABSOLUTE_COLORIMETRIC)、flags := 0x4000(SOFTPROOFING);支持的 flags 组合为 SOFTPROOFING 与 SOFTPROOFING | GAMUTCHECK(0x5000)。不支持的组合抛 cannot build proof transform。

inputProfile / outputProfile / proofProfile
三个 CmsProfile 实例;类型错误抛 Invalid type for Profile。
inputMode / outputMode
"RGB"/"LAB" 模式对(RGB→LAB、LAB→RGB、RGB→RGB、LAB→LAB)。
renderingIntent / proofRenderingIntent
0…3;proofRenderingIntent 必须为 3(ABSOLUTE_COLORIMETRIC)。
flags
SOFTPROOFING(默认)或 SOFTPROOFING | GAMUTCHECK。

返回:ImageCmsTransform。

BuildProofTransformFromOpenProfiles static

Pillow.ImageCms.BuildProofTransformFromOpenProfiles(inputProfile, outputProfile, proofProfile, inputMode, outputMode, renderingIntent := 0, proofRenderingIntent := 3, flags := 0x4000)

BuildProofTransform 的别名(Pillow 的 buildProofTransformFromOpenProfiles 即 buildProofTransform 的别名)。

返回:ImageCmsTransform。

ImageCmsTransform 实例

已构建的转换提供 input_mode / output_mode 属性与下列方法。它拥有自己的原生转换句柄(Close() 或析构时释放)。

Apply

transform.Apply(image)

把转换应用于图像并返回 output_mode 下的新图像。图像模式必须等于 input_mode,否则抛 mode mismatch。结果的 icc_profile info 被设为输出配置文件字节。

返回:新 Image。

ApplyInPlace

transform.ApplyInPlace(image)

就地应用转换;要求 input_mode == output_mode 且图像模式匹配,否则抛 mode mismatch。

返回:无(原地修改图像)。

OutputProfileBytes

transform.OutputProfileBytes()

返回输出配置文件的 ICC 字节——构建转换时捕获的快照。

返回:字节 Buffer。

ApplyTransform static

Pillow.ImageCms.ApplyTransform(image, transform, inPlace := false)

把转换应用于图像:inPlace 为真时走 transform.ApplyInPlace(image),否则走 transform.Apply(image)。参数类型错误抛 Invalid image type / Invalid transform type。

image
Pillow.Image 图像。
transform
ImageCmsTransform 转换。
inPlace
为真则原地修改;默认假则返回新图像。

返回:新 Image(inPlace 时无返回值)。

ProfileToProfile static

Pillow.ImageCms.ProfileToProfile(image, inputProfile, outputProfile, renderingIntent := 0, outputMode := unset, inPlace := false, flags := 0)

一步把图像从 inputProfile 转换到 outputProfile。与 Pillow(默认 outputMode 取图像模式)不同,本门面要求显式传入 outputMode:省略时抛 cannot build transform。就地模式要求 image.Mode == outputMode。

image
Pillow.Image 图像。
inputProfile / outputProfile
两个 CmsProfile 实例。
renderingIntent
0…3(默认 0)。
outputMode
必填的 Pillow 模式字符串("RGB"/"LAB")。
inPlace
为真则原地修改(模式须匹配);假则返回新图像。
flags
0 或 BLACKPOINTCOMPENSATION(8192)。

返回:新 Image(inPlace 时无返回值)。

示例

打开 sRGB 与 AdobeRGB 配置文件,构建 RGB→RGB 转换并应用,然后序列化配置文件字节。

;   Open two ICC profiles
srgb     := Pillow.ImageCms.GetOpenProfile("sRGB.icc")
adobergb := Pillow.ImageCms.GetOpenProfile("AdobeRGB.icc")

;   Build an RGB→RGB transform
transform := Pillow.ImageCms.BuildTransform(srgb, adobergb, "RGB", "RGB",
    Pillow.ImageCms.Intent.PERCEPTUAL, 0)

;   Apply it to an image
im  := Pillow.Image.Open("photo.jpg")
out := Pillow.ImageCms.ApplyTransform(im, transform)
out.Save("photo_adobe.jpg")

;   Serialize the profile bytes
iccBytes := srgb.Tobytes()                 ; ICC 内容 Buffer
im.Info["icc_profile"] := adobergb.Serialize()

;   Clean up
out.Close(), im.Close(), transform.Close(), srgb.Close(), adobergb.Close()
