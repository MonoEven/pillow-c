Image 模块

Image 类是库的核心:它包装由 pillow_c.dll 持有的原生图像句柄,提供 Pillow 11.3.0 的完整对象表面——构造、几何变换、像素、调色板、滤镜、合成、元数据与存取。AHK 数组对应 Python 元组([宽, 高]、[x, y]、[left, upper, right, lower]),unset 对应 None,错误以携带 Pillow 原始报错文本的 Error 抛出,Info 为 Map。

所有方法同时提供 Pillow 的 snake_case 别名(resize、getbbox、putpixel……);本页按 PascalCase 主名列示。

多数方法返回新 Image 且不改动本对象(Pillow 语义);就地修改的操作在下方单独标注。

构造与打开

New static

Pillow.Image.New(modeName, size, color := unset)

以给定模式与尺寸创建新图像,可选用单一颜色填充。

modeName
模式字符串:"1"、"L"、"P"、"RGB"、"RGBA"、"CMYK"、"I"、"F"、"I;16"……
size
数组 [宽, 高],单位为像素。
color
填充色:颜色名字符串、#rgb/#rrggbb 字符串、整数(L/I)、浮点数(F)或逐通道数组。

返回:新 Image。

Open static

Pillow.Image.Open(path, formats := unset)

打开并识别图像文件,与 Pillow 一样惰性解码(按需完成解码)。格式按内容识别,不依赖扩展名。

path
图像文件的文件系统路径。
formats
可选的格式名或 MIME 类型列表,优先尝试(Pillow 的 formats 参数)。

返回:新 Image。

对齐:文件缺失抛 FileNotFoundError,内容无法识别抛带引号的 UnidentifiedImageError;WebP/AVIF/JPEG2000 内容抛原样的 decoder … not available(见行为边界页)。

FromBytes static

Pillow.Image.FromBytes(modeName, size, bytes, decoder := unset, rawmode := unset, stride := 0, orientation := 1)

从内存中的原始像素字节构造图像(Pillow 的 Image.frombytes)。

modeName
模式字符串。
size
数组 [宽, 高]。
bytes
原始像素数据缓冲区;长度必须与模式/尺寸/步长匹配。
decoder / rawmode
解码器名与原始模式(如 "raw" / "RGB");默认 raw。
stride / orientation
行步长(字节)与存储方向(1 = 自顶向下)。

返回:新 Image。

FromBuffer static

Pillow.Image.FromBuffer(modeName, size, data, decoder := "raw", rawmode := unset, stride := 0, orientation := 1)

与 FromBytes 相同,解码器默认 "raw"(Pillow 的 Image.frombuffer;Pillow 的弃用模式警告在此不适用)。

返回:新 Image。

FromBytes (instance) method

image.FromBytes(bytes, decoder := unset, rawmode := unset, stride := 0, orientation := 1)

把原始字节载入本图像的像素存储。

返回:本图像(就地修改)。

Load method

image.Load()

分配像素存储并解码文件数据(Pillow 的 load())。门面按需解码,故通常无需显式调用。

返回:PixelAccess 对象。

PixelAccess class

Pillow.Image.PixelAccess(image)
pa[x, y]          ;  read  — GetPixel([x, y])
pa[x, y] := value ;  write — PutPixel([x, y], value)

Pillow 的像素访问对象:以 [x, y] 索引读写单个像素(内部走 GetPixel/PutPixel),含负数回绕与浮点截断。

Merge static

Pillow.Image.Merge(modeName, bands)

把若干单通道图像合并为多通道新图(Split 的逆操作)。

modeName
目标模式(如 3 通道用 "RGB",4 通道用 "RGBA")。
bands
单通道 Image 数组;数量必须与模式匹配。

返回:新 Image。

Blend static

Pillow.Image.Blend(left, right, alpha)

对同模式同尺寸的两图插值:left * (1 - alpha) + right * alpha。

alpha
0.0…1.0 之间的数;0 返回左图,1 返回右图。

返回:新 Image。

Composite static

Pillow.Image.Composite(image1, image2, mask)

mask 为 255 处取 image1、为 0 处取 image2;中间值不混合(与 Blend 不同)。

返回:新 Image。

AlphaComposite static + method

Pillow.Image.AlphaComposite(dst, src)   ;  static
image.AlphaComposite(image, dest := unset, source := unset)   ;  method

按 alpha 把 RGBA 源图合成到目标上:out = src*a + dst*(1-a)。方法形式支持目标/源偏移。

dest / source
可选 [x, y] 偏移;两者须同时给出或同时省略。

返回:新 Image(方法形式)/ 合成结果(静态形式)。

LinearGradient / RadialGradient static

Pillow.Image.LinearGradient(modeName)
Pillow.Image.RadialGradient(modeName)

返回 256×256 渐变图。支持模式:1、L、P、I、F(多字符模式抛 Pillow 原样的 image has wrong mode,未知单字符模式抛 unrecognized image mode)。线性:值为 y,自上而下。径向:值 = (int)sqrt(((x−128)²+(y−128)²)×2),≥255 时截断,自中心向外。

返回:新 Image。

EffectMandelbrot static

Pillow.Image.EffectMandelbrot(size, extent, quality)

生成 Mandelbrot 集图像。

size
数组 [宽, 高]。
extent
复平面区域的数组 [x0, y0, x1, y1]。
quality
整数迭代质量。

返回:新 Image。

EffectNoise static

Pillow.Image.EffectNoise(size, sigma)

生成给定尺寸的高斯噪声图像。

sigma
噪声标准差。

返回:新 Image。

EffectSpread static + method

Pillow.Image.EffectSpread(image, distance)   ;  static
image.EffectSpread(distance)                  ;  method

把每个像素随机位移到 distance 大小的邻域内(Pillow 的 Image.effect_spread)。

返回:新 Image。

几何变换

Crop

image.Crop(box := unset)

返回由四元矩形框定的区域。省略 box 时使用非零区域的包围盒。

box
[left, upper, right, lower];坐标可在图像之外。

返回:新 Image。

对齐:顺序错误时原样抛出 Coordinate 'right' is less than 'left' / Coordinate 'lower' is less than 'upper'。

Resize

image.Resize(size, resample := unset, box := unset, reducingGap := unset)

返回调整大小后的副本。默认 Resampling.BICUBIC(Pillow 11.3.0 规则:仅 BGR; 模式默认 NEAREST)。

size
数组 [宽, 高]。
resample
Resampling.NEAREST/BOX/BILINEAR/HAMMING/BICUBIC/LANCZOS;非法值抛 Unknown resampling filter (<value>). Use Image.Resampling…。
box
可选源区域 [left, upper, right, lower]。
reducingGap
先按此倍数分步缩小(Pillow 的 reducing_gap)。

返回:新 Image。

对齐:RGBA/LA 非 NEAREST 缩放先按 alpha 预乘(+127),a == 0 处保留预乘值;1/P 模式强制 NEAREST;I;16 使用 Pillow 的 16bpc 两遍采样;I;16B 非 NEAREST 抛出已记录的边界错误。

Thumbnail

image.Thumbnail(size, resample := unset, reducingGap := 2.0)

就地修改本图像为不超过 size 的缩略图,保持宽高比。

返回:无(就地修改)。

Reduce

image.Reduce(factor, box := unset)

以块平均方式把图像缩小 factor 倍并返回副本(正整数倍数)。

返回:新 Image。

Rotate

image.Rotate(angle, resample := unset, expand := false, center := unset, translate := unset, fillcolor := unset)

逆时针旋转 angle 度。

expand
为真时扩大输出以容纳整个旋转后的图像。
center
可选旋转中心 [x, y];默认图像中心。
translate
可选旋转后平移 [x, y]。
fillcolor
旋转后空白区域的颜色。

返回:新 Image。

Transpose

image.Transpose(method)

按 Transpose 常量翻转或旋转 90° 的整数倍(FLIP_LEFT_RIGHT、FLIP_TOP_BOTTOM、ROTATE_90/180/270、TRANSPOSE、TRANSVERSE)。

返回:新 Image。

对齐:非法值抛 No such transpose operation。

Transform

image.Transform(size, method, data, resample := unset, fillcolor := unset)

应用仿射/范围/透视/四边形/网格变换(Transform 常量;数据布局见 ImageTransform 页)。

size
输出尺寸 [宽, 高]。
method
Transform.EXTENT/AFFINE/QUAD/PERSPECTIVE/MESH。
data
数值数组(系数 / 角点 / 网格三元组)。
resample / fillcolor
重采样滤波器与背景色。

返回:新 Image。

Draft

image.Draft(mode, size)

配置解码器以缩小尺寸解码(JPEG)或为模式转换做准备;须在打开后立即调用。

mode
请求的模式。
size
请求的尺寸。

返回:无。

像素与通道

GetPixel / PutPixel

image.GetPixel(xy)        ;  xy = [x, y]
image.PutPixel(xy, value)

读写单个像素。坐标的负数回绕与 Pillow 一致(-1 为最后一个像素),浮点数截断。

value
整数(L/I)、逐通道数组(RGB…)或颜色字符串。

GetPixel 返回:像素值。PutPixel 返回:无(就地修改)。

对齐:字符串抛 an integer is required;越界抛 image index out of range。

GetData / PutData

image.GetData(band := unset)
image.PutData(data, scale := 1.0, offset := 0.0)

批量像素读写。GetData 返回每通道 256 项直方图组成的数组,或单通道的直方图。PutData 写入每通道直方图数组,可选线性变换。

返回:直方图数组(GetData)/ 无(PutData)。

Fill

image.Fill(color)

用单一颜色填满整幅图像(就地修改)。

Point

image.Point(lut, modeName := unset)

用查找表映射像素:每通道一个可调用对象,或扁平 LUT 数组。

lut
可调用对象或 LUT 数组;条目按 round(src) → dst 生效。
modeName
可选输出模式(如 "1" 或 "L")。

返回:新 Image。

对齐:LUT 过短抛 wrong number of lut entries;字符串条目抛 type str doesn't define __round__ method。

GetChannel

image.GetChannel(channel)

返回单个通道的 L 模式副本。通道 0 = 红(第一通道);负数自末通道起计。

返回:新的 L 模式 Image。

Split / GetBands / BandNames

image.Split()       ;  array of single-band copies
image.GetBands()    ;  array of channel names, e.g. ["R","G","B"]
image.BandNames()   ;  same as GetBands

Split 返回每通道一份 L 副本。GetBands/BandNames 返回 Pillow 在报错中使用的通道名列表(["R","G","B"]、["L"]、["C","M","Y","K"]……)。

统计

Histogram

image.Histogram(mask := unset)

返回直方图:每通道 256 项,与 Pillow 一样扁平拼接为一个数组。

mask
可选同尺寸 1/L 模式掩膜;仅统计掩膜内像素。

对齐:非 1/L 掩膜抛 bad transparency mask;尺寸不符抛 images do not match。I;16 直方图保留 Pillow 依赖内存布局的字节误读,记为边界。

Entropy

image.Entropy(mask := unset)

返回由直方图计算的图像熵(每像素比特数)。

GetExtrema

image.GetExtrema()

返回像素极值:单通道模式(L、I、F……)返回扁平 [min, max] 数组;多通道模式返回逐通道的 [min, max] 二元组数组(Pillow getextrema 的形态)。

对齐:I;16B 抛 Pillow 的 image has wrong mode。

GetBbox

image.GetBbox(alphaOnly := true)

返回非零区域的包围盒 [left, upper, right, lower]。alphaOnly := false 时忽略 alpha;全零图像返回 None(unset)。

GetProjection

image.GetProjection()

返回两个逐轴数组,统计每列(x)与每行(y)的非零像素数。

GetColors

image.GetColors(maxcolors := 256)

返回最常见颜色的 [计数, 颜色] 数组;颜色数超过 maxcolors 时返回 None(unset)。

调色板与量化

GetPalette / PutPalette

image.GetPalette(rawmode := "RGB")
image.PutPalette(data, rawmode := "RGB")

读写 P 模式图像的调色板。GetPalette 返回原始调色板字节(RGB 为 768 字节);PutPalette 挂接新调色板。

Quantize

image.Quantize(colors := 256, method := unset, kmeans := 0, palette := unset, dither := unset)

把图像转换为至多 colors 色的 P 模式。

method
Quantize.MEDIANCUT/MAXCOVERAGE/FASTOCTREE;LIBIMAGEQUANT 抛 Pillow 原样的 dependency required by this method was not enabled at compile time。
kmeans
k-means 精化迭代次数。
palette
可选的量化目标调色板图像。
dither
Dither.NONE 或 Dither.FLOYDSTEINBERG。

返回:新的 P 模式 Image。

ApplyTransparency / RemapPalette

image.ApplyTransparency()   ;  image.ApplyTransparency()
image.RemapPalette(destImage)

ApplyTransparency 把 P 模式透明色替换为真正的 alpha 通道。RemapPalette 以另一 P 模式图像的调色板重映射本图颜色。

合成与粘贴

Paste

image.Paste(source, box := unset, mask := unset)

把另一图像粘贴进本图像(就地修改)。省略 box 时两图须同尺寸;二元 box 定位源图左上角;四元 box 先把源图缩放到该区域。

mask
可选 1/L/RGBA 掩膜;255 = 粘贴,0 = 保留。

PutAlpha

image.PutAlpha(alpha)

以同尺寸 L 模式图像添加或替换 alpha 通道。

返回:新 Image。

转换与滤镜

Convert

image.Convert(modeName := unset, matrixOrDither := unset, dither := unset, palette := unset, colors := unset)

返回转换后的副本。省略模式时复制图像(可选把调色板转为 RGBA)。

modeName
目标模式;4×4 或 4×3 矩阵按 matrix · src + offset 转 L/RGB(12 值)或 RGBA/CMYK(16 值)。
matrixOrDither / dither
矩阵或 Dither 常量;P→RGB 转换可抖动。
palette
转 P 模式时的目标 Palette 常量或颜色序列。
colors
ADAPTIVE 调色板的颜色数(默认 256)。

返回:新 Image。

Filter

image.Filter(filter)

应用 ImageFilter 并返回结果。参数必须是 ImageFilter.Filter 实例或类。

对齐:其他参数抛 filter argument should be ImageFilter.Filter instance or class。

元数据与属性

GetExif / GetXmp

image.GetExif()   ;  an Image.Exif object
image.GetXmp()    ;  XMP metadata map, or None (unset)

GetExif 返回由已解码 EXIF 数据构造的 Image.Exif 对象(Pillow 的 getexif())。GetXmp 把内嵌 XMP 包解析为嵌套 Map(缺省时为 unset)。

Exif class

Pillow.Image.Exif.FromImage(image)
exif.Has(tag)                       ;  tag present?
exif.Get(tag, defaultValue := unset) ;  tag value
exif.Delete(tag)                     ;  remove a tag
exif.ToBytes()                       ;  serialized EXIF blob

Pillow 的 Exif 对象:Has/Get/Delete 操作 EXIF 标签;ToBytes 序列化回带 TIFF 头的 EXIF 数据块。标签值存于分类型的 Map(AsciiTags、IntTags、RationalTags、ByteArrayTags、UndefinedTags……),Orientation/HasOrientation 对应 Pillow 的同名字段。

分类型标签读取器(ReadUintTag、ReadAsciiTag、ReadRationalTag……)与 Normalize*/*TagType 辅助是 FromImage 背后的内部 EXIF 解析机制。

GetIm / Im method + property

image.GetIm()   ;  native handle
image.Im        ;  same handle

返回底层原生图像句柄(Pillow im ImagingCore 对象的对应物)。原生 ABI 覆盖 ImagingCore 的方法表面。

TiffCompressionName static

Pillow.Image.TiffCompressionName(value)

把 TIFF 压缩码映射为 Pillow 名称(1→"raw"、5→"lzw"、6→"jpeg"、8→"deflate"、32773→"packbits"……),用于 Info["compression"]。

保存与生命周期

Save

image.Save(path, format := unset, options := unset)

把图像保存为文件。格式由扩展名推断或显式指定。Pillow 的关键字选项映射为 PascalCase 选项键(quality、optimize、subsampling、dpi、compressLevel、iccProfile……)。

path
输出路径(也可接受类文件句柄)。
format
扩展名不明时显式指定的格式名。
options
编码器选项 Map。

返回:无。

ToBytes / ToBitmap

image.ToBytes(encoder := unset, rawmode := unset, orientation := 1)
image.ToBitmap(name := "image")

ToBytes 把图像编码为字节缓冲(tobytes)。ToBitmap 保存 AutoHotkey Gui 可用的位图文件(name 为文件基名)。

Copy

image.Copy()

返回本图像的完整副本(像素与 Info;文件数据不复制)。

Seek / Tell

image.Seek(frame)
image.Tell()   ;  current frame index

在动画图像的帧间移动(GIF、ICO、TIFF、FLI、MNG……)。Tell 返回当前帧号。

Verify

image.Verify()

不解码像素而校验文件完整性;文件损坏时抛出。

Close

image.Close()

释放原生图像句柄。对象随即不可用(Pillow 的已关闭图像报错形态)。

Show / ToQImage / ToQPixmap

image.Show(title := unset)
image.ToQImage()     ;  alias served by AHK case-insensitivity: toqimage()
image.ToQPixmap()    ;  alias: toqpixmap()

用系统查看器显示图像,或转换为 Qt 图像/画布(本运行时为边界)。

边界:AHK 运行时没有查看器注册表与 Qt 绑定,Show 抛 Pillow 形态的 no viewers found,ToQImage/ToQPixmap 抛 Pillow 原样的 Qt bindings are not installed,而非启动查看器或构造 QImage/QPixmap 对象。见行为边界。

GetChildImages

image.GetChildImages()

返回子图像(如 ICO 尺寸)——已实现句柄返回空数组,与 Pillow 一致。

ImagePut 互操作

与 ImagePut 的可选桥接。这些函数始终存在于 pillow.ahk 中，但只有用户先 #Include ImagePut 后才会真正调用它；否则会抛出明确的“requires ImagePut”错误。

FromImagePut static

Pillow.Image.FromImagePut(source, mode := "RGBA")

接受安全的 ImagePut 兼容输入（文件路径、URL、剪贴板、屏幕区域 [x, y, w, h]、已有 ImagePut buffer 等），通过 ImagePut 的 32-bit ARGB buffer 转换后返回新的 Pillow Image。输入会先经 ImageCheckSafe 校验；裸指针、句柄和监视器数字会被拒绝。如果 mode 不是 "RGBA"，会先以 RGBA 导入，再转换为请求的模式。未先 #Include ImagePut 时抛出明确的“requires ImagePut”错误。

返回：一个新的 Image。

ToImagePut static + method

Pillow.Image.ToImagePut(image)   ;  static
image.ToImagePut()               ;  instance form

将 Pillow Image 导出为 ImagePut 兼容的 buffer 对象。非 RGBA 图像会在内部先转换为 RGBA；ImagePut buffer 是 32-bit ARGB，因此往返过程保留 alpha。

返回：一个 ImagePut BitmapBuffer 对象，可传给 ImagePutWindow / ImagePutFile 等 ImagePut 函数。
