ImageTransform 模块

Pillow 11.3.0 的 PIL.ImageTransform 类对象。每个子类仅携带一个方法常量(Transform.EXTENT/AFFINE/QUAD/PERSPECTIVE/MESH);基类 Transform 存储数据并把 Transform() 路由到门面的 Image.Transform 接缝。Pillow 的该模块本身不可调用。

ImageTransform (module) class

__New(args*) {
    throw Error("Pillow ImageTransform module is not callable;  construct Pillow.ImageTransform.Transform subclasses", -1)
}

Pillow 的该模块不可调用,故构造模块类即显式失败;应改为构造某个 Transform 子类。

原样抛出:Pillow ImageTransform module is not callable; construct Pillow.ImageTransform.Transform subclasses。见行为边界。

Transform class

class Transform {
    __New(data) {
        this.Data := data
    }
    GetData() {
        return [this.Method, this.Data]
    }
    Transform(size, image, resample := unset, fillcolor := unset) {
        if IsSet(resample) && IsSet(fillcolor)
            return image.Transform(size, this.Method, this.Data, resample, fillcolor)
        if IsSet(resample)
            return image.Transform(size, this.Method, this.Data, resample)
        return image.Transform(size, this.Method, this.Data)
    }
}

基变换对象。__New(data) 存储一个数值数组——系数/角点/网格的布局取决于子类的 Method。GetData() 返回 [method, data]。Transform(size, image, …) 转发到 image.Transform(size, method, data, …),并在给出 resample 与 fillcolor 时透传。

data
数值数组(依方法为系数 / 角点 / 网格三元组)。
size
输出尺寸 [宽, 高]。
image
源 Image。
resample / fillcolor
可选的重采样滤波器与背景色。

Method subclasses classes

class AffineTransform extends Pillow.ImageTransform.Transform {
    Method := Pillow.Transform.AFFINE
}
class ExtentTransform extends Pillow.ImageTransform.Transform {
    Method := Pillow.Transform.EXTENT
}
class PerspectiveTransform extends Pillow.ImageTransform.Transform {
    Method := Pillow.Transform.PERSPECTIVE
}
class QuadTransform extends Pillow.ImageTransform.Transform {
    Method := Pillow.Transform.QUAD
}
class MeshTransform extends Pillow.ImageTransform.Transform {
    Method := Pillow.Transform.MESH
}

每个子类钉死自身的 Method 常量,使 GetData()/Transform() 路由到正确布局。用法:image.Transform(size, method, data, resample, fillcolor),配合 Transform.* 常量。

数据布局

MethodData中文
EXTENT映射到输出上的源区域(裁剪/拉伸/镜像)。
AFFINEx' = ax+by+c,y' = dx+ey+f。
QUAD输出→源四边形的四个角点。
PERSPECTIVE8 个系数,分母为 gx+hy+1。
MESH每个输出网格单元一个四边形;Pillow 要求 MESH 提供重采样滤波器。

原生接缝

C 层 ImagingTransformHandler 接缝(map 处理器)是已记录的边界:Pillow 的可调用 map 形态在本运行时无法存在,超出范围。

关于已记录的 ImagingTransformHandler 边界,见行为边界。

示例

经 image.Transform 的 EXTENT(裁剪/拉伸源矩形)与 AFFINE(六系数映射):

img := Pillow.Image.Open("photo.jpg")

;    EXTENT: map source region [x0,y0, x1,y1] onto a 200×200 output
cropped := img.Transform([200, 200], Pillow.Transform.EXTENT, [40, 40, 360, 360])

;    AFFINE: x' = ax+by+c, y' = dx+ey+f  (shear + translate here)
warped := img.Transform([200, 200], Pillow.Transform.AFFINE, [1, 0.5, 0, 0, 1, 0],
    Pillow.Resampling.BICUBIC, "white")

;    Same via the ImageTransform class objects
quad := Pillow.ImageTransform.QuadTransform([0, 0, 0, 200, 200, 200, 200, 0])
result := quad.Transform([200, 200], img, Pillow.Resampling.BILINEAR)

img.Close()
