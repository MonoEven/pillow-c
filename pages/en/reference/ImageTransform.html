ImageTransform module

Pillow 11.3.0's PIL.ImageTransform class objects. Each subclass only carries a method constant (Transform.EXTENT/AFFINE/QUAD/PERSPECTIVE/MESH); the base Transform class stores the data and routes Transform() through the facade's Image.Transform seam. Pillow's module itself is not callable.

ImageTransform (module) class

__New(args*) {
    throw Error("Pillow ImageTransform module is not callable;  construct Pillow.ImageTransform.Transform subclasses", -1)
}

Pillow's module is not callable, so constructing the module class fails loudly; build one of the Transform subclasses instead.

Raises verbatim: Pillow ImageTransform module is not callable; construct Pillow.ImageTransform.Transform subclasses. See Boundaries.

Transform class

class Transform {
    __New(data) {
        this.Data := data
    }
    GetData() {
        return [this.Method, this.Data]
    }
    Transform(size, image, resample := unset, fillcolor := unset) {
        if IsSet(resample) && IsSet(fillcolor)
            return image.Transform(size, this.Method, this.Data, resample, fillcolor)
        if IsSet(resample)
            return image.Transform(size, this.Method, this.Data, resample)
        return image.Transform(size, this.Method, this.Data)
    }
}

Base transform object. __New(data) stores a number array — the coefficient/corner/mesh layout depends on the subclass's Method. GetData() returns [method, data]. Transform(size, image, …) forwards to image.Transform(size, method, data, …), threading resample and fillcolor when present.

data
Number array (coefficients / corners / mesh triplets per method).
size
Output size [width, height].
image
Source Image.
resample / fillcolor
Optional resampling filter and background color.

Method subclasses classes

class AffineTransform extends Pillow.ImageTransform.Transform {
    Method := Pillow.Transform.AFFINE
}
class ExtentTransform extends Pillow.ImageTransform.Transform {
    Method := Pillow.Transform.EXTENT
}
class PerspectiveTransform extends Pillow.ImageTransform.Transform {
    Method := Pillow.Transform.PERSPECTIVE
}
class QuadTransform extends Pillow.ImageTransform.Transform {
    Method := Pillow.Transform.QUAD
}
class MeshTransform extends Pillow.ImageTransform.Transform {
    Method := Pillow.Transform.MESH
}

Each subclass pins its Method constant, so GetData()/Transform() route to the correct layout. Usage: image.Transform(size, method, data, resample, fillcolor) with the Transform.* constants.

Native seam

The C ImagingTransformHandler seam (the map handler) is the documented boundary: Pillow's callable-map form cannot exist in this runtime and stays out of scope.

See Boundaries for the documented ImagingTransformHandler boundary.

Examples

EXTENT (crop/stretch a source rectangle) and AFFINE (six-coefficient mapping) via image.Transform:

img := Pillow.Image.Open("photo.jpg")

;    EXTENT: map source region [x0,y0, x1,y1] onto a 200×200 output
cropped := img.Transform([200, 200], Pillow.Transform.EXTENT, [40, 40, 360, 360])

;    AFFINE: x' = ax+by+c, y' = dx+ey+f  (shear + translate here)
warped := img.Transform([200, 200], Pillow.Transform.AFFINE, [1, 0.5, 0, 0, 1, 0],
    Pillow.Resampling.BICUBIC, "white")

;    Same via the ImageTransform class objects
quad := Pillow.ImageTransform.QuadTransform([0, 0, 0, 200, 200, 200, 200, 0])
result := quad.Transform([200, 200], img, Pillow.Resampling.BILINEAR)

img.Close()
