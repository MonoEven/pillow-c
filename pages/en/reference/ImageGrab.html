ImageGrab module

The ImageGrab module captures the screen or the clipboard into an Image. On this facade it is a Windows-only seam backed by the native GDI/BitBlt path (pillow_c_image_grab).

Grab static

Pillow.ImageGrab.Grab(bbox := unset, includeLayeredWindows := false, allScreens := false)

Captures a screen region as an RGB Image. bbox is a 4-value rectangle in [left, top, right, bottom] order (x1/y1/x2/y2, matching Pillow's Windows grab): the source assigns left/top/right/bottom from bbox[1..4] and rejects right < left or bottom < top.

bbox
Optional 4-value [left, top, right, bottom] rectangle; when unset, the whole screen is captured.
includeLayeredWindows
Whether to include layered windows (Windows flag).
allScreens
Capture the virtual desktop spanning all monitors instead of the primary screen.

Returns: an RGB Image of the captured region.

Without bbox: allScreens := true takes the virtual-screen rectangle from GetSystemMetrics (76/77/78/79); otherwise the primary screen is taken from GetSystemMetrics (0/1) with left/top at 0. Coordinates are the logical pixels those metrics report; a native capture failure (status -3) raises Pillow's screen grab failed.

GrabClipboard static

Pillow.ImageGrab.GrabClipboard()

Captures an image from the Windows clipboard via pillow_c_image_grab_clipboard. Returns the Image, or 0 (this runtime's None analogue) when the clipboard holds no image.

Examples

Capture the primary screen and a region, then save each as PNG:

img := Pillow.ImageGrab.Grab()
img.Save("screenshot.png")
img.Close()

region := Pillow.ImageGrab.Grab([100, 100, 500, 400])   ;  [left, top, right, bottom]
region.Save("region.png")
region.Close()
