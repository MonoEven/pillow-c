ImageEnhance module

The ImageEnhance module contains four enhancer classes (Color, Contrast, Brightness, Sharpness) that adjust an image by blending it with a degenerate version. Usage: enhancer := Pillow.ImageEnhance.Contrast(img) then img2 := enhancer.Enhance(1.5).

_Enhance base class

enhancer.Enhance(factor)

Shared base of the four enhancers. The constructor stores the source image and a precomputed Degenerate image; Enhance(factor) returns Pillow.Image.Blend(Degenerate, Image, factor).

factor
Numeric blend weight: 0.0 → degenerate image, 1.0 → original, >1 → enhanced. Non-numeric raises Pillow's exact Pillow.ImageEnhance factor must be numeric.

Returns: a new Image (the blend result).

Color class

Pillow.ImageEnhance.Color(image)

Blends the image toward its grayscale version: Enhance(factor) = Blend(grayscale, image, factor). 0.0 → grayscale, 1.0 → original, >1 → exaggerated color saturation.

image
A Pillow.Image (else Pillow's exact Pillow.ImageEnhance.Color expects a Pillow.Image).

Returns: a Color enhancer instance.

Degenerate image: L/LA → a copy; RGB → Convert("L").Convert("RGB"); RGBA → Convert("LA").Convert("RGBA"); CMYK → Convert("L").Convert("CMYK"). Any other mode raises Pillow's exact Pillow.ImageEnhance.Color currently supports L LA RGB RGBA and CMYK.

Contrast class

Pillow.ImageEnhance.Contrast(image)

Blends toward a uniform image filled with the rounded histogram mean: Enhance(factor) = Blend(mean_image, image, factor). 0.0 → uniform mean, 1.0 → original, >1 → more contrast.

image
A Pillow.Image (else Pillow's exact Pillow.ImageEnhance.Contrast expects a Pillow.Image).

Returns: a Contrast enhancer instance.

Degenerate image: mean = rounded histogram mean (GrayscaleMeanRounded), built as an L image of that value then converted to the source mode; RGBA re-applies the alpha channel.

Brightness class

Pillow.ImageEnhance.Brightness(image)

Blends toward black: Enhance(factor) = Blend(black, image, factor). 0.0 → black, 1.0 → original, >1 → brighter.

image
A Pillow.Image (else Pillow's exact Pillow.ImageEnhance.Brightness expects a Pillow.Image).

Returns: a Brightness enhancer instance.

Degenerate image: a zero-filled image in the source mode; RGBA keeps its alpha channel.

Sharpness class

Pillow.ImageEnhance.Sharpness(image)

Blends toward the SMOOTH-filtered image: Enhance(factor) = Blend(smooth, image, factor). 0.0 → smoothed, 1.0 → original, >1 → sharper.

image
A Pillow.Image (else Pillow's exact Pillow.ImageEnhance.Sharpness expects a Pillow.Image).

Returns: a Sharpness enhancer instance.

Degenerate image: image.Filter(Pillow.ImageFilter.SMOOTH()); RGBA re-applies the alpha channel.

Internal helpers

RequireImage, GrayscaleMeanRounded and ZeroColor are module helpers used by the enhancer constructors — public for the facade's own use, not part of the Pillow-style user API.

Examples

Raise brightness by 1.2 and sharpen by 2.0 on the same source image.

img := Pillow.Image.Open("photo.jpg")
b := Pillow.ImageEnhance.Brightness(img)
brighter := b.Enhance(1.2)
s := Pillow.ImageEnhance.Sharpness(img)
sharper := s.Enhance(2.0)
img.Close()
