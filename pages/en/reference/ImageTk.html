ImageTk module

The ImageTk module mirrors Pillow 11.3.0's PIL.ImageTk: Tkinter-compatible image objects (PhotoImage, BitmapImage) used with a Tk Canvas, Label or Button.

This runtime ships no Tk interpreter, so constructing either class fails loudly with Pillow 11.3.0's exact Too early to create image: no default root window message — the RuntimeError Tkinter raises before a root window exists. See Boundaries.

PhotoImage static

Pillow.ImageTk.PhotoImage(image := unset, args*)

Pillow's ImageTk.PhotoImage(image, size=None, **kw) builds a Tkinter-compatible photo image (a Tk PhotoImage) from a Pillow Image, converting modes as Tk requires (e.g. RGBA → P with a transparency index).

image
The Pillow Image to wrap (the only positional argument).
args*
Additional Tkinter keywords (e.g. size); accepted for signature compatibility and ignored — the constructor fails before they are used.

Boundary: constructing raises Pillow's exact Too early to create image: no default root window. See Boundaries.

BitmapImage static

Pillow.ImageTk.BitmapImage(image := unset, args*)

Pillow's ImageTk.BitmapImage(image, size=None, **kw) builds a Tkinter-compatible bitmap image (a Tk BitmapImage) for a 1-bit (mode "1") Pillow Image.

image
The 1-bit Pillow Image to wrap (the only positional argument).
args*
Additional Tkinter keywords (e.g. size); accepted for signature compatibility and ignored — the constructor fails before they are used.

Boundary: constructing raises Pillow's exact Too early to create image: no default root window. See Boundaries.

RequireTk static

Pillow.ImageTk.RequireTk()

Internal helper: throws the boundary error Too early to create image: no default root window. Both constructors delegate to it.
