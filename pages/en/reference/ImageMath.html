ImageMath module

The ImageMath module evaluates image expressions: a Python-like infix mini-language compiled to the native RPN engine, plus Pillow's lambda_eval helper and the imagemath_* single-image operations. Because AHK identifiers are case-insensitive, Pillow's eval/unsafe_eval/lambda_eval and imagemath_* names map onto the PascalCase and snake_case members listed here.

variables is the AHK analogue of Pillow's keyword arguments: a Map of name → Image or Number.

Evaluation & lambda_eval

Eval static

Pillow.ImageMath.Eval(expression, variables := unset)

Compiles and evaluates an expression string (Pillow's ImageMath.eval, identical to unsafe_eval). When the expression references images the result is a new Image; a pure-scalar expression returns a Number (Integer or Float).

expression
String expression; non-strings raise Pillow.ImageMath expects a string expression.
variables
Map of name → Image (modes L/I/F) or Number. Any other container raises Pillow.ImageMath variables must be a Map of name to Image or Number; an unknown name raises 'name' not allowed; a non-L/I/F image raises unsupported mode: <mode>.

Returns: an Image, or an Integer/Float for scalar-only expressions.

Parity: size mismatches raise images do not match; a float operand to a bitwise operator raises bad operand type for '<op>'.

UnsafeEval static

Pillow.ImageMath.UnsafeEval(expression, variables := unset)

Direct alias of Eval (Pillow's unsafe_eval, which is itself the engine behind eval).

LambdaEval static

Pillow.ImageMath.LambdaEval(expression, options := unset, kwargs*)

Pillow's lambda_eval: calls expression with the ops dictionary (int/float/equal/notequal/min/max/convert plus the AHK adaptation add/sub/mul/div/mod/neg) merged with options and keyword values; Image values become Operands. An Operand result is evaluated through Eval; any other result is returned as-is.

expression
A callable (Func/closure); anything else raises Pillow.ImageMath.lambda_eval expects a callable expression. It is invoked with a single Map argument (the merged ops + kwargs).
options
Optional Map of extra names to inject; non-Maps raise Pillow.ImageMath.lambda_eval options must be a Map.
kwargs
Flat name, value, … pairs (Pillow's **kw). Image values are wrapped as Operand(name, Map(name, value)).

Returns: the evaluated Image/Number, or the callable's raw return value.

Expression Syntax

The Eval compiler is a shunting-yard parser over a Python-like infix language. Plain parentheses are grouping — (x + 1) * 2 — and a function name directly before ( is a call.

Single-image Ops

Pillow's module-level imagemath_* helpers are static members here. Each builds an Operand expression (they do not evaluate) and takes an Operand or a Number (auto-wrapped).

ImagemathInt / ImagemathFloat / ImagemathEqual / ImagemathNotequal / ImagemathMin / ImagemathMax / ImagemathConvert static

Pillow.ImageMath.ImagemathInt(self)            ;  alias imagemath_int(self)
Pillow.ImageMath.ImagemathFloat(self)          ;  alias imagemath_float(self)
Pillow.ImageMath.ImagemathEqual(self, other)    ;  alias imagemath_equal(self, other)
Pillow.ImageMath.ImagemathNotequal(self, other) ;  alias imagemath_notequal(self, other)
Pillow.ImageMath.ImagemathMin(self, other)      ;  alias imagemath_min(self, other)
Pillow.ImageMath.ImagemathMax(self, other)      ;  alias imagemath_max(self, other)
Pillow.ImageMath.ImagemathConvert(self, mode)   ;  alias imagemath_convert(self, mode)

Build Operands: int(self), float(self), (self == other), (self != other), min(self, other), max(self, other) and convert(self, 'mode'). mode must be a string or imagemath_convert raises Pillow.ImageMath.imagemath_convert mode expects a string.

Returns: an Operand (evaluate with Eval).

The Operand class

Operand class

op := Pillow.ImageMath.Operand(expr, variables := unset)
op.Expr        ;  expression string
op.Variables   ;  merged variable Map

Wraps an image operand expression for lambda_eval. The binary/unary operators are exposed as methods — AHK 2.1-alpha.30 does not dispatch operator meta-functions, so Pillow's _Operand operator surface (+ - * / % ** << >> & | ^ ~ and unary -/~) is the method list below, and lambda_eval also receives them as the add/sub/mul/div/mod/neg functions.

MethodEN

Divergence: ** (power) is absent (no Pow method). The ops dictionary returned by OperandOps() maps int/float/equal/notequal/min/max/convert to the Imagemath* builders and add/sub/mul/div/mod/neg to the binary/unary builders — the AHK adaptation of Pillow's operator surface.

Parity boundary: the RPN convert("L") seam reports mode I — a documented divergence (the L values are clamped, but the returned image is labelled I). See Boundaries.

Examples

Evaluate an expression over two images, and run a lambda_eval conversion:

img1 := Pillow.Image.Open("a.jpg")
img2 := Pillow.Image.Open("b.jpg")
;    Eval over two images — the variables Map is Pillow's kwargs.
sum := Pillow.ImageMath.Eval("a + b", Map("a", img1, "b", img2))
;    lambda_eval: the callable gets the ops dictionary + keyword Operands.
;    Pillow equivalent: lambda_eval(lambda: convert(a, "L"), a=img1)
gray := Pillow.ImageMath.LambdaEval(
    (args) => args["convert"](args["a"], "L"),
    , "a", img1)
img1.Close(), img2.Close()
