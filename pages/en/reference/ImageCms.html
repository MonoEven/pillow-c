ImageCms module

The ImageCms module is the Little CMS 2 color-management layer, Pillow 11.3.0-compatible (PIL.ImageCms): it opens and creates ICC profiles, builds color transforms between them, applies transforms to images, and reports profile intent support. Input/output modes are Pillow mode strings; this facade's transform validation accepts the RGB/LAB combinations (RGB→LAB, LAB→RGB, RGB→RGB, LAB→LAB) that the native layer implements.

Naming: primary names are PascalCase. AHK method lookup is case-insensitive, so Pillow's snake_case names (getOpenProfile, createProfile, buildTransform, profileToProfile, versions, …) resolve to the same methods automatically. Error text is pinned to Pillow 11.3.0: a wrong-typed profile raises Invalid type for Profile (Pillow's PyCMSError); an unsupported mode/intent/flags combination raises cannot build transform or cannot build proof transform; out-of-range intent/flags raise Pillow's exact renderingIntent must be an integer between 0 and 3 / flags must be an integer between 0 and 100663295. Deep native failures surface as pillow_c: <status> (e.g. an unreadable ICC file reports pillow_c: invalid argument, not Pillow's OSError).

Oracle parity: ICC byte content, intent support, and color arithmetic are oracle-verified against Pillow 11.3.0 (identity RGB→RGB transforms, soft-proofing with the SOFTPROOFING flags, and profile serialization).

Profile Objects

GetOpenProfile static

Pillow.ImageCms.GetOpenProfile(profile)

Opens an ICC profile from a file path string, a File object, an in-memory byte Buffer, or an existing profile (which it re-wraps via reference counting). Returns an ImageCmsProfile (a CmsProfile subclass that adds Tobytes()). A path containing non-ASCII characters is opened via the wide-character path API.

profile
Path string, File, byte Buffer, or CmsProfile; any other type raises Invalid type for Profile.

Returns: an ImageCmsProfile.

CreateProfile static

Pillow.ImageCms.CreateProfile(colorSpace, colorTemp := 0)

Creates an on-the-fly profile: "sRGB" (a built-in sRGB profile), "LAB" (an Lab profile, optionally with a white-point color temperature), or "XYZ". Any other color space raises Color space not supported for on-the-fly profile creation (<colorSpace>). For "LAB" a non-numeric colorTemp raises Color temperature must be numeric, `<colorTemp>` not valid.

colorSpace
"sRGB", "LAB", or "XYZ".
colorTemp
Optional numeric white-point temperature (Kelvin) for "LAB"; 0 gives the D50 default.

Returns: a CmsProfile (no Tobytes() — use Serialize()).

CmsProfile instance

Pillow.ImageCms.CmsProfile wraps a native lcms profile handle. Each instance owns its handle (freed on Close() or destruction). Profiles returned by GetOpenProfile/get_display_profile are ImageCmsProfile (adds Tobytes()); those returned by CreateProfile are plain CmsProfile.

Serialize / Tobytes

profile.Serialize()     ;  CmsProfile (all instances)
profile.Tobytes()       ;  ImageCmsProfile only (Pillow's tobytes)

Serializes the profile to its ICC byte representation. Tobytes() is the Pillow-style alias, present only on ImageCmsProfile.

Returns: a byte Buffer of the ICC content.

GetName

profile.GetName()

Returns the profile name string (used by the module-level GetProfileName).

Returns: a string.

is_intent_supported

profile.is_intent_supported(intent, direction)

Instance form of IsIntentSupported: delegates to Pillow.ImageCms.IsIntentSupported(this, intent, direction).

Returns: 1 when supported, −1 when not.

Transforms

BuildTransform static

Pillow.ImageCms.BuildTransform(inputProfile, outputProfile, inputMode, outputMode, renderingIntent := 0, flags := 0)

Builds a color transform between two profiles. Validates the intent and flags first with Pillow's exact messages, then the mode pair (RGB/LAB combinations only). Unsupported combinations raise cannot build transform. The transform snapshots the output profile's ICC bytes at build time and does not own the profile objects, so the profiles may be closed once the transform is built.

inputProfile / outputProfile
Two CmsProfile instances; wrong types raise Invalid type for Profile.
inputMode / outputMode
Pillow mode strings ("RGB" or "LAB"); valid pairs are RGB→LAB, LAB→RGB, RGB→RGB, LAB→LAB.
renderingIntent
0…3 (default 0 = PERCEPTUAL).
flags
0 or BLACKPOINTCOMPENSATION (8192).

Returns: an ImageCmsTransform.

Pillow.ImageCms.BuildTransformFromOpenProfiles(inputProfile, outputProfile, inputMode, outputMode, renderingIntent := 0, flags := 0)

Alias of BuildTransform (Pillow's buildTransformFromOpenProfiles is an alias of buildTransform).

Returns: an ImageCmsTransform.

Pillow.ImageCms.BuildProofTransform(inputProfile, outputProfile, proofProfile, inputMode, outputMode, renderingIntent := 0, proofRenderingIntent := 3, flags := 0x4000)

inputMode / outputMode
"RGB"/"LAB" mode pair (RGB→LAB, LAB→RGB, RGB→RGB, LAB→LAB).
renderingIntent / proofRenderingIntent
0…3; proofRenderingIntent must be 3 (ABSOLUTE_COLORIMETRIC).
flags
SOFTPROOFING (default) or SOFTPROOFING | GAMUTCHECK.

Returns: an ImageCmsTransform.

ImageCmsTransform instance

A built transform exposes input_mode / output_mode properties and the methods below. It owns its native transform handle (freed on Close() or destruction).

Apply

transform.Apply(image)

Applies the transform to an image and returns a new image in output_mode. The image's mode must equal input_mode, else mode mismatch. The result's icc_profile info is set to the output profile bytes.

Returns: a new Image.

ApplyInPlace

transform.ApplyInPlace(image)

Applies the transform to the image in place; requires input_mode == output_mode and a matching image mode, else mode mismatch.

Returns: nothing (mutates the image).

OutputProfileBytes

transform.OutputProfileBytes()

Returns the output profile's ICC bytes — the snapshot captured when the transform was built.

Returns: a byte Buffer.

ApplyTransform static

Pillow.ImageCms.ApplyTransform(image, transform, inPlace := false)

Applies a transform to an image, dispatching to transform.ApplyInPlace(image) when inPlace is true, otherwise transform.Apply(image). Wrong argument types raise Invalid image type / Invalid transform type.

image
A Pillow.Image.
transform
An ImageCmsTransform.
inPlace
True to mutate the image; false (default) to return a new one.

Returns: a new Image (or nothing when inPlace).

ProfileToProfile static

Pillow.ImageCms.ProfileToProfile(image, inputProfile, outputProfile, renderingIntent := 0, outputMode := unset, inPlace := false, flags := 0)

Transforms an image from inputProfile to outputProfile in one call. Unlike Pillow (which defaults outputMode to the image's mode), this facade requires outputMode: omitting it raises cannot build transform. In-place mode requires image.Mode == outputMode.

image
A Pillow.Image.
inputProfile / outputProfile
Two CmsProfile instances.
renderingIntent
0…3 (default 0).
outputMode
Required Pillow mode string ("RGB"/"LAB").
inPlace
True to mutate the image (mode must match); false to return a new image.
flags
0 or BLACKPOINTCOMPENSATION (8192).

Returns: a new Image (or nothing when inPlace).

Examples

Open sRGB and AdobeRGB profiles, build an RGB→RGB transform, apply it, and serialize the profile bytes.

srgb     := Pillow.ImageCms.GetOpenProfile("sRGB.icc")
adobergb := Pillow.ImageCms.GetOpenProfile("AdobeRGB.icc")


transform := Pillow.ImageCms.BuildTransform(srgb, adobergb, "RGB", "RGB",
    Pillow.ImageCms.Intent.PERCEPTUAL, 0)


im  := Pillow.Image.Open("photo.jpg")
out := Pillow.ImageCms.ApplyTransform(im, transform)
out.Save("photo_adobe.jpg")


iccBytes := srgb.Tobytes()                 ; ICC content Buffer
im.Info["icc_profile"] := adobergb.Serialize()


out.Close(), im.Close(), transform.Close(), srgb.Close(), adobergb.Close()
