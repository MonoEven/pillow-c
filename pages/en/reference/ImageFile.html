ImageFile module

Pillow 11.3.0's PIL.ImageFile module surface. The native ABI decodes and encodes whole files, so the incremental feed/plugin protocol (Parser's decoder-based path, StubImageFile, StubHandler, PyCodec, PyDecoder, PyEncoder) is a documented boundary. The constants (MAXBLOCK/SAFEBLOCK/ERRORS), the LOAD_TRUNCATED_IMAGES default, the whole-file Parser fallback, and the plain PyCodecState object are covered exactly.

Constants

MAXBLOCK / SAFEBLOCK constants

Pillow.ImageFile.MAXBLOCK := 65536
Pillow.ImageFile.SAFEBLOCK := 1048576

Pillow's default chunk sizes for image I/O, identical to PIL.ImageFile.MAXBLOCK and PIL.ImageFile.SAFEBLOCK: MAXBLOCK is the per-read block cap, and SAFEBLOCK the conservative fallback used when a codec does not declare its own block size.

ERRORS Map

static ERRORS := Map(

Truncated Loading

LOAD_TRUNCATED_IMAGES property

static LoadTruncatedImages {
    get => Pillow.ImageFile._LoadTruncated
    set {
        if value
            throw Error("Pillow.ImageFile.LOAD_TRUNCATED_IMAGES truncated-load tolerance is not supported: native decoders require complete files (the Pillow default is False)", -1)
        Pillow.ImageFile._LoadTruncated := false
    }
}
static _LoadTruncated := false

Read/write property whose default is false, matching Pillow's default. Setting it true is a documented fail-loud boundary: native decoders decode whole files strictly, so truncated tolerance cannot be honored and instead raises Pillow's exact rejection message.

Boundary: reading back always yields false; a truthy assignment throws. See Boundaries.

Codec State

PyCodecState class

class PyCodecState {
    Xsize := 0
    Ysize := 0
    Xoff := 0
    Yoff := 0
}

Pillow 11.3.0's plain codec-state object: four integer fields, all defaulting to 0. AHK case-insensitivity serves the snake_case reads/writes (xsize/ysize/xoff/yoff) on top of the PascalCase fields.

Xsize / Ysize
Decoded image dimensions.
Xoff / Yoff
Offset into the decode target.

Boundary Stubs

Pillow's incremental/plugin protocol cannot exist over the whole-file native ABI. These classes fail loudly on construction with Pillow-shaped messages instead of building inert shells.

ImageFile (base object) class

__New(args*) => Pillow.ImageFile.RequireIncremental()

Pillow's ImageFile.ImageFile(fp, name) base object. The AHK runtime has no file-object/incremental protocol, so construction fails loudly.

Raises: Pillow.ImageFile incremental decoding is not supported: the native ABI decodes whole files. See Boundaries.

Parser class

parser := Pillow.ImageFile.Parser()
parser.Reset()
parser.Feed(data)
parser.Close()

Pillow 11.3.0's ImageFile.Parser feed/close consumer. The facade implements Pillow's own fallback path for non-incremental formats: it accumulates the fed buffers and reopens the whole stream through the eager Open at Close(). The observable feed/close/error surface matches Pillow.

Reset
Pillow asserts the parser has not collected data yet; reuse raises cannot reuse parsers.
Feed
Appends a buffer and attempts an eager open, swallowing not-yet-identifiable failures.
Close
Reopens the accumulated stream and returns the Image; unparsable data raises cannot parse this image.

Boundary: the decoder-based incremental decode path stays a documented child — this facade routes through the whole-file fallback only. See Boundaries.

PyCodec / PyDecoder / PyEncoder classes

class PyCodec {

    __New(args*) => Pillow.ImageFile.RequirePyCodecMode()

    __New(args*) => Pillow.ImageFile.RequirePyCodecMode()

Pillow 11.3.0's codec base classes. PyCodec.__init__() requires a mode argument, so constructing any of the three without it raises the exact missing-positional-argument error.

Raises verbatim: PyCodec.__init__() missing 1 required positional argument: 'mode'. See Boundaries.

Deprecated Helpers

ReportOSError static

Pillow.ImageFile.ReportOSError(code)

Serves Pillow 11.3.0's deprecated raise_oserror helper (removal in Pillow 12), which only translates codec decode() return codes — a role the native ABI surfaces directly. AHK identifiers beginning with Raise lex as the raise keyword at call sites, and a parameter named error would shadow the Error class (AHK names are case-insensitive), so the facade member is ReportOSError(code).

Raises: raise_oserror is a deprecated Pillow helper; codec errors surface directly from the native ABI. See Boundaries.

ImageFileFormat does not exist in Pillow 11.3.0 (no such name in the module) and therefore has no facade member here.

Internal helpers
