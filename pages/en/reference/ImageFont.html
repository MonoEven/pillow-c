ImageFont module

Font loading and metrics, mirroring Pillow's ImageFont: Truetype loads a TrueType/OpenType file into a FreeTypeFont object whose methods measure and rasterize text, including the full variable-font variation surface (fvar axes, named instances, avar + HVAR advance deltas).

Module Functions

Truetype static

Pillow.ImageFont.Truetype(font, size := 10, index := 0, encoding := "", layoutEngine := unset)

Loads a TrueType/OpenType font. size in points; index selects a face inside a collection; encoding selects a Unicode cmap; layoutEngine accepts Layout.BASIC/Layout.RAQM.

font
Path to a .ttf/.otf/.ttc file or a file handle; missing files raise cannot open resource.

Returns: a FreeTypeFont object.

LoadPath / Load static

Pillow.ImageFont.LoadPath(filename)   ;  alias: Load(filename), load_path(filename)

Loads a font from a path (like Pillow's load_path).

LoadDefault static

Pillow.ImageFont.LoadDefault()   ;  alias: load_default()

Loads Pillow's default bitmap font.

Boundary: the bundled default font differs from Pillow's Aileron (the runtime ships its own default glyph set), so default-font metrics match in shape but not byte-for-byte; drawing text with the default font uses the native seams. See Boundaries.

The FreeTypeFont Object

GetMetrics

font.GetMetrics()

Returns a Map with the face metrics: ascent, descent (pixels, FreeType rule).

GetName

font.GetName()

Returns the font family name (e.g. "DejaVu Sans").

GetLength

font.GetLength(text, mode := "", direction := unset, features := unset, language := unset)

Returns the advance width of the text in pixels. Multi-line text follows Pillow's longest-line rule.

GetBbox

font.GetBbox(text, anchor := unset, mode := "", direction := unset, features := unset, language := unset, strokeWidth := 0)

Returns the ink bounding box [left, top, right, bottom] relative to the anchor; strokeWidth expands the box like Pillow.

Facade note: anchor is the positional second parameter here (Pillow passes it second-to-last); mode/direction/features/language are accepted-and-ignored. Anchor math replicates Pillow's exact em-box rules (horizontal m → center, r → right edge; vertical a → 0, t → ink top, m → center, s/b → ink bottom, d → descent).

GetMask

font.GetMask(text, mode := "", ink := 0, direction := unset, features := unset, language := unset, strokeWidth := 0, anchor := unset, start := unset)

Renders the text to an Image: mode ""/"L"/"1"/unknown → L (mode "1" with mono-rounded metrics); "RGBA" → RGBA whose alpha scales with ink.

Boundaries: glyphs are GDI-rasterized (gray8 ink values are the documented rasterizer divergence); strokeWidth/anchor/start are accepted-and-ignored (FreeType-stroke boundary).

GetMask2

font.GetMask2(text, mode := "", ink := 0, args*)

Pillow's getmask2: returns [mask, offset] where offset is the bbox top-left corner.

FontVariant

font.FontVariant(font := unset, size := unset, index := unset, encoding := unset, layoutEngine := unset)

Returns a copy of the font with overridden attributes (Pillow's font_variant).

GetVariationAxes

font.GetVariationAxes()   ;  alias: get_variation_axes()

Returns the variable-font fvar axes as an array of Maps: name (bytes), minimum, default, maximum.

GetVariationNames

font.GetVariationNames()   ;  alias: get_variation_names()

Returns the named instances (e.g. "Regular", "Bold") as an array of byte strings.

SetVariationByAxes

font.SetVariationByAxes(axes)   ;  alias: set_variation_by_axes()

Sets the variation coordinates from an array of per-axis values (exact length required).

Parity: the full engine is replicated — avar segment maps, HVAR item variation stores (format 0/1, FreeType's region scalars) and per-glyph advance deltas through 26.6 arithmetic; error shapes match Pillow (argument must be a list, non-variable invalid argument OSError).

SetVariationByName

font.SetVariationByName(name)   ;  alias: set_variation_by_name()

Selects a named instance.

Parity: unknown names raise Pillow's exact b'<name>' is not in list.

TransposedFont & Layout

TransposedFont class

Pillow.ImageFont.TransposedFont(font, orientation := unset)

Wraps a font with an EXIF orientation; exposes GetMask, GetBbox, GetLength (orientation storage, the exact (0, 0, w, h) getbbox normalization with the 90/270 width/height swap, getlength delegation).

Parity: 90/270 GetLength raises text length is undefined for text rotated by 90 or 270 degrees.

Layout constants

Pillow.ImageFont.Layout.BASIC := 0
Pillow.ImageFont.Layout.RAQM   := 1

Layout engine constants; RAQM is accepted but the runtime is a no-libraqm build (text-direction options raise Pillow's KeyError shape).

Internal helpers

CheckStringLength (rejects over-long text with Pillow's error), LoadDefaultImagefont (loads the bundled default bitmap font) and ResolveWindowsFont (Windows font-path resolution) are facade internals — public for the facade's own use, not part of the Pillow-style user API. On FreeTypeFont, Close, RequireHandle, DuplicateHandle and IsVariable are the native-handle lifecycle helpers behind the public surface.

Examples

Load a variable font, measure and render:

font := Pillow.ImageFont.Truetype("C:\Windows\Fonts\bahnschrift.ttf", 24)
axes := font.GetVariationAxes()          ;  e.g. [{"name": b"wght", "minimum": 300, ...}]
font.SetVariationByName("Bold")
mask := font.GetMask2("Hi")              ;  [L-image, offset]
bb   := font.GetBbox("Hi")               ;  [left, top, right, bottom]
len  := font.GetLength("Hi")
