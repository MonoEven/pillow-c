Pillow entry class

The Pillow class is the facade root: it hosts the module classes (Image, ImageDraw, …), the constant enums, and the DLL plumbing.

Configure static

Pillow.Configure(options := unset)

Configures the facade. Options: DllPath (path to pillow_c.dll). Call once before using any image API.

Pillow.Configure({ DllPath: A_ScriptDir "\build\x64\Release\pillow_c.dll" })

AbiVersion static

Pillow.AbiVersion()

Returns the DLL ABI version number.

CheckStatus / StatusMessage static

Pillow.CheckStatus(statusCode)      ;  raises on error statuses
Pillow.StatusMessage(statusCode)    ;  status text

CheckStatus converts a native status code (PILLOW_C_OK=0, NULL_POINTER=-1, INVALID_LENGTH=-2, INVALID_ARGUMENT=-3, ALLOCATION_FAILED=-4) into a thrown Error or no-op; StatusMessage returns the human-readable text.

ModeId / ModeName static

Pillow.ModeId(modeName)   ;  "L" → 8, "RGB" → 3, "RGBA" → 4, "I" → 8(int), "F" → 9, ...
Pillow.ModeName(mode)     ;  reverse mapping

Convert between mode strings and native mode ids.

RequireDllPath / EnsureDllLoaded / WrapImageHandle static

Pillow.RequireDllPath()              ;  configured DLL path (or raises)
Pillow.EnsureDllLoaded()              ;  loads the DLL once
Pillow.WrapImageHandle(handle)        ;  native handle → Pillow.Image

Internal plumbing: resolve/load the DLL and wrap a native image handle into a managed Image object.
