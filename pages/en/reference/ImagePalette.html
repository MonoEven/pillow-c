ImagePalette module

The ImagePalette module stores a palette as a flat byte sequence and provides palette builders and index lookups, matching Pillow 11.3.0's PIL.ImagePalette. The palette sequence is stored as an AHK Array (Pillow accepts any int sequence), and the lazy Colors map uses comma-joined string keys because AHK Map keys are identity-compared (no tuple keys).

Surface notes: Pillow.ImagePalette(...) constructs an instance (Pillow's ImagePalette.ImagePalette class). Random() shares Pillow's shape and value range but not its Mersenne-Twister stream; Load() and the PaletteFile/GimpPaletteFile/GimpGradientFile parser classes are documented fail-loud boundaries — see Boundaries.

Class & Fields

ImagePalette class

Pillow.ImagePalette(mode := "RGB", palette := unset)

Constructs a palette. mode is the channel layout string ("RGB", "RGBA", …); palette is an optional flat byte Array (defaults to empty). This facade's constructor omits Pillow's trailing size argument — palette.Length is the single source of truth for the byte count.

mode
Channel layout string; defaults to "RGB".
palette
Optional flat int sequence; unset gives an empty palette.

Returns: an ImagePalette instance.

Instance Methods

Copy

palette.Copy()

Returns an independent copy (mode, rawmode, a cloned byte array, and the dirty flag).

Returns: a new ImagePalette.

GetData

palette.GetData()

Returns [Rawmode, Palette] when raw, otherwise [Mode, ToBytes()] (Pillow's getdata shape).

Returns: [modeString, data].

ToBytes / Tostring

palette.ToBytes()
palette.Tostring()   ;  alias of ToBytes (Pillow's tostring)

Serializes the palette entries to a Buffer of bytes. A raw palette (Rawmode set) raises Pillow's exact palette contains raw palette data.

Returns: a byte Buffer.

Save

palette.Save(fp)

Writes a Pillow-style palette file: a # Palette header, a # Mode: … line, then 256 indexed lines (missing entries padded with 0). fp must be a file path string.

Returns: nothing (writes the file).

GetColor

palette.GetColor(color, image := unset)

Returns the palette index for a color, allocating a new entry when needed (Pillow's getcolor). color is a channel array such as [255, 0, 0]. In RGB mode a 4-element color must have alpha 255 (else cannot add non-opaque RGBA color to RGB palette); in RGBA mode a 3-element color gets alpha 255 appended. A raw palette (Rawmode set) raises palette contains raw palette data.

color
Channel array (3 or 4 elements).
image
Optional image whose Info background/transparency indices are skipped as specials.

Returns: the palette index (0–255).

Fun parity fact: the oracle-verified GetColor allocation sequence for a reference input is [1, 4, 15, 5, 18, 6, 21] — Pillow hard-codes //3 regardless of mode and skips the image's background/transparency specials, both mirrored exactly. Exceeding 255 distinct colors with no free histogram slot raises cannot allocate more than 256 colors.

Module Palette Builders

Random static

Pillow.ImagePalette.Random(mode := "RGB")

Builds a 256-entry palette of random channel values in 0–255. Shape and range match Pillow; the exact stream differs (documented boundary).

Returns: a new ImagePalette.

Boundary: Pillow uses Python's global Mersenne-Twister stream; this runtime uses AHK's own RNG with the same shape/range. See Boundaries.

Raw static

Pillow.ImagePalette.Raw(rawmode, data)

Wraps raw palette bytes: sets Rawmode, stores data as the byte array, and marks the palette dirty. A raw palette cannot be serialized or color-looked-up.

Returns: a raw ImagePalette.

Negative static

Pillow.ImagePalette.Negative(mode := "RGB")

Builds a palette whose channels run from the maximum value downward (the inverse of the standard ramp).

Returns: a new ImagePalette.

Sepia static

Pillow.ImagePalette.Sepia(white := "#fff0c0")

Builds a sepia-tinted palette by scaling three linear LUTs to the given white color (Pillow's default warm white).

Returns: an "RGB" ImagePalette.

Wedge static

Pillow.ImagePalette.Wedge(mode := "RGB")

Builds a grayscale ramp palette: each 256-entry index repeats across the mode's channels.

Returns: a new ImagePalette.

MakeLinearLut static

Pillow.ImagePalette.MakeLinearLut(black, white)

Builds a 256-entry linear LUT from black to white. A non-zero black raises unavailable when black is non-zero (Pillow's exact message).

Returns: a 256-element int Array.

MakeGammaLut static

Pillow.ImagePalette.MakeGammaLut(exp)

Builds a 256-entry gamma LUT: round((i / 255) ** exp * 255) for each index i.

Returns: a 256-element int Array.

Load Boundary

Load static

Pillow.ImagePalette.Load(filename)

Loads a GIMP palette, GIMP gradient, or Teragon-style palette file via the three-way fallback chain (GimpPaletteFile → GimpGradientFile → PaletteFile). A missing file raises [Errno 2] No such file or directory: '…'; when every parser rejects the content, the chain raises Pillow's exact cannot load palette.

filename
Path to a palette/gradient file.

Returns: [bytes, rawmode] ("RGB" or "RGBA").

Boundary: the PaletteFile/GimpPaletteFile/GimpGradientFile parser classes are not exposed as classes — only Load's fallback chain and its internal helpers exist. Gradient non-RGB color spaces (cannot handle HSV colour space) and short segment lines (list index out of range) escape unwrapped, matching Pillow. See Boundaries.

Examples

Attach a Wedge grayscale palette to a P-mode image:

pal := Pillow.ImagePalette.Wedge("RGB")   ; 256 grayscale steps
img := Pillow.Image.New("P", [256, 16])
img.PutPalette(pal.ToBytes(), "RGB")
img.Save("wedge.png")
img.Close()
