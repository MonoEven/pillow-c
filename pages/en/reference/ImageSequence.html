ImageSequence module

The ImageSequence module iterates over the frames of a multi-frame image (GIF, TIFF, ICO, …). Pillow's Python generator is materialized as an AHK array by AllFrames: one call returns every frame as a list instead of a lazy iterator.

AllFrames static

Pillow.ImageSequence.AllFrames(im, fn := unset)

Returns an AHK array with one Image per frame of im. im may be a single Pillow.Image or an array of images. Each element is an independent copy (frame.Copy()), so modifying a returned frame leaves the source untouched.

im
A Pillow.Image, or an array of images to iterate.
fn
Optional callable; when set, each frame is mapped through fn.Call(frame) and the mapped array is returned.

Returns: an array of frame copies (or the mapped array when fn is given).

Iterating an animation does not disturb the source's seek position: the frame index is restored afterwards (finally { image.Seek(current) }). When the format provides it (e.g. GIF), each copied frame carries per-frame Info such as duration, loop, background, and comment.

all_frames static

Pillow.ImageSequence.all_frames(im, fn := unset)

snake_case alias of AllFrames, mirroring Pillow's ImageSequence.all_frames name.

Iterator class

Pillow.ImageSequence.Iterator(image)

A stateful frame iterator over a single image. Unlike AllFrames, it seeks the image directly and yields the same Image object (no copy), so it advances the source's frame position as it goes.

Also exposes the __Item[index] getter (delegates to GetFrame) and the static helper IsEndError(err), which recognizes Pillow's attempt to seek outside sequence / no more images in file messages.

__New constructor

Pillow.ImageSequence.Iterator.__New(image)

Creates an iterator over image (must be a Pillow.Image), storing it and resetting the loop position to 0.

Raises im must have seek method when the argument is not a Pillow.Image.

__Enum method

Pillow.ImageSequence.Iterator.__Enum(varCount)

AHK for-loop protocol. Supports one loop variable (the frame) or two (index and frame); any other count raises.

GetFrame method

Pillow.ImageSequence.Iterator.GetFrame(index)

Seeks the underlying image to index and returns it. index must be an integer; seeking past the end raises end of sequence.

SeekForIteration method

Pillow.ImageSequence.Iterator.SeekForIteration(index)

Seeks to index and returns true, or false once the end of the sequence is reached. Used internally by __Enum.

Examples

Save every frame of an animated GIF as separate PNGs:

im := Pillow.Image.Open("animation.gif")
frames := Pillow.ImageSequence.AllFrames(im)   ;  array of independent copies
for i, frame in frames
    frame.Save("frame_" i ".png")
for frame in frames
    frame.Close()
im.Close()
