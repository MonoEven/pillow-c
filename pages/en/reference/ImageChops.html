ImageChops module

The ImageChops module contains channel ("chops") operations — arithmetic, bitwise, and blend operations on images. Binary operations require both images to share the same mode and size, and every function returns a new Image while leaving its inputs unchanged (Pillow semantics).

Naming: primary names are PascalCase. AHK method lookup is case-insensitive, so Pillow's underscore-free snake_case names (blend, difference, multiply, lighter, …) resolve to the same methods automatically; the seven underscore forms — add_modulo, hard_light, logical_and, logical_or, logical_xor, soft_light, subtract_modulo — are declared as explicit aliases.

Parity: for binary ops a mode/size mismatch raises Pillow's status error; when both operands are I or F mode the error surfaces as Pillow's exact image has wrong mode.

Unary Operations

Constant static

Pillow.ImageChops.Constant(image, value)

Returns an image with the same mode and size as image, filled with a single value.

value
Integer fill value; a non-integer raises Pillow.ImageChops.Constant value must be an integer.

Returns: a new Image.

Duplicate static

Pillow.ImageChops.Duplicate(image)

Returns a full copy of the image (Pillow's ImageChops.duplicate, equivalent to image.Copy()).

Returns: a new Image.

Invert static

Pillow.ImageChops.Invert(image)

Inverts each pixel: out = MAX − a, where MAX is the maximum value of the mode (255 for L/RGB, 1 for mode "1", …).

Returns: a new Image.

Offset static

Pillow.ImageChops.Offset(image, xoffset, yoffset := unset)

Shifts the image by (xoffset, yoffset) pixels; the emptied region is filled with 0. When yoffset is omitted it defaults to xoffset.

xoffset / yoffset
Integer pixel offsets (positive shifts right/down); non-integers raise a validation error.

Returns: a new Image.

Arithmetic

Add static

Pillow.ImageChops.Add(left, right, scale := 1.0, offset := 0)

Adds two images: out = (left + right) / scale + offset.

scale / offset
Numeric divisor and addend; non-numeric values raise a validation error.

Returns: a new Image.

Subtract static

Pillow.ImageChops.Subtract(left, right, scale := 1.0, offset := 0)

Subtracts two images: out = (left − right) / scale + offset.

scale / offset
Numeric divisor and addend; non-numeric values raise a validation error.

Returns: a new Image.

AddModulo static

Pillow.ImageChops.AddModulo(left, right)

Adds two images and wraps the result around the mode's range (modulo 256 for 8-bit modes).

Returns: a new Image.

SubtractModulo static

Pillow.ImageChops.SubtractModulo(left, right)

Subtracts two images and wraps the result around the mode's range (modulo 256 for 8-bit modes).

Returns: a new Image.

Difference static

Pillow.ImageChops.Difference(left, right)

Absolute per-pixel difference: out = abs(left − right).

Returns: a new Image.

Multiply static

Pillow.ImageChops.Multiply(left, right)

Multiplies two images: out = left * right / 255.

Returns: a new Image.

Screen static

Pillow.ImageChops.Screen(left, right)

Screen blend: out = 255 − ((255 − left) * (255 − right) / 255).

Returns: a new Image.

Blend Modes

Blend static

Pillow.ImageChops.Blend(left, right, alpha)

Linear interpolation between two same-size images: out = left * (1 − alpha) + right * alpha. Delegates to Pillow.Image.Blend.

alpha
Number in 0.0…1.0; 0 returns left, 1 returns right.

Returns: a new Image.

Composite static

Pillow.ImageChops.Composite(image1, image2, mask)

Copies image1 where mask is 255 and image2 where it is 0; intermediate mask values are not blended (unlike Blend). Delegates to Pillow.Image.Composite.

mask
A 1/L/LA/RGBA mode image; any other mode raises bad transparency mask.

Returns: a new Image.

Darker static

Pillow.ImageChops.Darker(left, right)

Per-pixel minimum: out = min(left, right).

Returns: a new Image.

Lighter static

Pillow.ImageChops.Lighter(left, right)

Per-pixel maximum: out = max(left, right).

Returns: a new Image.

Overlay static

Pillow.ImageChops.Overlay(left, right)

Overlay blend: Screen for bright values and Multiply for dark ones, combining the two images.

Returns: a new Image.

SoftLight static

Pillow.ImageChops.SoftLight(left, right)

Soft-light blend using Pillow's standard formula (a gentler version of HardLight).

Returns: a new Image.

HardLight static

Pillow.ImageChops.HardLight(left, right)

Hard-light blend using Pillow's standard formula: like Overlay but with the operands swapped.

Returns: a new Image.

Logical Operations

The logical operations work on mode-"1" images (0 / 255): each applies the bitwise operation per pixel, then yields 255 where the result is nonzero and 0 otherwise.

LogicalAnd static

Pillow.ImageChops.LogicalAnd(left, right)

Bitwise AND: 255 where left & right is nonzero, else 0.

Returns: a new Image.

LogicalOr static

Pillow.ImageChops.LogicalOr(left, right)

Bitwise OR: 255 where left | right is nonzero, else 0.

Returns: a new Image.

LogicalXor static

Pillow.ImageChops.LogicalXor(left, right)

Bitwise XOR: 255 where left ^ right is nonzero, else 0.

Returns: a new Image.

Examples

Darken two opened images, then take their absolute difference and save it.

img1 := Pillow.Image.Open("photo1.jpg")
img2 := Pillow.Image.Open("photo2.jpg")
dark  := Pillow.ImageChops.Darker(img1, img2)      ; per-pixel min
lite  := Pillow.ImageChops.Lighter(img1, img2)     ; per-pixel max
diff  := Pillow.ImageChops.Difference(img1, img2)  ;  abs(a - b)
diff.Save("diff.png")
img1.Close(), img2.Close(), dark.Close(), lite.Close(), diff.Close()
