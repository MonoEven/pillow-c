ImageColor module

Color-string parsing and color-space conversion, mirroring Pillow's ImageColor. GetRgb parses CSS/SVG color names, #hex strings, and functional rgb()/rgba()/hsl()/hsb()/hsv() strings into RGB(A) arrays; GetColor converts the result to a target image mode; the HSV/HSL helpers replicate Python's colorsys formulas.

Module Functions

GetRgb static

Pillow.ImageColor.GetRgb(color)

Pillow's getrgb: parses a color string into an RGB(A) array. Accepted forms are the 148 CSS/SVG color names (the ColorMap table), #rgb/#rrggbb/#rgba/#rrggbbaa hex strings, and the functional rgb(r, g, b), rgb(r%, g%, b%), rgba(r, g, b, a), hsl(h, s%, l%), and hsb(h, s%, b%)/hsv(h, s%, v%) strings.

color
A color string (lowercased before parsing). A non-string raises Pillow.ImageColor.GetRgb expects a color string; a string over 100 characters raises Pillow's exact color specifier is too long.

Returns: [r, g, b], or [r, g, b, a] for the #rgba/#rrggbbaa/rgba() forms.

Parity: unknown specifiers raise Pillow's exact unknown color specifier: '…' (the quoted text is the lowercased input), and every regex plus the name table match Pillow 11.3.0.

GetColor static

Pillow.ImageColor.GetColor(color, modeName)

Pillow's getcolor: parses color (same accepted forms as GetRgb) and converts the result to modeName.

color
Color string; see GetRgb for accepted forms and errors.
modeName
Target Pillow mode (required, no default): "HSV" converts to an HSV triple; base mode "L" ("1"/"L"/"I"/"F"/"I;16"… and "LA") converts to grayscale; a trailing "A" ("RGBA") appends alpha; otherwise the RGB triple is returned unchanged.

Returns: a grayscale integer for base-L modes (plus alpha as [gray, a] for "LA"); [h, s, v] (0–255) for "HSV"; [r, g, b, a] for "RGBA"; otherwise [r, g, b]. AHK arrays stand in for Pillow's tuples — no packed integer is returned.

Parity: the grayscale coefficient (r*19595 + g*38470 + b*7471 + 0x8000) >> 16 and the trailing-A rule replicate Pillow 11.3.0 exactly.

HlsToRgb static

Pillow.ImageColor.HlsToRgb(h, l, s)

Converts hue/lightness/saturation floats to [r, g, b], replicating Python's colorsys.hls_to_rgb. This is the backend of the hsl() functional string in GetRgb.

h
Hue, 0.0–1.0 (wrapped into range).
l
Lightness, 0.0–1.0.
s
Saturation, 0.0–1.0.

Returns: [r, g, b] integers, 0–255.

HsvToRgb static

Pillow.ImageColor.HsvToRgb(h, s, v)

Converts hue/saturation/value floats to [r, g, b], replicating Python's colorsys.hsv_to_rgb. This is the backend of the hsb()/hsv() functional strings in GetRgb.

h
Hue, 0.0–1.0.
s
Saturation, 0.0–1.0.
v
Value, 0.0–1.0.

Returns: [r, g, b] integers, 0–255.

RgbToHsv static

Pillow.ImageColor.RgbToHsv(rgb)

Converts an [r, g, b] array to [h, s, v] in Pillow's HSV-mode convention (each channel 0–255): Python's colorsys.rgb_to_hsv followed by ×255. This is the backend of GetColor for modeName := "HSV".

rgb
[r, g, b] array, each channel 0–255.

Returns: [h, s, v] integers, each 0–255.

ColorMap static

Pillow.ImageColor.ColorMap()

Returns the named-color table (a static Map): the 148 CSS4/X11 names Pillow supports — the same set as Pillow 11.3.0, including both gray/grey and darkgray/darkgrey spellings — each mapped to a #rrggbb string. Internal: GetRgb looks a name up here, then re-parses the hex value.

Returns: a Map of name → #rrggbb.

HexByte static

Pillow.ImageColor.HexByte(hex)

Internal: parses a 1–2 character hex string into an integer (Integer("0x" hex)).

hex
1–2 lowercase hex characters.

Returns: integer 0–255.

HueToRgb static

Pillow.ImageColor.HueToRgb(m1, m2, h)

Internal: the _v helper from Python's colorsys — the piecewise mixing function used by HlsToRgb.

Examples

Parse names, hex, and HSL, and convert to HSV/gray:

c1   := Pillow.ImageColor.GetRgb("#336699")            ;  [51, 102, 153]
c2   := Pillow.ImageColor.GetRgb("hsl(120, 50%, 50%)") ;  [64, 191, 64]
hsv  := Pillow.ImageColor.HsvToRgb(0, 1, 1)            ;  [255, 0, 0]
gray := Pillow.ImageColor.GetColor("tomato", "L")      ;  142
