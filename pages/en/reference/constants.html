Constants

Enum classes under the Pillow namespace, matching Pillow 11.3.0's constant values exactly.

Transpose

Pillow.Transpose.FLIP_LEFT_RIGHT := 0   ; mirror left-right
Pillow.Transpose.FLIP_TOP_BOTTOM := 1   ; mirror top-bottom
Pillow.Transpose.ROTATE_90 := 2         ; rotate 90° CCW
Pillow.Transpose.ROTATE_180 := 3        ; rotate 180°
Pillow.Transpose.ROTATE_270 := 4        ; rotate 270° CCW
Pillow.Transpose.TRANSPOSE := 5         ; transpose
Pillow.Transpose.TRANSVERSE := 6        ; transverse
