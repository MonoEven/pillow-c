Image module

The Image class is the workhorse of the library: it wraps a native image handle owned by pillow_c.dll and provides Pillow 11.3.0's full object surface — constructors, geometry, pixels, palette, filters, compositing, metadata and save/load. AHK arrays stand in for Python tuples ([width, height], [x, y], [left, upper, right, lower]), unset is the None analogue, errors are thrown as Error objects with Pillow's exact message strings, and Info is a Map.

All methods also exist under their Pillow snake_case names (resize, getbbox, putpixel, …); this page lists the PascalCase primary names.

Most methods return a new Image and leave this one unchanged (Pillow semantics). Operations that mutate in place are marked below.

Constructors & Loading

New static

Pillow.Image.New(modeName, size, color := unset)

Creates a new image of the given mode and size, optionally filled with a single color.

modeName
Mode string: "1", "L", "P", "RGB", "RGBA", "CMYK", "I", "F", "I;16", …
size
Array [width, height] in pixels.
color
Fill color: a name string, a #rgb/#rrggbb string, an integer (L/I), a float (F) or an array per band.

Returns: a new Image.

Open static

Pillow.Image.Open(path, formats := unset)

Opens and identifies an image file, decoding it lazily like Pillow (full decode happens on demand). Formats are detected by content, not by extension.

path
Filesystem path to the image file.
formats
Optional list of format names or MIME types to try first (Pillow's formats argument).

Returns: a new Image.

Parity: raises FileNotFoundError for missing files and Pillow's quoted UnidentifiedImageError for unrecognized content; WebP/AVIF/JPEG2000 content raises the exact decoder … not available (see Boundaries).

FromBytes static

Pillow.Image.FromBytes(modeName, size, bytes, decoder := unset, rawmode := unset, stride := 0, orientation := 1)

Builds an image from raw pixel bytes in memory (Pillow's Image.frombytes).

modeName
Mode string.
size
Array [width, height].
bytes
Buffer of raw pixel data; its length must match the mode/size/stride.
decoder / rawmode
Decoder name and raw mode (e.g. "raw" / "RGB"); default raw.
stride / orientation
Row stride in bytes and storage orientation (1 = top-down).

Returns: a new Image.

FromBuffer static

Pillow.Image.FromBuffer(modeName, size, data, decoder := "raw", rawmode := unset, stride := 0, orientation := 1)

Identical to FromBytes with the decoder defaulting to "raw" (Pillow's Image.frombuffer; Pillow's deprecated-mode warning does not apply here).

Returns: a new Image.

FromBytes (instance) method

image.FromBytes(bytes, decoder := unset, rawmode := unset, stride := 0, orientation := 1)

Loads pixel data from raw bytes into this image's storage.

Returns: this image (mutates in place).

Load method

image.Load()

Allocates pixel storage and decodes the file data (Pillow's load()). The facade decodes on demand, so this is usually implicit.

Returns: a PixelAccess object.

PixelAccess class

Pillow.Image.PixelAccess(image)
pa[x, y]          ;  read  — GetPixel([x, y])
pa[x, y] := value ;  write — PutPixel([x, y], value)

Pillow's pixel-access object: indexing with [x, y] reads/writes one pixel through GetPixel/PutPixel, including negative-coordinate wrapping and float truncation.

Merge static

Pillow.Image.Merge(modeName, bands)

Merges single-band images into a new multi-band image (inverse of Split).

modeName
Target mode (e.g. "RGB" for 3 bands, "RGBA" for 4).
bands
Array of single-band Images; the count must match the mode.

Returns: a new Image.

Blend static

Pillow.Image.Blend(left, right, alpha)

Interpolates two same-mode/size images: left * (1 - alpha) + right * alpha.

alpha
Number in 0.0…1.0; 0 returns left, 1 returns right.

Returns: a new Image.

Composite static

Pillow.Image.Composite(image1, image2, mask)

Copies image1 where mask is 255 and image2 where mask is 0; intermediate mask values are not blended (unlike Blend).

Returns: a new Image.

AlphaComposite static + method

Pillow.Image.AlphaComposite(dst, src)   ;  static
image.AlphaComposite(image, dest := unset, source := unset)   ;  method

Composites an RGBA source over a destination using alpha: out = src*a + dst*(1-a). The method form supports destination/source offsets.

dest / source
Optional [x, y] offsets; both must be given or both omitted.

Returns: a new Image (method form) / the composited result (static form).

LinearGradient / RadialGradient static

Pillow.Image.LinearGradient(modeName)
Pillow.Image.RadialGradient(modeName)

Returns a 256×256 gradient image. Supported modes: 1, L, P, I, F (multi-character modes raise Pillow's exact image has wrong mode, unknown single-character modes raise unrecognized image mode). Linear: value = y, top to bottom. Radial: value = (int)sqrt(((x−128)²+(y−128)²)×2) clamped at ≥ 255, centre to edge.

Returns: a new Image.

EffectMandelbrot static

Pillow.Image.EffectMandelbrot(size, extent, quality)

Generates a Mandelbrot set image.

size
Array [width, height].
extent
Array [x0, y0, x1, y1] of the complex-plane region.
quality
Integer iteration quality.

Returns: a new Image.

EffectNoise static

Pillow.Image.EffectNoise(size, sigma)

Generates a Gaussian-noise image of the given size.

sigma
Standard deviation of the noise.

Returns: a new Image.

EffectSpread static + method

Pillow.Image.EffectSpread(image, distance)   ;  static
image.EffectSpread(distance)                  ;  method

Randomly displaces each pixel within a distance-sized region (Pillow's Image.effect_spread).

Geometry

Crop

image.Crop(box := unset)

Returns a rectangular region defined by a 4-tuple box. Omitting the box uses the bounding box of the non-zero region.

box
[left, upper, right, lower]; coordinates may lie outside the image.

Returns: a new Image.

Parity: box order errors raise Coordinate 'right' is less than 'left' / Coordinate 'lower' is less than 'upper' exactly.

Resize

image.Resize(size, resample := unset, box := unset, reducingGap := unset)

Returns a resized copy. Defaults to Resampling.BICUBIC (Pillow 11.3.0's rule: NEAREST only for BGR; modes).

size
Array [width, height].
resample
Resampling.NEAREST/BOX/BILINEAR/HAMMING/BICUBIC/LANCZOS; invalid values raise Unknown resampling filter (<value>). Use Image.Resampling….
box
Optional source region [left, upper, right, lower].
reducingGap
Downsize in steps of this factor first (Pillow's reducing_gap).

Returns: a new Image.

Parity: RGBA/LA non-NEAREST resizes premultiply by alpha (+127) and keep the premultiplied value where a == 0; mode 1/P force NEAREST; I;16 uses Pillow's 16bpc two-pass sampler; non-NEAREST I;16B raises the documented boundary error.

Thumbnail

image.Thumbnail(size, resample := unset, reducingGap := 2.0)

Modifies this image in place to a thumbnail no larger than size, preserving the aspect ratio.

Returns: nothing (mutates in place).

Reduce

image.Reduce(factor, box := unset)

Returns a copy reduced factor times by block-averaging (integer factor > 0).

Returns: a new Image.

Rotate

image.Rotate(angle, resample := unset, expand := false, center := unset, translate := unset, fillcolor := unset)

Rotates counterclockwise by angle degrees.

expand
True enlarges the output to contain the whole rotated image.
center
Optional rotation center [x, y]; default is the image center.
translate
Optional post-rotate translation [x, y].
fillcolor
Color for areas outside the rotated image.

Returns: a new Image.

Transpose

image.Transpose(method)

Flips or rotates by multiples of 90° using a Transpose constant (FLIP_LEFT_RIGHT, FLIP_TOP_BOTTOM, ROTATE_90/180/270, TRANSPOSE, TRANSVERSE).

Returns: a new Image.

Parity: invalid methods raise No such transpose operation.

Transform

image.Transform(size, method, data, resample := unset, fillcolor := unset)

Applies an affine/extent/perspective/quad/mesh transform (Transform constants; see the ImageTransform page for the data layouts).

size
Output size [width, height].
method
Transform.EXTENT/AFFINE/QUAD/PERSPECTIVE/MESH.
data
Array of numbers (coefficients / corners / mesh triplets).
resample / fillcolor
Resampling filter and background color.

Returns: a new Image.

Draft

image.Draft(mode, size)

Configures the decoder to decode at reduced size (JPEG) or to prepare for a mode conversion; must be called right after opening.

mode
Requested mode.
size
Requested size.

Returns: nothing.

Pixels & Bands

GetPixel / PutPixel

image.GetPixel(xy)        ;  xy = [x, y]
image.PutPixel(xy, value)

Reads/writes one pixel. Coordinates wrap negative values like Pillow (-1 = last pixel) and floats truncate.

value
Integer (L/I), array per band (RGB…), or a color string.

GetPixel returns: pixel value. PutPixel returns: nothing (mutates).

Parity: strings raise an integer is required; out-of-range raises image index out of range.

GetData / PutData

image.GetData(band := unset)
image.PutData(data, scale := 1.0, offset := 0.0)

Bulk pixel read/write. GetData returns an array of 256-entry histograms per band, or the histogram of one band. PutData writes an array of per-band histograms with an optional linear transform.

Returns: array of histograms (GetData) / nothing (PutData).

Fill

image.Fill(color)

Fills the whole image with one color (mutates in place).

Point

image.Point(lut, modeName := unset)

Maps pixels through a lookup table: either one callable per band or a flat LUT array.

lut
Callable(s) or LUT array; entries act as round(src) → dst.
modeName
Optional output mode (e.g. "1" or "L").

Returns: a new Image.

Parity: a short LUT raises wrong number of lut entries; string entries raise type str doesn't define __round__ method.

GetChannel

image.GetChannel(channel)

Returns a copy of one channel as an L image. Channel 0 = red (first band); negative indices count from the last band.

Returns: a new L-mode Image.

Split / GetBands / BandNames

image.Split()       ;  array of single-band copies
image.GetBands()    ;  array of channel names, e.g. ["R","G","B"]
image.BandNames()   ;  same as GetBands

Split returns one L copy per band. GetBands/BandNames return the band name list Pillow uses in error messages (["R","G","B"], ["L"], ["C","M","Y","K"]…).

Statistics

Histogram

image.Histogram(mask := unset)

Returns the histogram: one 256-entry list per band, flattened into a single array (Pillow layout).

mask
Optional 1/L-mode mask of the same size; only masked pixels count.

Parity: a non-1/L mask raises bad transparency mask; size mismatches raise images do not match. I;16 histograms keep Pillow's layout-dependent byte misread as a documented boundary.

Entropy

image.Entropy(mask := unset)

Returns the image entropy (in bits per pixel) computed from the histogram.

GetExtrema

image.GetExtrema()

Returns min/max pixel values: for single-band modes (L, I, F, …) a flat [min, max] array; for multi-band modes an array of [min, max] pairs, one per band (Pillow's getextrema shape).

Parity: I;16B raises Pillow's image has wrong mode.

GetBbox

image.GetBbox(alphaOnly := true)

Returns the bounding box of the non-zero region as [left, upper, right, lower]. With alphaOnly := false alpha is ignored; an all-zero image returns None (unset).

GetProjection

image.GetProjection()

Returns two per-axis arrays counting non-zero pixels per column (x) and per row (y).

GetColors

image.GetColors(maxcolors := 256)

Returns an array of [count, color] pairs of the most frequent colors, or None (unset) above maxcolors.

Palette & Quantize

GetPalette / PutPalette

image.GetPalette(rawmode := "RGB")
image.PutPalette(data, rawmode := "RGB")

Reads/writes the palette of a P-mode image. GetPalette returns the raw palette bytes (768 for RGB); PutPalette attaches a new palette.

Quantize

image.Quantize(colors := 256, method := unset, kmeans := 0, palette := unset, dither := unset)

Converts the image to P mode with at most colors colors.

method
Quantize.MEDIANCUT/MAXCOVERAGE/FASTOCTREE; LIBIMAGEQUANT raises Pillow's exact dependency required by this method was not enabled at compile time.
kmeans
Number of k-means refinement iterations.
palette
Optional palette image to quantize to.
dither
Dither.NONE or Dither.FLOYDSTEINBERG.

Returns: a new P-mode Image.

ApplyTransparency / RemapPalette

image.ApplyTransparency()   ;  image.ApplyTransparency()
image.RemapPalette(destImage)

ApplyTransparency replaces the P-mode transparency color with a real alpha band. RemapPalette remaps this image's colors through another P-mode image's palette.

Compositing

Paste

image.Paste(source, box := unset, mask := unset)

Pastes another image into this one (mutates in place). Box-less pastes require equal sizes; a 2-tuple box places the source's upper-left corner; a 4-tuple box resizes the source first.

mask
Optional 1/L/RGBA mask; 255 = paste, 0 = keep.

PutAlpha

image.PutAlpha(alpha)

Adds or replaces the alpha band from an L-mode image of the same size.

Returns: a new Image.

Conversion & Filters

Convert

image.Convert(modeName := unset, matrixOrDither := unset, dither := unset, palette := unset, colors := unset)

Returns a converted copy. Omitting the mode copies the image (optionally converting the palette to RGBA).

modeName
Target mode; a 4×4 or 4×3 matrix converts to L/RGB (12 values) or RGBA/CMYK (16 values) via matrix · src + offset.
matrixOrDither / dither
Matrix or Dither constant; P→RGB conversions accept dithering.
palette
Target Palette constant or a sequence of colors when converting to P.
colors
Color count for ADAPTIVE palettes (default 256).

Returns: a new Image.

Filter

image.Filter(filter)

Applies an ImageFilter and returns the result. The argument must be an ImageFilter.Filter instance or class.

Parity: other arguments raise filter argument should be ImageFilter.Filter instance or class.

Metadata & Attributes

GetExif / GetXmp

image.GetExif()   ;  an Image.Exif object
image.GetXmp()    ;  XMP metadata map, or None (unset)

GetExif returns an Image.Exif object built from the decoded EXIF data (Pillow's getexif()). GetXmp parses the embedded XMP packet into a nested map (or unset when absent).

Exif class

Pillow.Image.Exif.FromImage(image)
exif.Has(tag)                       ;  tag present?
exif.Get(tag, defaultValue := unset) ;  tag value
exif.Delete(tag)                     ;  remove a tag
exif.ToBytes()                       ;  serialized EXIF blob

Pillow's Exif object: Has/Get/Delete work on EXIF tags; ToBytes serializes back to the TIFF-header EXIF blob. Tag values are stored in the typed Maps (AsciiTags, IntTags, RationalTags, ByteArrayTags, UndefinedTags, …), and Orientation/HasOrientation mirror Pillow's fields.

The typed tag readers (ReadUintTag, ReadAsciiTag, ReadRationalTag, …) and the Normalize*/*TagType helpers are the internal EXIF parsing machinery behind FromImage.

image.GetIm()   ;  native handle
image.Im        ;  same handle

Returns the underlying native image handle (the analogue of Pillow's im ImagingCore object). The native ABI covers the ImagingCore method surface.

Saving & Lifecycle

Save

image.Save(path, format := unset, options := unset)

Saves the image to a file. The format is derived from the extension or given explicitly. Pillow's keyword options map to PascalCase option keys (quality→quality, optimize→optimize, subsampling, dpi, compressLevel, iccProfile, …).

path
Output path (also accepts a file object-like handle).
format
Explicit format name when the extension is ambiguous.
options
Map of encoder options.

Returns: nothing.

ToBytes / ToBitmap

image.ToBytes(encoder := unset, rawmode := unset, orientation := 1)
image.ToBitmap(name := "image")

ToBytes encodes the image to a byte buffer (tobytes). ToBitmap saves a bitmap file usable by AutoHotkey's Gui (name = the file's base name).

Copy

image.Copy()

Returns a full copy of this image (pixels and Info; file data is not duplicated).

Seek / Tell

image.Seek(frame)
image.Tell()   ;  current frame index

Moves between frames of an animated image (GIF, ICO, TIFF, FLI, MNG…). Tell returns the current frame number.

Verify

image.Verify()

Checks the file integrity without decoding pixels; raises on a corrupted file.

Close

image.Close()

Releases the native image handle. The object becomes unusable (Pillow's closed-image error shape).

Show / ToQImage / ToQPixmap

image.Show(title := unset)
image.ToQImage()     ;  alias served by AHK case-insensitivity: toqimage()
image.ToQPixmap()    ;  alias: toqpixmap()

Displays the image with a system viewer, or converts it to a Qt image/pixmap (boundaries in this runtime).

Boundary: the AHK runtime has no viewer registry and no Qt binding, so Show raises Pillow's no viewers found shape and ToQImage/ToQPixmap raise Pillow's exact Qt bindings are not installed instead of launching a viewer or building QImage/QPixmap objects. See Boundaries.

GetChildImages

image.GetChildImages()

Returns sub-images (e.g. ICO sizes) — an empty array for the implemented handles, matching Pillow.

ImagePut interop

Optional bridge to ImagePut. The functions are present in pillow.ahk but only call into ImagePut when the user has #Included ImagePut first; otherwise they raise a clear “requires ImagePut” error.

FromImagePut static

Pillow.Image.FromImagePut(source, mode := "RGBA")

Accepts any ImagePut-compatible input (file path, URL, clipboard, window, screen region, HBitmap, existing ImagePut buffer, ...), converts it through ImagePut's 32-bit ARGB buffer, and returns a new Pillow Image. If mode is not "RGBA", the image is first imported as RGBA and then converted to the requested mode.

Returns: a new Image.

ToImagePut static + method

Pillow.Image.ToImagePut(image)   ;  static
image.ToImagePut()               ;  instance form

Exports a Pillow Image to an ImagePut-compatible buffer object. Non-RGBA images are converted to RGBA internally; ImagePut's buffer is 32-bit ARGB, so this round-trip preserves alpha.

Returns: an ImagePut BitmapBuffer object that can be passed to ImagePut functions such as ImagePutWindow / ImagePutFile.

Examples

Rotate, paste and save (the Pillow tutorial shape):

img := Pillow.Image.Open("photo.jpg")
rot := img.Rotate(45, Pillow.Resampling.BICUBIC, true, , , "white")
rot.Paste(Pillow.Image.New("RGBA", [64, 64], "red"), [10, 10])
rot.Save("out.png")
rot.Close(), img.Close()

Thumbnail + gradient + histogram:

im := Pillow.Image.LinearGradient("L")
im.Thumbnail([128, 128])
hist := im.Histogram()          ;  256 entries for L
thumb := Pillow.Image.Open("big.png")
thumb.Thumbnail([300, 300])
thumb.Save("thumb.png", , Map("optimize", true))
