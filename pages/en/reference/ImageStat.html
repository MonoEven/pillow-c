ImageStat module

The ImageStat module computes per-band statistics from a histogram. Stat wraps either an Image (whose histogram is taken internally) or a precomputed raw histogram list; every statistic is a lazily computed, cached attribute that returns a per-band ARRAY — for an RGB image Mean returns [rMean, gMean, bMean].

Each attribute is computed on first access and cached (Pillow's cached_property); it is a per-band array whose length equals the band count (histogram length // 256).

Construction

Stat class

Pillow.ImageStat.Stat(imageOrList, mask := unset)

Builds a statistics object over an image or a raw histogram list. If a mask is given, only the pixels covered by the mask are counted.

imageOrList
An Image, or a precomputed histogram list whose length must be a multiple of 256 (one 256-bin block per band).
mask
Optional mask image: mode "1" or "L", same size as the image; only masked pixels count. Requires image input — a list plus mask raises Pillow.ImageStat.Stat mask requires image input.

Returns: a new Stat.

Mask parity: a non-1/L mask raises Pillow's exact bad transparency mask; a size mismatch raises images do not match.

Like Pillow, the histogram groups pixels into 256 bins even for more-than-8-bit modes, so I/F mode mean/median/rms top out at 255 and extrema cannot exceed 255 — use image.GetExtrema() for exact per-band extrema. I;16 histograms keep Pillow's layout-dependent byte misread as a documented boundary (see Boundaries).

Global static

Pillow.ImageStat.Global(imageOrList, mask := unset)

Pillow's ImageStat.Global is the plain alias Global = Stat. Because global is a reserved keyword in AutoHotkey, the facade exposes the alias as a static constructor method: it forwards its arguments to Stat and returns the new statistics object.

Returns: a new Stat (identical to Pillow.ImageStat.Stat).

Attributes

Extrema property

stat.Extrema

Min/max values per band: an array of [min, max] pairs — the lowest and highest occupied histogram bins.

Count property

stat.Count

Total number of pixels per band — the sum of the band's 256 histogram bins (integer array).

Sum property

stat.Sum

Sum of pixel values per band: Σ level × count[level] over the band's 256 bins.

Sum2 property

stat.Sum2

Sum of squared pixel values per band: Σ level² × count[level].

Mean property

stat.Mean

Arithmetic mean pixel level per band: sum / count.

Median property

stat.Median

Median pixel level per band, found by walking the cumulative histogram until it exceeds count // 2.

Rms property

stat.Rms

Root-mean-square per band: sqrt(sum2 / count).

Var property

stat.Var

Variance per band: (sum2 − sum² / count) / count.

StdDev property

stat.StdDev

Standard deviation per band: sqrt(var).

Internal helpers

Pillow.ImageStat.StrPut is a buffer-write helper used by the facade; it is not part of the Pillow-style user API.

Examples

Compute and print the mean and standard deviation of an RGB image:

img := Pillow.Image.Open("photo.jpg")    ;  RGB image
st := Pillow.ImageStat.Stat(img)
mean := st.Mean                          ;  [rMean, gMean, bMean]
std  := st.StdDev                        ;  [rStddev, gStddev, bStddev]
txt := ""
loop mean.Length
    txt .= "band " A_Index ": mean=" Round(mean[A_Index], 2)
        .  "  stddev=" Round(std[A_Index], 2) "`n"
MsgBox txt
img.Close()
