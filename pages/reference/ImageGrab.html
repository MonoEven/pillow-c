ImageGrab module

The ImageGrab module captures the screen or the clipboard into an Image. On this facade it is a Windows-only seam backed by the native GDI/BitBlt path (pillow_c_image_grab).

ImageGrab 模块把屏幕或剪贴板内容捕获为 Image。在此 facade 中它是仅限 Windows 的接缝,由原生 GDI/BitBlt 路径(pillow_c_image_grab)支撑。

Grab static

Pillow.ImageGrab.Grab(bbox := unset, includeLayeredWindows := false, allScreens := false)

Captures a screen region as an RGB Image. bbox is a 4-value rectangle in [left, top, right, bottom] order (x1/y1/x2/y2, matching Pillow's Windows grab): the source assigns left/top/right/bottom from bbox[1..4] and rejects right < left or bottom < top.

把屏幕区域捕获为 RGB Image。bbox 是按 [left, top, right, bottom](x1/y1/x2/y2,同 Pillow 的 Windows grab)排列的四值矩形:源码从 bbox[1..4] 取 left/top/right/bottom,并拒绝 right < left 或 bottom < top。

bbox
Optional 4-value [left, top, right, bottom] rectangle; when unset, the whole screen is captured.可选的四值 [left, top, right, bottom] 矩形;unset 时捕获整个屏幕。
includeLayeredWindows
Whether to include layered windows (Windows flag).是否包含分层窗口(Windows 标志)。
allScreens
Capture the virtual desktop spanning all monitors instead of the primary screen.捕获跨所有显示器的虚拟桌面,而非主屏幕。

Returns: an RGB Image of the captured region.返回:捕获区域的 RGB Image。

Without bbox: allScreens := true takes the virtual-screen rectangle from GetSystemMetrics (76/77/78/79); otherwise the primary screen is taken from GetSystemMetrics (0/1) with left/top at 0. Coordinates are the logical pixels those metrics report; a native capture failure (status -3) raises Pillow's screen grab failed.未提供 bbox 时:allScreens := true 取 GetSystemMetrics(76/77/78/79)的虚拟屏幕矩形;否则取 GetSystemMetrics(0/1)的主屏幕,left/top 为 0。坐标为这些度量返回的逻辑像素;原生捕获失败(status -3)抛 Pillow 的 screen grab failed。

GrabClipboard static

Pillow.ImageGrab.GrabClipboard()

Captures an image from the Windows clipboard via pillow_c_image_grab_clipboard. Returns the Image, or 0 (this runtime's None analogue) when the clipboard holds no image.

通过 pillow_c_image_grab_clipboard 从 Windows 剪贴板捕获图像。返回 Image;剪贴板没有图像时返回 0(此运行时的 None 对应物)。

示例 · Examples

Capture the primary screen and a region, then save each as PNG:

捕获主屏幕与一块区域,并分别保存为 PNG:

img := Pillow.ImageGrab.Grab()
img.Save("screenshot.png")
img.Close()

region := Pillow.ImageGrab.Grab([100, 100, 500, 400])   ; [left, top, right, bottom]
region.Save("region.png")
region.Close()
