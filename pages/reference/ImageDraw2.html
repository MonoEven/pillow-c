ImageDraw2 module

The experimental ImageDraw2 module mirrors Pillow's WCK-style pendulum interface: a Pen/Brush pair plus a Draw handle that renders shapes and text onto an image. It is Pillow 11.3.0-compatible under the Pillow. namespace; 0 is the AHK None analogue and unset the "argument not given" sentinel.

实验性的 ImageDraw2 模块镜像 Pillow 的 WCK 风格摆锤接口:由 Pen/Brush 搭配一个 Draw 句柄,把形状与文字渲染到图像上。它在 Pillow. 命名空间下与 Pillow 11.3.0 兼容;0 是 AHK 的 None 对应物,unset 是“未传参”哨兵。

Surface notes: shape rendering resolves a Pen to outline color + width and a Brush to fill color, then delegates to the underlying ImageDraw.Draw handle; the opacity field is stored on Pen/Brush for Pillow parity but is not composited by this facade. Text drawing stays on the documented native draw seam (the API-DRAWFONT-001 boundary).表面说明:形状渲染把 Pen 解析为轮廓色 + 线宽、把 Brush 解析为填充色,然后转交底层 ImageDraw.Draw 句柄;opacity 字段为对齐 Pillow 而存储在 Pen/Brush 上,但本门面不合成它。Text 绘制停留在已记录的原生绘制管线(API-DRAWFONT-001 边界)。

Pen class

Pillow.ImageDraw2.Pen(color, width := 1, opacity := 255)

A stroke (outline) style: a color plus a line width and opacity. The color is resolved through GetRgbColor — color names and #hex strings only; a tuple raises Pillow's exact 'tuple' object has no attribute 'lower' error.

描边(轮廓)样式:颜色加线宽与不透明度。颜色经 GetRgbColor 解析——只接受颜色名与 #hex 字符串;元组抛 Pillow 原样的 'tuple' object has no attribute 'lower' 错误。

color
A color name or #hex string.颜色名或 #hex 字符串。
width
Line width (default 1).线宽(默认 1)。
opacity
Opacity 0–255 (default 255); stored for Pillow parity.不透明度 0–255(默认 255);为对齐 Pillow 而存储。

Brush class

Pillow.ImageDraw2.Brush(color, opacity := 255)

A fill style: a color plus opacity. The color resolves through GetRgbColor exactly like Pen.

填充样式:颜色加不透明度。颜色与 Pen 一样经 GetRgbColor 解析。

color
A color name or #hex string.颜色名或 #hex 字符串。
opacity
Opacity 0–255 (default 255); stored for Pillow parity.不透明度 0–255(默认 255);为对齐 Pillow 而存储。

Font class

Pillow.ImageDraw2.Font(color, file, size := 12)

A text style: a color plus a truetype font loaded via ImageFont.Truetype(file, size).

文字样式:颜色加上经 ImageFont.Truetype(file, size) 加载的 truetype 字体。

color
A color name or #hex string.颜色名或 #hex 字符串。
file
Path to a truetype font file.truetype 字体文件路径。
size
Font size in pixels (default 12).字号(像素,默认 12)。

Draw class

Pillow.ImageDraw2.Draw(image, size := unset, color := unset)

Creates an ImageDraw2 drawing handle over an image. Pass a Pillow.Image, or a mode string together with size (and optional color) to create a new blank image.

在图像上创建 ImageDraw2 绘图句柄。传入 Pillow.Image,或传入模式字符串并搭配 size(以及可选的 color)来新建空白图像。

image
A Pillow.Image, or a mode string (e.g. "RGB").Pillow.Image,或模式字符串(如 "RGB")。
size
Required when image is a mode string; the new image's [width, height].当 image 为模式字符串时必填;新图像的 [width, height]。
color
Optional background color when creating from a mode string.由模式字符串创建时的可选背景色。

Returns: a Draw handle (exposes Image and Draw fields).返回:Draw 句柄(暴露 Image 与 Draw 字段)。

size/color apply only when image is a mode string (they seed Image.New(mode, size, color)); when an actual Image is passed they are ignored.size/color 仅在 image 为模式字符串时生效(它们用于 Image.New(mode, size, color));传入实际 Image 时二者被忽略。

Flush

draw.Flush()

Returns the underlying image (all drawing is in place on it).

返回底层图像(所有绘制都就地作用于它)。

Returns: the Pillow.Image being drawn.返回:被绘制的 Pillow.Image。

Settransform

draw.Settransform(offset)

Applies a pixel offset to subsequent shape and text rendering: (xoffset, yoffset) becomes the affine (1, 0, xoffset, 0, 1, yoffset).

对后续形状与文字渲染应用像素偏移:(xoffset, yoffset) 转换为仿射 (1, 0, xoffset, 0, 1, yoffset)。

offset
A [xoffset, yoffset] pair.[xoffset, yoffset] 坐标对。

Render

draw.Render(op, xy, pen := unset, brush := unset, options := unset)

Low-level dispatcher: resolves pen to outline color + width and brush to fill color, applies the current transform to xy, then calls the underlying ImageDraw.Draw handle for op. The shape methods below delegate here.

底层调度器:把 pen 解析为轮廓色 + 线宽、把 brush 解析为填充色,对 xy 应用当前变换,然后为 op 调用底层 ImageDraw.Draw 句柄。下面的形状方法都转交到这里。

op
Operation name: "arc"|"line"|"chord"|"ellipse"|"pieslice"|"polygon"|"rectangle".操作名:"arc"|"line"|"chord"|"ellipse"|"pieslice"|"polygon"|"rectangle"。
xy
Coordinates for the operation.操作的坐标。
pen
A Pen (outline) or Brush (fill), or unset.Pen(轮廓)或 Brush(填充),或 unset。
brush
A Brush (fill) or Pen (outline), or unset.Brush(填充)或 Pen(轮廓),或 unset。
options
Operation options (e.g. {Start, End} angles).操作选项(如 {Start, End} 角度)。

形状 · Shapes

Each shape takes a Pen (outline) and/or a Brush (fill); Arc/Chord/Pieslice also take start/end angles in degrees. A Pen supplies the outline color and width; a Brush supplies the fill color.

每个形状接收 Pen(轮廓)和/或 Brush(填充);Arc/Chord/Pieslice 还接收以度计的 start/end 角度。Pen 提供轮廓色与线宽;Brush 提供填充色。

Arc / Chord / Pieslice

draw.Arc(xy, pen := unset, start := 0, end := 360, brush := unset)
draw.Chord(xy, pen := unset, start := 0, end := 360, brush := unset)
draw.Pieslice(xy, pen := unset, start := 0, end := 360, brush := unset)

Draws circular segments between start and end degrees. Arc outlines only; chord closes with a line; pieslice closes through the center.

在 start 与 end 度之间绘制圆弧段。Arc 只描边;chord 以弦封闭;pieslice 经圆心封闭成扇形。

draw.Ellipse(xy, pen := unset, brush := unset)

在包围盒 xy 内绘制椭圆。

Line

draw.Line(xy, pen := unset, brush := unset)

沿 [x, y] 点序列绘制折线。

Polygon

draw.Polygon(xy, pen := unset, brush := unset)

Draws a polygon through the given vertices (closed automatically).

沿给定顶点绘制多边形(自动闭合)。

Rectangle

draw.Rectangle(xy, pen := unset, brush := unset)

Draws a rectangle; xy = [left, upper, right, lower].

绘制矩形;xy = [left, upper, right, lower]。

文字 · Text

Text

draw.Text(xy, text, font)

Draws text at xy using a Font (color + truetype font). Requires a Pillow.ImageDraw2.Font.

用 Font(颜色 + truetype 字体)在 xy 处绘制文字。要求 Pillow.ImageDraw2.Font。

Returns: the Draw handle (chainable).返回:Draw 句柄(可链式调用)。

Text drawing delegates to ImageDraw.Text and stays on the documented native draw seam (the API-DRAWFONT-001 boundary).文字绘制转交 ImageDraw.Text,并停留在已记录的原生绘制管线(API-DRAWFONT-001 边界)。

返回文字绘制后的包围盒(转交 ImageDraw.TextBbox)。

Textlength

draw.Textlength(text, font)

返回文字的像素宽度(转交 ImageDraw.TextLength)。

内部辅助 · Internal Helper

GetRgbColor static

Pillow.ImageDraw2.GetRgbColor(color)

Internal helper: resolves a color name or #hex string via ImageColor.GetRgb. Non-string values raise Pillow's exact 'tuple' object has no attribute 'lower' error. Not part of the public drawing surface.

内部辅助:经 ImageColor.GetRgb 解析颜色名或 #hex 字符串。非字符串值抛 Pillow 原样的 'tuple' object has no attribute 'lower' 错误。不属于公开绘图接口。

示例 · Examples

Draw a rectangle with a Pen onto a new image:

用 Pen 在新图像上绘制矩形:

img := Pillow.Image.New("RGB", [200, 120], "white")
d := Pillow.ImageDraw2.Draw(img)
pen := Pillow.ImageDraw2.Pen("red", 3)
d.Rectangle([[20, 20], [180, 100]], pen)
out := d.Flush()          ; the same img
out.Save("draw2.png")
out.Close()
