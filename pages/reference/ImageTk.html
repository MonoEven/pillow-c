ImageTk module

The ImageTk module mirrors Pillow 11.3.0's PIL.ImageTk: Tkinter-compatible image objects (PhotoImage, BitmapImage) used with a Tk Canvas, Label or Button.

ImageTk 模块对应 Pillow 11.3.0 的 PIL.ImageTk:用于 Tk Canvas、Label 或 Button 的 Tkinter 兼容图像对象(PhotoImage、BitmapImage)。

This runtime ships no Tk interpreter, so constructing either class fails loudly with Pillow 11.3.0's exact Too early to create image: no default root window message — the RuntimeError Tkinter raises before a root window exists. See Boundaries.本运行时不含 Tk 解释器,因此构造任一类都显式失败,抛出 Pillow 11.3.0 的原样报错 Too early to create image: no default root window(即根窗口尚不存在时 Tkinter 抛出的 RuntimeError)。见行为边界。

PhotoImage static

Pillow.ImageTk.PhotoImage(image := unset, args*)

Pillow's ImageTk.PhotoImage(image, size=None, **kw) builds a Tkinter-compatible photo image (a Tk PhotoImage) from a Pillow Image, converting modes as Tk requires (e.g. RGBA → P with a transparency index).

Pillow 的 ImageTk.PhotoImage(image, size=None, **kw) 由 Pillow Image 构造 Tkinter 兼容的照片图像(Tk 的 PhotoImage),并按 Tk 的要求转换模式(如 RGBA → 带透明索引的 P)。

image
The Pillow Image to wrap (the only positional argument).要包装的 Pillow Image(唯一的位置参数)。
args*
Additional Tkinter keywords (e.g. size); accepted for signature compatibility and ignored — the constructor fails before they are used.额外的 Tkinter 关键字(如 size);仅为签名兼容而接受并被忽略——构造在用到它们之前即失败。

Boundary: constructing raises Pillow's exact Too early to create image: no default root window. See Boundaries.边界:构造抛 Pillow 原样的 Too early to create image: no default root window。见行为边界。

Pillow's ImageTk.BitmapImage(image, size=None, **kw) builds a Tkinter-compatible bitmap image (a Tk BitmapImage) for a 1-bit (mode "1") Pillow Image.

Pillow 的 ImageTk.BitmapImage(image, size=None, **kw) 为 1 位(模式 "1")Pillow Image 构造 Tkinter 兼容的位图图像(Tk 的 BitmapImage)。

Boundary: constructing raises Pillow's exact Too early to create image: no default root window. See Boundaries.边界:构造抛 Pillow 原样的 Too early to create image: no default root window。见行为边界。

RequireTk static

Pillow.ImageTk.RequireTk()

Internal helper: throws the boundary error Too early to create image: no default root window. Both constructors delegate to it.

内部辅助:抛出边界错误 Too early to create image: no default root window。两个构造函数都委托给它。
