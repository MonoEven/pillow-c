ImageQt module

The ImageQt module mirrors Pillow 11.3.0's PIL.ImageQt: helpers that move pixel data between a Pillow Image and Qt's QImage/QPixmap types as provided by PyQt6 or PySide6.

ImageQt 模块对应 Pillow 11.3.0 的 PIL.ImageQt:在 Pillow Image 与 Qt 的 QImage/QPixmap 类型(由 PyQt6 或 PySide6 提供)之间搬运像素数据的辅助函数。

This runtime ships no Qt binding, so every interop function below fails loudly with Pillow 11.3.0's exact message Qt bindings are not installed — the ImportError Pillow raises when neither PyQt6 nor PySide6 is importable. See Boundaries.本运行时不含 Qt 绑定,因此下方每个互操作函数都显式失败,抛出 Pillow 11.3.0 的原样报错 Qt bindings are not installed(即 PyQt6 与 PySide6 均不可导入时 Pillow 抛出的 ImportError)。见行为边界。

ImageQt static

Pillow.ImageQt.ImageQt(im)

Pillow's ImageQt.ImageQt(im) converts a Pillow Image into a Qt QImage subclass (PyQt6's or PySide6's QImage), sharing the underlying pixel buffer. It is the module's primary interop entry point.

Pillow 的 ImageQt.ImageQt(im) 把 Pillow Image 转换为 Qt 的 QImage 子类(PyQt6 或 PySide6 的 QImage),共享底层像素缓冲,是本模块的主要互操作入口。

im
The Pillow Image to wrap.要包装的 Pillow Image。

Boundary: raises Pillow's exact Qt bindings are not installed. See Boundaries.边界:抛 Pillow 原样的 Qt bindings are not installed。见行为边界。

ToQImage static

Pillow.ImageQt.ToQImage(im)

Pillow's ImageQt.toqimage(im) converts an Image to a Qt QImage in RGBA8888 form, suitable for handing to Qt widgets.

Pillow 的 ImageQt.toqimage(im) 把 Image 转换为 RGBA8888 形态的 Qt QImage,可直接交给 Qt 控件。

im
The Pillow Image to convert.要转换的 Pillow Image。

Boundary: raises Pillow's exact Qt bindings are not installed. See Boundaries.边界:抛 Pillow 原样的 Qt bindings are not installed。见行为边界。

ToQPixmap static

Pillow.ImageQt.ToQPixmap(im)

Pillow's ImageQt.toqpixmap(im) converts an Image to a Qt QPixmap (via toqimage), for drawing onto Qt surfaces.

Pillow 的 ImageQt.toqpixmap(im) 把 Image 转换为 Qt QPixmap(经 toqimage),用于绘制到 Qt 表面上。

im
The Pillow Image to convert.要转换的 Pillow Image。

Boundary: raises Pillow's exact Qt bindings are not installed. See Boundaries.边界:抛 Pillow 原样的 Qt bindings are not installed。见行为边界。

FromQImage static

Pillow.ImageQt.FromQImage(qim)

Pillow's ImageQt.fromqimage(qim) converts a Qt QImage back into a Pillow Image (the reverse of toqimage).

Pillow 的 ImageQt.fromqimage(qim) 把 Qt QImage 转回 Pillow Image(toqimage 的逆操作)。

qim
The Qt QImage to convert.要转换的 Qt QImage。

Boundary: raises Pillow's exact Qt bindings are not installed. See Boundaries.边界:抛 Pillow 原样的 Qt bindings are not installed。见行为边界。

RequireQt static

Pillow.ImageQt.RequireQt()

Internal helper: throws the boundary error Qt bindings are not installed. All four interop functions above delegate to it.

内部辅助:抛出边界错误 Qt bindings are not installed。上述四个互操作函数都委托给它。
