Image module

The Image class is the workhorse of the library: it wraps a native image handle owned by pillow_c.dll and provides Pillow 11.3.0's full object surface — constructors, geometry, pixels, palette, filters, compositing, metadata and save/load. AHK arrays stand in for Python tuples ([width, height], [x, y], [left, upper, right, lower]), unset is the None analogue, errors are thrown as Error objects with Pillow's exact message strings, and Info is a Map.

Image 类是库的核心:它包装由 pillow_c.dll 持有的原生图像句柄,提供 Pillow 11.3.0 的完整对象表面——构造、几何变换、像素、调色板、滤镜、合成、元数据与存取。AHK 数组对应 Python 元组([宽, 高]、[x, y]、[left, upper, right, lower]),unset 对应 None,错误以携带 Pillow 原始报错文本的 Error 抛出,Info 为 Map。

All methods also exist under their Pillow snake_case names (resize, getbbox, putpixel, …); this page lists the PascalCase primary names.所有方法同时提供 Pillow 的 snake_case 别名(resize、getbbox、putpixel……);本页按 PascalCase 主名列示。

Most methods return a new Image and leave this one unchanged (Pillow semantics). Operations that mutate in place are marked below.多数方法返回新 Image 且不改动本对象(Pillow 语义);就地修改的操作在下方单独标注。
