ImageColor module

Color-string parsing and color-space conversion, mirroring Pillow's ImageColor. GetRgb parses CSS/SVG color names, #hex strings, and functional rgb()/rgba()/hsl()/hsb()/hsv() strings into RGB(A) arrays; GetColor converts the result to a target image mode; the HSV/HSL helpers replicate Python's colorsys formulas.

颜色字符串解析与色彩空间转换,对应 Pillow 的 ImageColor。GetRgb 把 CSS/SVG 颜色名、#hex 字符串以及函数式 rgb()/rgba()/hsl()/hsb()/hsv() 字符串解析为 RGB(A) 数组;GetColor 再把结果转换为目标图像模式;HSV/HSL 辅助函数复刻 Python colorsys 的公式。

模块函数 · Module Functions

GetRgb static

Pillow.ImageColor.GetRgb(color)

Pillow's getrgb: parses a color string into an RGB(A) array. Accepted forms are the 148 CSS/SVG color names (the ColorMap table), #rgb/#rrggbb/#rgba/#rrggbbaa hex strings, and the functional rgb(r, g, b), rgb(r%, g%, b%), rgba(r, g, b, a), hsl(h, s%, l%), and hsb(h, s%, b%)/hsv(h, s%, v%) strings.

Pillow 的 getrgb:把颜色字符串解析为 RGB(A) 数组。接受的格式包括 148 个 CSS/SVG 颜色名(即 ColorMap 表)、#rgb/#rrggbb/#rgba/#rrggbbaa 十六进制串,以及函数式 rgb(r, g, b)、rgb(r%, g%, b%)、rgba(r, g, b, a)、hsl(h, s%, l%) 与 hsb(h, s%, b%)/hsv(h, s%, v%) 串。

color
A color string (lowercased before parsing). A non-string raises Pillow.ImageColor.GetRgb expects a color string; a string over 100 characters raises Pillow's exact color specifier is too long.颜色字符串(解析前转小写)。非字符串抛 Pillow.ImageColor.GetRgb expects a color string;超过 100 字符抛 Pillow 原样的 color specifier is too long。

Returns: [r, g, b], or [r, g, b, a] for the #rgba/#rrggbbaa/rgba() forms.返回:[r, g, b];#rgba/#rrggbbaa/rgba() 形式返回 [r, g, b, a]。

Parity: unknown specifiers raise Pillow's exact unknown color specifier: '…' (the quoted text is the lowercased input), and every regex plus the name table match Pillow 11.3.0.对齐:未知字符串抛 Pillow 原样的 unknown color specifier: '…'(引号内为转小写后的输入),且每条正则与名称表均与 Pillow 11.3.0 一致。

GetColor static

Pillow.ImageColor.GetColor(color, modeName)

Pillow's getcolor: parses color (same accepted forms as GetRgb) and converts the result to modeName.

Pillow 的 getcolor:解析 color(接受与 GetRgb 相同的格式)并把结果转换为 modeName。

color
Color string; see GetRgb for accepted forms and errors.颜色字符串;接受的格式与报错见 GetRgb。
modeName
Target Pillow mode (required, no default): "HSV" converts to an HSV triple; base mode "L" ("1"/"L"/"I"/"F"/"I;16"… and "LA") converts to grayscale; a trailing "A" ("RGBA") appends alpha; otherwise the RGB triple is returned unchanged.目标 Pillow 模式(必填,无默认值):"HSV" 转换为 HSV 三元组;基模式 "L"("1"/"L"/"I"/"F"/"I;16"… 与 "LA")转换为灰度;末尾 "A"("RGBA")追加 alpha;否则原样返回 RGB 三元组。

Returns: a grayscale integer for base-L modes (plus alpha as [gray, a] for "LA"); [h, s, v] (0–255) for "HSV"; [r, g, b, a] for "RGBA"; otherwise [r, g, b]. AHK arrays stand in for Pillow's tuples — no packed integer is returned.返回:基 L 模式为灰度整数("LA" 时为 [gray, a]);"HSV" 为 [h, s, v](0–255);"RGBA" 为 [r, g, b, a];否则为 [r, g, b]。AHK 数组对应 Pillow 的元组——不返回打包整数。

Parity: the grayscale coefficient (r*19595 + g*38470 + b*7471 + 0x8000) >> 16 and the trailing-A rule replicate Pillow 11.3.0 exactly.对齐:灰度系数 (r*19595 + g*38470 + b*7471 + 0x8000) >> 16 与末尾 A 规则与 Pillow 11.3.0 完全一致。

HlsToRgb static

Pillow.ImageColor.HlsToRgb(h, l, s)

Converts hue/lightness/saturation floats to [r, g, b], replicating Python's colorsys.hls_to_rgb. This is the backend of the hsl() functional string in GetRgb.

把色相/明度/饱和度浮点数转换为 [r, g, b],复刻 Python 的 colorsys.hls_to_rgb。这是 GetRgb 中 hsl() 函数式字符串的后端。

Hue, 0.0–1.0 (wrapped into range).色相,0.0–1.0(越界时回绕)。
l
Lightness, 0.0–1.0.明度,0.0–1.0。
s
Saturation, 0.0–1.0.饱和度,0.0–1.0。

Returns: [r, g, b] integers, 0–255.返回:[r, g, b] 整数,0–255。

RgbToHsv static

Pillow.ImageColor.RgbToHsv(rgb)

Converts an [r, g, b] array to [h, s, v] in Pillow's HSV-mode convention (each channel 0–255): Python's colorsys.rgb_to_hsv followed by ×255. This is the backend of GetColor for modeName := "HSV".

把 [r, g, b] 数组转换为 Pillow HSV 模式约定的 [h, s, v](各通道 0–255):即 Python 的 colorsys.rgb_to_hsv 再 ×255。这是 GetColor 在 modeName := "HSV" 时的后端。

rgb
[r, g, b] array, each channel 0–255.[r, g, b] 数组,各通道 0–255。

Returns: [h, s, v] integers, each 0–255.返回:[h, s, v] 整数,各 0–255。

ColorMap static

Pillow.ImageColor.ColorMap()

Returns the named-color table (a static Map): the 148 CSS4/X11 names Pillow supports — the same set as Pillow 11.3.0, including both gray/grey and darkgray/darkgrey spellings — each mapped to a #rrggbb string. Internal: GetRgb looks a name up here, then re-parses the hex value.

返回命名颜色表(静态 Map):Pillow 支持的 148 个 CSS4/X11 颜色名——与 Pillow 11.3.0 同一集合,含 gray/grey 与 darkgray/darkgrey 两种拼写——每个映射到 #rrggbb 字符串。内部:GetRgb 在此查名,再重新解析十六进制值。

Returns: a Map of name → #rrggbb.返回:名称 → #rrggbb 的 Map。
