ImageDraw module

The ImageDraw module provides 2-D drawing onto an Image: Draw(image) returns a drawing handle whose methods mutate the image in place, exactly like Pillow's ImageDraw.Draw. All coordinates use the Image coordinate system (origin top-left). Snake_case aliases exist for every method (rounded_rectangle, multiline_text, …).

ImageDraw 模块提供图像上的 2D 绘图:Draw(image) 返回绘图句柄,其方法与 Pillow 的 ImageDraw.Draw 一样就地修改图像。所有坐标沿用 Image 坐标系(原点左上)。每个方法都有 snake_case 别名(rounded_rectangle、multiline_text……)。

Surface notes: Pillow's Draw.shape() is not exposed on the handle, the instance form of flood fill is the module-level Floodfill(), and the deprecated textsize()/multiline_textsize() are superseded by TextLength()/TextBbox().表面说明:句柄上不暴露 Pillow 的 Draw.shape();泛洪填充的实例形式即模块级 Floodfill();已弃用的 textsize()/multiline_textsize() 由 TextLength()/TextBbox() 取代。

模块函数 · Module Functions

Draw static

Pillow.ImageDraw.Draw(image)   ; alias: getdraw(image)

Creates a drawing handle for the given image. The handle exposes the Image field (the image being drawn).

为给定图像创建绘图句柄。句柄暴露 Image 字段(被绘制的图像)。

Returns: a DrawHandle object.返回:DrawHandle 对象。

Floodfill static

Pillow.ImageDraw.Floodfill(image, xy, value, border := unset, thresh := 0.0)

Fills the connected region around xy whose color distance from the seed is at most thresh; with a border, fills until pixels of the border color.

填充 xy 周围与种子色差不超过 thresh 的连通区域;给定 border 时填充到边框色为止。

value
Fill color.填充色。
border
Optional border color (same shape as value).可选边框色(与 value 同形态)。
thresh
Max color-distance threshold (float).最大色差阈值(浮点)。

Returns: nothing (mutates in place).返回:无(就地修改)。

Parity: numeric modes keep Pillow's exact scalar/tuple/border/threshold semantics, including I/F tuple values (color must be int or single-element tuple, must be real number, not tuple), incomparable tuple borders, and NaN/±∞ thresholds.对齐:数值模式完整复刻 Pillow 的标量/元组/边框/阈值语义,包括 I/F 元组值(color must be int or single-element tuple、must be real number, not tuple)、不可比较的元组边框与 NaN/±∞ 阈值。

形状绘制 · Shapes

Rectangle

handle.Rectangle(box, fill := unset, outline := unset, width := 1)

Draws a rectangle. Box = [left, upper, right, lower]; outline draws only the border of the given width.

绘制矩形。box = [left, upper, right, lower];outline 只描指定宽度的边框。

RoundedRectangle

handle.RoundedRectangle(box, radius := 0, fill := unset, outline := unset, width := 1, corners := unset)

Draws a rectangle with rounded corners. radius is the corner radius; corners selects which corners to round (4 booleans: TL, TR, BR, BL).

绘制圆角矩形。radius 为圆角半径;corners 选择哪些角为圆角(4 个布尔:左上、右上、右下、左下)。

Ellipse / Circle

handle.Ellipse(box, fill := unset, outline := unset, width := 1)
handle.Circle(xy, radius, fill := unset, outline := unset, width := 1)

Draws an ellipse inside the bounding box, or a circle centered at xy.

在包围盒内绘制椭圆,或以 xy 为圆心画圆。

Arc / Chord / Pieslice

handle.Arc(box, start, end, fill := unset, width := 1)
handle.Chord(box, start, end, fill := unset, outline := unset, width := 1)
handle.Pieslice(box, start, end, fill := unset, outline := unset, width := 1)

Draws circular segments between angles start and end (degrees, counterclockwise from 3 o'clock). Arc draws the outline only; chord closes the segment with a line; pieslice closes it through the center.

在 start 与 end 角之间绘制圆弧段(角度制,自 3 点钟方向逆时针)。Arc 只描边;chord 以弦封闭;pieslice 经圆心封闭成扇形。

Line

handle.Line(xy, fill := unset, width := 0, joint := unset)

Draws a polyline through the [x, y] points; joint is "curve" or None.

沿 [x, y] 点序列绘制折线;joint 为 "curve" 或无。

Point

handle.Point(xy, fill := unset)

Draws single points (one [x, y] or an array of them).

绘制单个点(单个 [x, y] 或其数组)。

Polygon

handle.Polygon(xy, fill := unset, outline := unset, width := 1)

Draws a polygon through the given vertices; the shape is closed automatically.

沿给定顶点绘制多边形;形状自动闭合。

RegularPolygon

handle.RegularPolygon(boundingCircle, nSides, rotation := 0, fill := unset, outline := unset, width := 1)

Draws a regular polygon. boundingCircle = [cx, cy, r], nSides ≥ 3, rotation in degrees.

绘制正多边形。boundingCircle = [cx, cy, r],nSides ≥ 3,rotation 为角度。

Bitmap

handle.Bitmap(xy, bitmap)

Draws a 1-bit mask bitmap at xy with the current fill color (Pillow's draw_bitmap; used by the truetype text path).

以当前填充色在 xy 处绘制 1 位掩膜位图(Pillow 的 draw_bitmap;truetype 文字路径使用)。

文字 · Text

All text methods share these options: fill (color), font (an ImageFont; default font when omitted), anchor (horizontal a-m + vertical a-d, Pillow's em-box anchor math), strokeWidth/strokeFill, spacing, align ("left"|"center"|"right"|"justify"), direction/features/language (RAQM layout), embeddedColor, and fontSize (load_default size).

所有文字方法共享这些选项:fill(颜色)、font(ImageFont;省略时用默认字体)、anchor(水平 a-m 加垂直 a-d,Pillow 的 em-box 锚点算法)、strokeWidth/strokeFill、spacing、align("left"|"center"|"right"|"justify")、direction/features/language(RAQM 排版)、embeddedColor 与 fontSize(load_default 字号)。

Text

handle.Text(xy, text, fill := unset, font := unset, anchor := unset, strokeWidth := 0, strokeFill := unset, spacing := 4, align := "left", direction := unset, features := unset, language := unset, embeddedColor := false, fontSize := unset)

Draws text at xy (the anchor point; default anchor "la"). Text containing \n delegates to the multiline layout.

在 xy(锚点;默认锚 "la")处绘制文字。含 \n 的文字转交多行排版。

Parity: with a TRUETYPE font the facade follows Pillow's own path — font.getmask2(text, mode, ink) + draw_bitmap at int(xy) + offset (the GDI gray8 mask is the documented rasterizer boundary); the default font keeps the native draw seams. Stroked truetype text (strokeWidth > 0) raises the facade's boundary error. direction/features/language raise Pillow's exact 'setting text direction, language or font features is not supported without libraqm' KeyError.对齐:使用 TRUETYPE 字体时,门面走 Pillow 自身路径——font.getmask2(text, mode, ink) + 在 int(xy) + offset 处 draw_bitmap(GDI 灰度掩膜为已记录的栅格化边界);默认字体保留原生绘制管线。带描边的 truetype 文字(strokeWidth > 0)抛门面的边界错误。direction/features/language 抛 Pillow 原样的 'setting text direction, language or font features is not supported without libraqm' KeyError。

MultilineText

handle.MultilineText(xy, text, fill := unset, font := unset, spacing := 4, align := "left", anchor := unset, strokeWidth := 0, strokeFill := unset, direction := unset, features := unset, language := unset, embeddedColor := false, fontSize := unset)

Draws multi-line text, replicating Pillow's _prepare_multiline_text exactly: anchor validation order, float spacing TypeErrors, left/center/right/justify (including the word spread), and the m/d anchor adjustments.

绘制多行文字,精确复刻 Pillow 的 _prepare_multiline_text:锚点校验顺序、浮点 spacing 的 TypeError、left/center/right/justify(含词间扩展)与 m/d 锚点调整。

TextLength

handle.TextLength(text, font := unset, direction := unset, features := unset, language := unset, embeddedColor := false, fontSize := unset)

Returns the width (in pixels) of the text as drawn. Multi-line text is rejected with Pillow's exact error.

返回文字绘制后的宽度(像素)。多行文字按 Pillow 原样报错拒绝。

TextBbox

handle.TextBbox(xy, text, font := unset, anchor := unset, strokeWidth := 0, spacing := 4, align := "left", direction := unset, features := unset, language := unset, embeddedColor := false, fontSize := unset)

Returns the bounding box [left, upper, right, lower] of the text as drawn; the upper-left corner is added after anchoring (Pillow semantics).

返回文字绘制后的包围盒 [left, upper, right, lower];锚定后再加左上角坐标(Pillow 语义)。

handle.MultilineTextBbox(xy, text, font := unset, spacing := 4, align := "left", anchor := unset, strokeWidth := 0, direction := unset, features := unset, language := unset, embeddedColor := false, fontSize := unset)

返回多行文字的包围盒,含 Pillow 的浮点加法语义。

示例 · Examples

Shapes and text (Pillow tutorial shape):

形状与文字(Pillow 教程形态):

img := Pillow.Image.New("RGB", [200, 120], "white")
d := Pillow.ImageDraw.Draw(img)
d.Line([[0, 0], [199, 0], [199, 119], [0, 119], [0, 0]], "blue", 3)
d.RoundedRectangle([[20, 20], [180, 100]], 12, "yellow", "red", 2)
d.Ellipse([60, 40, 140, 90], "lime", "black", 1)
d.Text([10, 100], "Hello 中文", "navy")
img.Save("draw.png")
img.Close()
