ImagePalette module

The ImagePalette module stores a palette as a flat byte sequence and provides palette builders and index lookups, matching Pillow 11.3.0's PIL.ImagePalette. The palette sequence is stored as an AHK Array (Pillow accepts any int sequence), and the lazy Colors map uses comma-joined string keys because AHK Map keys are identity-compared (no tuple keys).

ImagePalette 模块把调色板存为扁平的字节序列,并提供调色板构造器与索引查找,对齐 Pillow 11.3.0 的 PIL.ImagePalette。调色板序列存为 AHK Array(Pillow 接受任意整数序列),惰性 Colors 映射使用逗号拼接的字符串键——因为 AHK 的 Map 键按身份比较(没有元组键)。

Surface notes: Pillow.ImagePalette(...) constructs an instance (Pillow's ImagePalette.ImagePalette class). Random() shares Pillow's shape and value range but not its Mersenne-Twister stream; Load() and the PaletteFile/GimpPaletteFile/GimpGradientFile parser classes are documented fail-loud boundaries — see Boundaries / 行为边界.表面说明:Pillow.ImagePalette(...) 直接构造实例(Pillow 的 ImagePalette.ImagePalette 类)。Random() 与 Pillow 的形状、取值范围一致,但随机流(梅森旋转)不同;Load() 与 PaletteFile/GimpPaletteFile/GimpGradientFile 解析器类为已记录的显式失败边界——见行为边界。

类与字段 · Class & Fields

ImagePalette class

Pillow.ImagePalette(mode := "RGB", palette := unset)

Constructs a palette. mode is the channel layout string ("RGB", "RGBA", …); palette is an optional flat byte Array (defaults to empty). This facade's constructor omits Pillow's trailing size argument — palette.Length is the single source of truth for the byte count.

构造调色板。mode 为通道布局字符串("RGB"、"RGBA"……);palette 为可选的扁平字节 Array(默认空)。本门面的构造器省略 Pillow 末尾的 size 参数——字节数只由 palette.Length 决定。

mode
Channel layout string; defaults to "RGB".通道布局字符串;默认 "RGB"。
palette
Optional flat int sequence; unset gives an empty palette.可选扁平整数序列;unset 得到空调色板。

Returns: an ImagePalette instance.返回:ImagePalette 实例。

GetColor

palette.GetColor(color, image := unset)

Returns the palette index for a color, allocating a new entry when needed (Pillow's getcolor). color is a channel array such as [255, 0, 0]. In RGB mode a 4-element color must have alpha 255 (else cannot add non-opaque RGBA color to RGB palette); in RGBA mode a 3-element color gets alpha 255 appended. A raw palette (Rawmode set) raises palette contains raw palette data.

返回某颜色的调色板索引,必要时分配新条目(Pillow 的 getcolor)。color 为通道数组,如 [255, 0, 0]。RGB 模式下 4 元素颜色必须 alpha 为 255(否则 cannot add non-opaque RGBA color to RGB palette);RGBA 模式下 3 元素颜色补 alpha 255。原始调色板(Rawmode 已设)抛 palette contains raw palette data。

color
Channel array (3 or 4 elements).通道数组(3 或 4 元素)。
image
Optional image whose Info background/transparency indices are skipped as specials.可选图像;其 Info 的 background/transparency 索引作为保留项被跳过。

Returns: the palette index (0–255).返回:调色板索引(0–255)。

Fun parity fact: the oracle-verified GetColor allocation sequence for a reference input is [1, 4, 15, 5, 18, 6, 21] — Pillow hard-codes //3 regardless of mode and skips the image's background/transparency specials, both mirrored exactly. Exceeding 255 distinct colors with no free histogram slot raises cannot allocate more than 256 colors.趣味对齐事实:参考输入下经 oracle 验证的 GetColor 分配序列为 [1, 4, 15, 5, 18, 6, 21]——Pillow 无论模式一律硬编码 //3,并跳过图像的 background/transparency 保留索引,两者均逐项复刻。超过 255 种不同颜色且无空闲直方图槽时抛 cannot allocate more than 256 colors。

模块调色板构造器 · Module Palette Builders

Random static

Pillow.ImagePalette.Random(mode := "RGB")

Builds a 256-entry palette of random channel values in 0–255. Shape and range match Pillow; the exact stream differs (documented boundary).

构造 256 条目的随机调色板,通道值在 0–255。形状与取值范围与 Pillow 一致;逐值随机流不同(已记录边界)。

Returns: a new ImagePalette.返回:新的 ImagePalette。

Boundary: Pillow uses Python's global Mersenne-Twister stream; this runtime uses AHK's own RNG with the same shape/range. See Boundaries / 行为边界.边界:Pillow 使用 Python 全局梅森旋转随机流;本运行时用 AHK 自身的随机源,形状与取值范围相同。见行为边界。

Raw static

Pillow.ImagePalette.Raw(rawmode, data)

Wraps raw palette bytes: sets Rawmode, stores data as the byte array, and marks the palette dirty. A raw palette cannot be serialized or color-looked-up.

包装原始调色板字节:设置 Rawmode、把 data 存为字节数组并标记为 dirty。原始调色板不可序列化,也不可做颜色查找。

Returns: a raw ImagePalette.返回:原始 ImagePalette。

Negative static

Pillow.ImagePalette.Negative(mode := "RGB")

Builds a palette whose channels run from the maximum value downward (the inverse of the standard ramp).

构造通道值自最大值向下递减的调色板(标准渐变的反相)。

Returns: a new ImagePalette.返回:新的 ImagePalette。

通过把三条线性 LUT 缩放到给定 white 颜色(Pillow 默认的暖白)来构造褐色调调色板。

加载边界 · Load Boundary

Load static

Pillow.ImagePalette.Load(filename)

Loads a GIMP palette, GIMP gradient, or Teragon-style palette file via the three-way fallback chain (GimpPaletteFile → GimpGradientFile → PaletteFile). A missing file raises [Errno 2] No such file or directory: '…'; when every parser rejects the content, the chain raises Pillow's exact cannot load palette.

通过三段回退链(GimpPaletteFile → GimpGradientFile → PaletteFile)加载 GIMP 调色板、GIMP 渐变或 Teragon 风格调色板文件。文件缺失抛 [Errno 2] No such file or directory: '…';当所有解析器都拒绝内容时,回退链抛 Pillow 原样的 cannot load palette。

filename
Path to a palette/gradient file.调色板/渐变文件路径。

Returns: [bytes, rawmode] ("RGB" or "RGBA").返回:[字节, rawmode]("RGB" 或 "RGBA")。

Boundary: the PaletteFile/GimpPaletteFile/GimpGradientFile parser classes are not exposed as classes — only Load's fallback chain and its internal helpers exist. Gradient non-RGB color spaces (cannot handle HSV colour space) and short segment lines (list index out of range) escape unwrapped, matching Pillow. See Boundaries / 行为边界.边界:PaletteFile/GimpPaletteFile/GimpGradientFile 解析器类不作为类暴露——只有 Load 的回退链及其内部辅助函数。渐变的非 RGB 色彩空间(cannot handle HSV colour space)与过短的段行(list index out of range)原样上抛,与 Pillow 一致。见行为边界。

示例 · Examples

Attach a Wedge grayscale palette to a P-mode image:

把 Wedge 灰度调色板挂到 P 模式图像上:

pal := Pillow.ImagePalette.Wedge("RGB")   ; 256 grayscale steps / 256 级灰度
img := Pillow.Image.New("P", [256, 16])
img.PutPalette(pal.ToBytes(), "RGB")
img.Save("wedge.png")
img.Close()
