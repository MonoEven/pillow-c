ImageStat module

The ImageStat module computes per-band statistics from a histogram. Stat wraps either an Image (whose histogram is taken internally) or a precomputed raw histogram list; every statistic is a lazily computed, cached attribute that returns a per-band ARRAY — for an RGB image Mean returns [rMean, gMean, bMean].

ImageStat 模块基于直方图计算逐通道统计量。Stat 包装一个 Image(内部取直方图)或预先计算好的原始直方图列表;每个统计量都是惰性计算并缓存的属性,返回逐通道数组——RGB 图像的 Mean 返回 [rMean, gMean, bMean]。

Each attribute is computed on first access and cached (Pillow's cached_property); it is a per-band array whose length equals the band count (histogram length // 256).每个属性在首次访问时计算并缓存(Pillow 的 cached_property);结果是逐通道数组,长度等于通道数(直方图长度 // 256)。

构造 · Construction

Stat class

Pillow.ImageStat.Stat(imageOrList, mask := unset)

Builds a statistics object over an image or a raw histogram list. If a mask is given, only the pixels covered by the mask are counted.

在图像或原始直方图列表上构建统计对象;若提供掩膜,仅统计掩膜覆盖的像素。

imageOrList
An Image, or a precomputed histogram list whose length must be a multiple of 256 (one 256-bin block per band).一个 Image,或预先计算的直方图列表;列表长度必须是 256 的整数倍(每通道一个 256 箱块)。
mask
Optional mask image: mode "1" or "L", same size as the image; only masked pixels count. Requires image input — a list plus mask raises Pillow.ImageStat.Stat mask requires image input.可选掩膜:模式 "1" 或 "L",与图像同尺寸;仅统计掩膜内像素。要求图像输入——列表配掩膜抛 Pillow.ImageStat.Stat mask requires image input。

Returns: a new Stat.返回:新 Stat。

Mask parity: a non-1/L mask raises Pillow's exact bad transparency mask; a size mismatch raises images do not match.掩膜对齐:非 1/L 掩膜抛 Pillow 原样的 bad transparency mask;尺寸不符抛 images do not match。

Like Pillow, the histogram groups pixels into 256 bins even for more-than-8-bit modes, so I/F mode mean/median/rms top out at 255 and extrema cannot exceed 255 — use image.GetExtrema() for exact per-band extrema. I;16 histograms keep Pillow's layout-dependent byte misread as a documented boundary (see Boundaries).与 Pillow 相同,直方图即使超过 8 位/通道仍按 256 箱分组,故 I/F 模式的 mean/median/rms 上限为 255,extrema 最大值不超过 255——精确逐通道极值请用 image.GetExtrema()。I;16 直方图保留 Pillow 依赖内存布局的字节误读,记为边界(见行为边界页)。

Global static

Pillow.ImageStat.Global(imageOrList, mask := unset)

Pillow's ImageStat.Global is the plain alias Global = Stat. Because global is a reserved keyword in AutoHotkey, the facade exposes the alias as a static constructor method: it forwards its arguments to Stat and returns the new statistics object.

Pillow 的 ImageStat.Global 只是别名 Global = Stat。因 global 是 AutoHotkey 的保留关键字,门面将该别名暴露为静态构造方法:把参数转发给 Stat 并返回新的统计对象。

Returns: a new Stat (identical to Pillow.ImageStat.Stat).返回:新 Stat(等同 Pillow.ImageStat.Stat)。

属性 · Attributes

Extrema property

stat.Extrema

Min/max values per band: an array of [min, max] pairs — the lowest and highest occupied histogram bins.

每通道极值:[min, max] 二元组数组——直方图中最低与最高被占用的箱。

Count property

stat.Count

Total number of pixels per band — the sum of the band's 256 histogram bins (integer array).

每通道像素总数——该通道 256 个直方图箱之和(整数数组)。

Sum property

stat.Sum

Sum of pixel values per band: Σ level × count[level] over the band's 256 bins.

每通道像素值之和:对该通道 256 个箱求 Σ level × count[level]。

Sum2 property

stat.Sum2

Sum of squared pixel values per band: Σ level² × count[level].

每通道像素值平方和:Σ level² × count[level]。

Mean property

stat.Mean

Arithmetic mean pixel level per band: sum / count.

每通道像素算术平均:sum / count。

Median property

stat.Median

Median pixel level per band, found by walking the cumulative histogram until it exceeds count // 2.

每通道像素中位数:累加直方图直到超过 count // 2 时取该箱。

Rms property

stat.Rms

Root-mean-square per band: sqrt(sum2 / count).

每通道均方根:sqrt(sum2 / count)。

Var property

stat.Var

Variance per band: (sum2 − sum² / count) / count.

每通道方差:(sum2 − sum² / count) / count。

StdDev property

stat.StdDev

Standard deviation per band: sqrt(var).

每通道标准差:sqrt(var)。

内部辅助 · Internal helpers

Pillow.ImageStat.StrPut is a buffer-write helper used by the facade; it is not part of the Pillow-style user API.Pillow.ImageStat.StrPut 是门面使用的缓冲区写入辅助函数,不属于 Pillow 风格的用户 API。

示例 · Examples

Compute and print the mean and standard deviation of an RGB image:

计算并打印 RGB 图像的均值与标准差:

img := Pillow.Image.Open("photo.jpg")    ; RGB image
st := Pillow.ImageStat.Stat(img)
mean := st.Mean                          ; [rMean, gMean, bMean]
std  := st.StdDev                        ; [rStddev, gStddev, bStddev]
txt := ""
loop mean.Length
    txt .= "band " A_Index ": mean=" Round(mean[A_Index], 2)
        .  "  stddev=" Round(std[A_Index], 2) "`n"
MsgBox txt
img.Close()
