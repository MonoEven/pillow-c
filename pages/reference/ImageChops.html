ImageChops module

The ImageChops module contains channel ("chops") operations — arithmetic, bitwise, and blend operations on images. Binary operations require both images to share the same mode and size, and every function returns a new Image while leaving its inputs unchanged (Pillow semantics).

ImageChops 模块提供通道("chops")运算——图像间的算术、按位与混合运算。二元运算要求两幅图像模式与尺寸一致,且每个函数都返回新 Image、不修改输入(Pillow 语义)。

Naming: primary names are PascalCase. AHK method lookup is case-insensitive, so Pillow's underscore-free snake_case names (blend, difference, multiply, lighter, …) resolve to the same methods automatically; the seven underscore forms — add_modulo, hard_light, logical_and, logical_or, logical_xor, soft_light, subtract_modulo — are declared as explicit aliases.命名:主名为 PascalCase。AHK 方法查找不区分大小写,故 Pillow 不含下划线的 snake_case 名(blend、difference、multiply、lighter……)自动解析到同名主方法;七个含下划线形式(add_modulo、hard_light、logical_and、logical_or、logical_xor、soft_light、subtract_modulo)以显式别名声明。

Parity: for binary ops a mode/size mismatch raises Pillow's status error; when both operands are I or F mode the error surfaces as Pillow's exact image has wrong mode.对齐:二元运算的模式/尺寸不符抛 Pillow 的状态错误;当两操作数均为 I 或 F 模式时,错误以 Pillow 原样的 image has wrong mode 呈现。

单图运算 · Unary Operations

Constant static

Pillow.ImageChops.Constant(image, value)

Returns an image with the same mode and size as image, filled with a single value.

返回与 image 同模式同尺寸、以单一数值填充的图像。

value
Integer fill value; a non-integer raises Pillow.ImageChops.Constant value must be an integer.整数填充值;非整数抛 Pillow.ImageChops.Constant value must be an integer。

Returns: a new Image.返回:新 Image。

Duplicate static

Pillow.ImageChops.Duplicate(image)

Returns a full copy of the image (Pillow's ImageChops.duplicate, equivalent to image.Copy()).

返回图像的完整副本(Pillow 的 ImageChops.duplicate,等价于 image.Copy())。

Returns: a new Image.返回:新 Image。

Invert static

Pillow.ImageChops.Invert(image)

Inverts each pixel: out = MAX − a, where MAX is the maximum value of the mode (255 for L/RGB, 1 for mode "1", …).

反转每个像素:out = MAX − a,其中 MAX 为该模式的最大值(L/RGB 为 255、"1" 模式为 1……)。

Returns: a new Image.返回:新 Image。

Offset static

Pillow.ImageChops.Offset(image, xoffset, yoffset := unset)

Shifts the image by (xoffset, yoffset) pixels; the emptied region is filled with 0. When yoffset is omitted it defaults to xoffset.

把图像平移 (xoffset, yoffset) 像素;腾出的区域以 0 填充。省略 yoffset 时默认取 xoffset。

xoffset / yoffset
Integer pixel offsets (positive shifts right/down); non-integers raise a validation error.整数像素偏移(正值为向右/向下);非整数抛校验错误。

Returns: a new Image.返回:新 Image。

两图相加:out = (left + right) / scale + offset。

两图相减并对模式范围取模回绕(8 位模式按 256 取模)。

Pillow.ImageChops.Difference(left, right)

逐像素取绝对差:out = abs(left − right)。

Multiply static

Pillow.ImageChops.Multiply(left, right)

Multiplies two images: out = left * right / 255.

两图相乘:out = left * right / 255。

Returns: a new Image.返回:新 Image。

Screen static

Pillow.ImageChops.Screen(left, right)

Screen blend: out = 255 − ((255 − left) * (255 − right) / 255).

滤色混合:out = 255 − ((255 − left) * (255 − right) / 255)。

Returns: a new Image.返回:新 Image。

混合 · Blend Modes

Blend static

Pillow.ImageChops.Blend(left, right, alpha)

Linear interpolation between two same-size images: out = left * (1 − alpha) + right * alpha. Delegates to Pillow.Image.Blend.

两幅同尺寸图像线性插值:out = left * (1 − alpha) + right * alpha。委托给 Pillow.Image.Blend。

alpha
Number in 0.0…1.0; 0 returns left, 1 returns right.0.0…1.0 之间的数;0 返回左图,1 返回右图。

Returns: a new Image.返回:新 Image。

Composite static

Pillow.ImageChops.Composite(image1, image2, mask)

Copies image1 where mask is 255 and image2 where it is 0; intermediate mask values are not blended (unlike Blend). Delegates to Pillow.Image.Composite.

mask 为 255 处取 image1、为 0 处取 image2;中间值不混合(与 Blend 不同)。委托给 Pillow.Image.Composite。

mask
A 1/L/LA/RGBA mode image; any other mode raises bad transparency mask.1/L/LA/RGBA 模式图像;其他模式抛 bad transparency mask。

Returns: a new Image.返回:新 Image。

Pillow.ImageChops.Darker(left, right)

Per-pixel minimum: out = min(left, right).

逐像素取较小值:out = min(left, right)。

Returns: a new Image.返回:新 Image。

Lighter static

Pillow.ImageChops.Lighter(left, right)

Per-pixel maximum: out = max(left, right).

逐像素取较大值:out = max(left, right)。

Returns: a new Image.返回:新 Image。

Overlay static

Pillow.ImageChops.Overlay(left, right)

Overlay blend: Screen for bright values and Multiply for dark ones, combining the two images.

叠加混合:亮部取滤色、暗部取正片叠底,综合两幅图像。

Returns: a new Image.返回:新 Image。

SoftLight static

Pillow.ImageChops.SoftLight(left, right)

Soft-light blend using Pillow's standard formula (a gentler version of HardLight).

柔光混合,使用 Pillow 标准公式(HardLight 的柔和版本)。

Hard-light blend using Pillow's standard formula: like Overlay but with the operands swapped.

强光混合,使用 Pillow 标准公式:与 Overlay 相同但两操作数对调。

Returns: a new Image.返回:新 Image。

按位逻辑 · Logical Operations

The logical operations work on mode-"1" images (0 / 255): each applies the bitwise operation per pixel, then yields 255 where the result is nonzero and 0 otherwise.

逻辑运算作用于 "1" 模式图像(0 / 255):逐像素按位运算,结果非零处为 255、否则为 0。

LogicalAnd static

Pillow.ImageChops.LogicalAnd(left, right)

Bitwise AND: 255 where left & right is nonzero, else 0.

按位与:left & right 非零处为 255,否则为 0。

Returns: a new Image.返回:新 Image。

LogicalOr static

Pillow.ImageChops.LogicalOr(left, right)

Bitwise OR: 255 where left | right is nonzero, else 0.

按位或:left | right 非零处为 255,否则为 0。

Returns: a new Image.返回:新 Image。

LogicalXor static

Pillow.ImageChops.LogicalXor(left, right)

Bitwise XOR: 255 where left ^ right is nonzero, else 0.

按位异或:left ^ right 非零处为 255,否则为 0。

Returns: a new Image.返回:新 Image。

以下成员实现上述运算共用的 DLL 管道。它们对门面内部公开,但不属于 Pillow 风格的用户 API。

HelperEN / 中文

示例 · Examples

Darken two opened images, then take their absolute difference and save it.

打开两幅图像并取较暗者,再计算两者绝对差并保存。

img1 := Pillow.Image.Open("photo1.jpg")
img2 := Pillow.Image.Open("photo2.jpg")
dark  := Pillow.ImageChops.Darker(img1, img2)      ; per-pixel min / 逐像素较小值
lite  := Pillow.ImageChops.Lighter(img1, img2)     ; per-pixel max / 逐像素较大值
diff  := Pillow.ImageChops.Difference(img1, img2)  ; abs(a - b)
diff.Save("diff.png")
img1.Close(), img2.Close(), dark.Close(), lite.Close(), diff.Close()
