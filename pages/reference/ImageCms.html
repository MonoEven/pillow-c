ImageCms module

The ImageCms module is the Little CMS 2 color-management layer, Pillow 11.3.0-compatible (PIL.ImageCms): it opens and creates ICC profiles, builds color transforms between them, applies transforms to images, and reports profile intent support. Input/output modes are Pillow mode strings; this facade's transform validation accepts the RGB/LAB combinations (RGB→LAB, LAB→RGB, RGB→RGB, LAB→LAB) that the native layer implements.

ImageCms 模块是 Little CMS 2 色彩管理层,兼容 Pillow 11.3.0(PIL.ImageCms):打开与创建 ICC 配置文件、构建配置文件间的色彩转换、把转换应用于图像,并查询配置文件的 intent 支持。输入/输出模式为 Pillow 模式字符串;本门面的转换校验接受原生层实现的 RGB/LAB 组合(RGB→LAB、LAB→RGB、RGB→RGB、LAB→LAB)。

Naming: primary names are PascalCase. AHK method lookup is case-insensitive, so Pillow's snake_case names (getOpenProfile, createProfile, buildTransform, profileToProfile, versions, …) resolve to the same methods automatically. Error text is pinned to Pillow 11.3.0: a wrong-typed profile raises Invalid type for Profile (Pillow's PyCMSError); an unsupported mode/intent/flags combination raises cannot build transform or cannot build proof transform; out-of-range intent/flags raise Pillow's exact renderingIntent must be an integer between 0 and 3 / flags must be an integer between 0 and 100663295. Deep native failures surface as pillow_c: <status> (e.g. an unreadable ICC file reports pillow_c: invalid argument, not Pillow's OSError).命名:主名为 PascalCase。AHK 方法查找不区分大小写,故 Pillow 的 snake_case 名(getOpenProfile、createProfile、buildTransform、profileToProfile、versions……)自动解析到同名主方法。错误文本与 Pillow 11.3.0 对齐:配置文件类型错误抛 Invalid type for Profile(Pillow 的 PyCMSError);不支持的模式/intent/flags 组合抛 cannot build transform 或 cannot build proof transform;越界的 intent/flags 抛 Pillow 原样的 renderingIntent must be an integer between 0 and 3 / flags must be an integer between 0 and 100663295。深层原生失败以 pillow_c: <status> 呈现(例如无法读取的 ICC 文件报 pillow_c: invalid argument,而非 Pillow 的 OSError)。

Oracle parity: ICC byte content, intent support, and color arithmetic are oracle-verified against Pillow 11.3.0 (identity RGB→RGB transforms, soft-proofing with the SOFTPROOFING flags, and profile serialization).Oracle 对齐:ICC 字节内容、intent 支持与色彩运算均以 Pillow 11.3.0 为基准逐一验证(恒等 RGB→RGB 转换、带 SOFTPROOFING 标志的软打样,以及配置文件序列化)。

CreateProfile static

Pillow.ImageCms.CreateProfile(colorSpace, colorTemp := 0)

Creates an on-the-fly profile: "sRGB" (a built-in sRGB profile), "LAB" (an Lab profile, optionally with a white-point color temperature), or "XYZ". BuildTransform static

Pillow.ImageCms.BuildTransform(inputProfile, outputProfile, inputMode, outputMode, renderingIntent := 0, flags := 0)

Builds a color transform between two profiles. Validates the intent and flags first with Pillow's exact messages, then the mode pair (RGB/LAB combinations only). Unsupported combinations raise cannot build transform. The transform snapshots the output profile's ICC bytes at build time and does not own the profile objects, so the profiles may be closed once the transform is built.

构建两个配置文件之间的色彩转换。先以 Pillow 原样消息校验 intent 与 flags,再校验模式对(仅 RGB/LAB 组合)。不支持的组合抛 cannot build transform。转换在构建时快照输出配置文件的 ICC 字节,且不拥有配置文件对象,因此转换构建完成后即可关闭配置文件。

0…3 (default 0 = PERCEPTUAL).0…3(默认 0 = PERCEPTUAL)。

示例 · Examples

Open sRGB and AdobeRGB profiles, build an RGB→RGB transform, apply it, and serialize the profile bytes.

打开 sRGB 与 AdobeRGB 配置文件,构建 RGB→RGB 转换并应用,然后序列化配置文件字节。

; Open two ICC profiles / 打开两个 ICC 配置文件
srgb     := Pillow.ImageCms.GetOpenProfile("sRGB.icc")
adobergb := Pillow.ImageCms.GetOpenProfile("AdobeRGB.icc")

; Build an RGB→RGB transform / 构建 RGB→RGB 转换
transform := Pillow.ImageCms.BuildTransform(srgb, adobergb, "RGB", "RGB",
    Pillow.ImageCms.Intent.PERCEPTUAL, 0)

; Apply it to an image / 将转换应用于图像
im  := Pillow.Image.Open("photo.jpg")
out := Pillow.ImageCms.ApplyTransform(im, transform)
out.Save("photo_adobe.jpg")

; Serialize the profile bytes / 序列化配置文件字节
iccBytes := srgb.Tobytes()                 ; ICC content Buffer / ICC 内容 Buffer
im.Info["icc_profile"] := adobergb.Serialize()

; Clean up / 清理
out.Close(), im.Close(), transform.Close(), srgb.Close(), adobergb.Close()
