ImageOps module

The ImageOps module provides ready-made image processing functions — contrast, colorization, equalization, posterize/solarize, EXIF transpose, and aspect-ratio resizing (contain/cover/fit/pad). Methods use PascalCase primary names mirroring Pillow's PIL.ImageOps; the snake_case alias exif_transpose is also provided.

ImageOps 模块提供现成的图像处理函数——对比度、上色、均衡化、色调分离/曝光反转、EXIF 转置,以及保持宽高比的缩放(contain/cover/fit/pad)。方法以 PascalCase 主名对应 Pillow 的 PIL.ImageOps;同时提供 snake_case 别名 exif_transpose。

Most functions return a new Image and leave the input untouched; only ExifTranspose(…, true) mutates in place. Resampling defaults mirror Pillow (BICUBIC for the resize family, BILINEAR for Deform).多数函数返回新 Image 且不改动输入;仅 ExifTranspose(…, true) 就地修改。重采样默认值与 Pillow 一致(resize 族为 BICUBIC,Deform 为 BILINEAR)。

点与颜色操作 · Point & color ops

Autocontrast static

Pillow.ImageOps.Autocontrast(image, cutoff := 0, ignore := unset, mask := unset, preserveTone := false)

Normalizes image contrast: it computes a histogram (of the mask region when given), discards cutoff percent from both the darkest and lightest ends, then remaps so the darkest pixel becomes 0 and the lightest 255.

归一化图像对比度:计算(或由 mask 限定区域的)直方图,从最暗与最亮两端各裁掉 cutoff 百分比,再把最暗像素重映射为 0、最亮为 255。

cutoff
Percent to cut from the low and high ends; a single number applies to both, or [low, high].在低端与高端裁掉的百分比;单个数字两端同用,或 [low, high]。
ignore
Background pixel value(s) to zero out of the histogram before remapping.重映射前从直方图中剔除的背景像素值(单个或数组)。
mask
Optional mask restricting the histogram to its pixels.可选掩膜,仅用其像素参与直方图。
preserveTone
Use an L-conversion histogram to preserve tone (Photoshop-style).用 L 转换后的直方图以保留色调(Photoshop 风格)。

Returns: a new Image.返回:新 Image。

Colorize static

Pillow.ImageOps.Colorize(image, black, white, mid := unset, blackpoint := 0, whitepoint := 255, midpoint := 127)

Colorizes an L image: black pixels map to black, white pixels to white, with an optional mid color for three-point interpolation. Returns an RGB image.

给 L 图像上色:黑像素映射为 black、白像素映射为 white,可选 mid 颜色做三点插值。返回 RGB 图像。

black
Color for black input pixels ([r, g, b] or a name).黑色输入像素对应的颜色([r, g, b] 或颜色名)。
white
Color for white input pixels.白色输入像素对应的颜色。
mid
Optional midtone color for three-point mapping.可选的中间调颜色,启用三点映射。
blackpoint / whitepoint / midpoint
Integer mapping positions; must satisfy blackpoint <= midpoint <= whitepoint (or blackpoint <= whitepoint without mid).整数映射位置;须满足 blackpoint <= midpoint <= whitepoint(无 mid 时为 blackpoint <= whitepoint)。

Returns: a new RGB Image.返回:新的 RGB Image。

Requires an L-mode input; other modes raise an error.要求输入为 L 模式;其他模式报错。

Equalize static

Pillow.ImageOps.Equalize(image, mask := unset)

Equalizes the image histogram: a non-linear mapping spreads each non-alpha band toward a uniform distribution of values.

均衡图像直方图:用非线性映射把每个非 alpha 通道拉向均匀分布。

mask
Optional mask; only its pixels are included in the analysis.可选掩膜,仅其像素参与统计。

Returns: a new Image.返回:新 Image。

Numeric I/F modes raise Pillow's not supported for mode ….数值型 I/F 模式抛 Pillow 的 not supported for mode …。

Grayscale static

Pillow.ImageOps.Grayscale(image)

Converts the image to grayscale (mode L) via the L conversion; an L image is simply copied.

通过 L 转换把图像转为灰度(模式 L);L 图像仅复制。

Returns: a new L-mode Image.返回:新的 L 模式 Image。

Invert static

Pillow.ImageOps.Invert(image)

Negates the image: every channel becomes 255 - value. Supported for L, RGB and 1 modes.

反相图像:每个通道变为 255 - value。支持 L、RGB 与 1 模式。

Returns: a new Image.返回:新 Image。

Parity: unlike ImageChops.Invert, this raises Pillow's not supported for mode … on RGBA and other modes.对齐:与 ImageChops.Invert 不同,RGBA 及其他模式抛 Pillow 的 not supported for mode …。

Posterize static

Pillow.ImageOps.Posterize(image, bits)

Reduces the number of bits kept for each color channel to bits (1–8).

把每个颜色通道保留的位数降到 bits(1–8)。

Returns: a new Image.返回:新 Image。

The facade validates that bits is an integer ≤ 8 (native accepts down to −31).门面校验 bits 为 ≤ 8 的整数(原生最低到 −31)。

Solarize static

Pillow.ImageOps.Solarize(image, threshold := 128)

Inverts every pixel value at or above threshold, leaving lower values unchanged.

把 ≥ threshold 的像素值反相,低于阈值的保持不变。

threshold
Gray level above which pixels are inverted.反相的灰度阈值。

Returns: a new Image.返回:新 Image。

几何与尺寸 · Geometry & sizing

Contain static

Pillow.ImageOps.Contain(image, size, method := unset)

Resizes the image to fit within size while keeping the aspect ratio (neither axis exceeds size).

按比例缩放到能完整放入 size(两轴均不超过 size)。

size
Requested output size [width, height].请求的输出尺寸 [width, height]。
method
Resampling method; default BICUBIC.重采样方法;默认 BICUBIC。

Returns: a new Image.返回:新 Image。

Cover static

Pillow.ImageOps.Cover(image, size, method := unset)

Resizes so the image covers size while keeping the aspect ratio (both axes meet or exceed size).

按比例缩放到覆盖 size(两轴均达到或超过 size)。

size
Requested output size [width, height].请求的输出尺寸 [width, height]。
method
Resampling method; default BICUBIC.重采样方法;默认 BICUBIC。

Returns: a new Image.返回:新 Image。

Crop static

Pillow.ImageOps.Crop(image, border := 0)

Removes border pixels from the image. border may be a number, [x, y], or [left, top, right, bottom].

从图像裁掉 border 像素。border 可为数字、[x, y] 或 [left, top, right, bottom]。

Returns: a new Image.返回:新 Image。

Expand static

Pillow.ImageOps.Expand(image, border := 0, fill := 0)

Adds a border around the image, filled with fill (default black). border uses the same shapes as Crop.

在图像四周添加边框,以 fill(默认黑)填充。border 与 Crop 同形。

fill
Fill value (a color name, tuple, or scalar).填充值(颜色名、元组或标量)。

Returns: a new Image.返回:新 Image。

Fit static

Pillow.ImageOps.Fit(image, size, method := unset, bleed := 0.0, centering := unset)

Resizes and crops to exactly size, preserving aspect ratio. bleed trims a fraction from every edge (0 to < 0.5) and centering selects the crop position (default [0.5, 0.5]).

缩放并裁剪到精确 size、保持宽高比。bleed 从各边裁去比例(0 到 < 0.5),centering 决定裁剪位置(默认 [0.5, 0.5])。

size
Requested output size [width, height].请求的输出尺寸 [width, height]。
bleed
Decimal fraction trimmed from each edge (default 0).从各边裁去的小数比例(默认 0)。
centering
Crop position [x, y], each in 0–1; default [0.5, 0.5].裁剪位置 [x, y],各分量 0–1;默认 [0.5, 0.5]。

Returns: a new Image.返回:新 Image。

Pad static

Pillow.ImageOps.Pad(image, size, method := unset, color := unset, centering := unset)

Resizes to fit within size (contain) then pads the remainder with color (default black), positioned by centering (default [0.5, 0.5]).

先等比缩放到 size 内(contain),再用 color(默认黑)填充剩余区域,位置由 centering(默认 [0.5, 0.5])决定。

size
Requested output size [width, height].请求的输出尺寸 [width, height]。
color
Background color of the padding (default black).填充区域的背景色(默认黑)。
centering
Position of the resized image [x, y] in 0–1.缩放后图像的位置 [x, y],取值 0–1。

Returns: a new Image.返回:新 Image。

Scale static

Pillow.ImageOps.Scale(image, factor, resample := unset)

Rescales by factor: width and height are multiplied using round-half-even, then resized (default BICUBIC). factor = 1 returns a copy; factor <= 0 raises an error.

按 factor 缩放:宽高乘以因子(round-half-even)后 resize(默认 BICUBIC)。factor = 1 返回副本;factor <= 0 报错。

factor
Expansion factor as a number (> 1 enlarges, < 1 shrinks).缩放系数(> 1 放大,< 1 缩小)。
resample
Resampling method; default BICUBIC.重采样方法;默认 BICUBIC。

Returns: a new Image.返回:新 Image。

变换 · Transforms

Deform static

Pillow.ImageOps.Deform(image, deformer, resample := unset)

Deforms the image through a deformer object that exposes getmesh(image); the mesh is applied with a MESH transform (default resample BILINEAR).

通过暴露 getmesh(image) 的变形对象做 MESH 变换(默认重采样 BILINEAR)。

deformer
Any object with a getmesh(image) method returning the mesh.任何带 getmesh(image) 方法并返回网格的对象。
resample
Resampling filter; default BILINEAR.重采样滤镜;默认 BILINEAR。

Returns: a new Image.返回:新 Image。

ExifTranspose static

Pillow.ImageOps.ExifTranspose(image, in_place := false)   ; alias: exif_transpose(image, in_place := false)

Applies the EXIF Orientation tag (2–8) as a transpose. With in_place := true the image is mutated and nothing is returned; otherwise a transposed copy (or a plain copy when orientation ≤ 1) is returned.

按 EXIF Orientation 标签(2–8)做转置。in_place := true 时就地修改且无返回;否则返回转置副本(orientation ≤ 1 时返回普通副本)。

in_place
When true, transpose the image in place and return nothing.为 true 时就地转置且不返回。

Returns: a new transposed Image (or a copy when orientation ≤ 1); nothing when in_place is true.返回:新的转置 Image(orientation ≤ 1 时为副本);in_place 为 true 时无返回。

Parity: the facade transposes but does not strip the EXIF Orientation tag (Pillow removes it).对齐:门面仅转置,不删除 EXIF Orientation 标签(Pillow 会删除)。

Returns: a new Image.返回:新 Image。

水平翻转(左右镜像)。

示例 · Examples

Contrast boost, histogram equalization and EXIF auto-rotation:

对比度增强、直方图均衡与 EXIF 自动旋转:

img   := Pillow.Image.Open("scan.jpg")
boost := Pillow.ImageOps.Autocontrast(img, 2)     ; clip 2% off each end
eq    := Pillow.ImageOps.Equalize(img)            ; equalize the histogram
fixed := Pillow.ImageOps.ExifTranspose(img)       ; apply EXIF orientation
fixed := Pillow.ImageOps.exif_transpose(img)      ; snake_case alias
boost.Save("autocontrast.png")
eq.Save("equalized.png")
fixed.Save("upright.png")
img.Close()
