ImageMath module

The ImageMath module evaluates image expressions: a Python-like infix mini-language compiled to the native RPN engine, plus Pillow's lambda_eval helper and the imagemath_* single-image operations. Because AHK identifiers are case-insensitive, Pillow's eval/unsafe_eval/lambda_eval and imagemath_* names map onto the PascalCase and snake_case members listed here.

ImageMath 模块求值图像表达式:一套类 Python 的中缀小语言被编译到原生 RPN 引擎,外加 Pillow 的 lambda_eval 辅助函数与 imagemath_* 单图像操作。由于 AHK 标识符不区分大小写,Pillow 的 eval/unsafe_eval/lambda_eval 与 imagemath_* 名称都映射到下文列出的 PascalCase 与 snake_case 成员。

variables is the AHK analogue of Pillow's keyword arguments: a Map of name → Image or Number.variables 是 Pillow 关键字参数的 AHK 对应物:一个 name → Image 或 Number 的 Map。

求值与 lambda · Evaluation & lambda_eval

Eval static

Pillow.ImageMath.Eval(expression, variables := unset)

Compiles and evaluates an expression string (Pillow's ImageMath.eval, identical to unsafe_eval). When the expression references images the result is a new Image; a pure-scalar expression returns a Number (Integer or Float).

编译并求值一个表达式字符串(Pillow 的 ImageMath.eval,与 unsafe_eval 相同)。表达式引用图像时返回新的 Image;纯标量表达式返回 Number(Integer 或 Float)。

expression
String expression; non-strings raise Pillow.ImageMath expects a string expression.字符串表达式;非字符串抛 Pillow.ImageMath expects a string expression。
variables
Map of name → Image (modes L/I/F) or Number. Any other container raises Pillow.ImageMath variables must be a Map of name to Image or Number; an unknown name raises 'name' not allowed; a non-L/I/F image raises unsupported mode: <mode>.name → Image(L/I/F 模式)或 Number 的 Map。其他容器抛 Pillow.ImageMath variables must be a Map of name to Image or Number;未知名称抛 'name' not allowed;非 L/I/F 图像抛 unsupported mode: <模式>。

Returns: an Image, or an Integer/Float for scalar-only expressions.返回:Image;纯标量表达式返回 Integer/Float。

Parity: size mismatches raise images do not match; a float operand to a bitwise operator raises bad operand type for '<op>'.对齐:尺寸不符抛 images do not match;位运算遇到浮点操作数抛 bad operand type for '<op>'。

UnsafeEval static

Pillow.ImageMath.UnsafeEval(expression, variables := unset)

Direct alias of Eval (Pillow's unsafe_eval, which is itself the engine behind eval).

Eval 的直接别名(Pillow 的 unsafe_eval,后者即 eval 背后的引擎)。

LambdaEval static

Pillow.ImageMath.LambdaEval(expression, options := unset, kwargs*)

Pillow's lambda_eval: calls expression with the ops dictionary (int/float/equal/notequal/min/max/convert plus the AHK adaptation add/sub/mul/div/mod/neg) merged with options and keyword values; Image values become Operands. An Operand result is evaluated through Eval; any other result is returned as-is.

Pillow 的 lambda_eval:用 ops 字典(int/float/equal/notequal/min/max/convert,加上 AHK 适配的 add/sub/mul/div/mod/neg)合并 options 与关键字值后调用 expression;Image 值变为 Operand。Operand 结果经 Eval 求值;其他结果原样返回。

expression
A callable (Func/closure); anything else raises Pillow.ImageMath.lambda_eval expects a callable expression. It is invoked with a single Map argument (the merged ops + kwargs).可调用对象(Func/闭包);否则抛 Pillow.ImageMath.lambda_eval expects a callable expression。以单个 Map(合并后的 ops + 关键字)作为参数调用。
options
Optional Map of extra names to inject; non-Maps raise Pillow.ImageMath.lambda_eval options must be a Map.可选的额外名称注入 Map;非 Map 抛 Pillow.ImageMath.lambda_eval options must be a Map。
kwargs
Flat name, value, … pairs (Pillow's **kw). Image values are wrapped as Operand(name, Map(name, value)).扁平的 name, value, … 对(Pillow 的 **kw)。Image 值被包装为 Operand(name, Map(name, value))。

Returns: the evaluated Image/Number, or the callable's raw return value.返回:求值后的 Image/Number,或可调用对象的原始返回值。

表达式语法 · Expression Syntax

The Eval compiler is a shunting-yard parser over a Python-like infix language. Plain parentheses are grouping — (x + 1) * 2 — and a function name directly before ( is a call.

Eval 编译器是对类 Python 中缀语言的调车场解析器。普通括号为分组——(x + 1) * 2——紧跟 ( 的函数名是调用。

Operand 类 · The Operand class

Operand class

op := Pillow.ImageMath.Operand(expr, variables := unset)
op.Expr        ; expression string
op.Variables   ; merged variable Map

Wraps an image operand expression for lambda_eval. The binary/unary operators are exposed as methods — AHK 2.1-alpha.30 does not dispatch operator meta-functions, so Pillow's _Operand operator surface (+ - * / % ** << >> & | ^ ~ and unary -/~) is the method list below, and lambda_eval also receives them as the add/sub/mul/div/mod/neg functions.

为 lambda_eval 包装图像操作数表达式。二元/一元运算符以方法形式暴露——AHK 2.1-alpha.30 不派发运算符元函数,故 Pillow _Operand 的运算符表面(+ - * / % ** << >> & | ^ ~ 与一元 -/~)即下列方法,lambda_eval 也以 add/sub/mul/div/mod/neg 函数收到它们。

MethodEN中文

示例 · Examples

Evaluate an expression over two images, and run a lambda_eval conversion:

对两幅图像求值表达式,并执行一次 lambda_eval 转换:

img1 := Pillow.Image.Open("a.jpg")
img2 := Pillow.Image.Open("b.jpg")
; Eval over two images — the variables Map is Pillow's kwargs.
sum := Pillow.ImageMath.Eval("a + b", Map("a", img1, "b", img2))
; lambda_eval: the callable gets the ops dictionary + keyword Operands.
; Pillow equivalent: lambda_eval(lambda: convert(a, "L"), a=img1)
gray := Pillow.ImageMath.LambdaEval(
    (args) => args["convert"](args["a"], "L"),
    , "a", img1)
img1.Close(), img2.Close()
