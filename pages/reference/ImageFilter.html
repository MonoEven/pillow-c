ImageFilter module

The ImageFilter module contains prebuilt convolution kernels and filter classes. Apply a filter with image.Filter(f) or f.Apply(image). Validation replicates Pillow's exact messages.

ImageFilter 模块提供预置卷积核与滤波器类。用 image.Filter(f) 或 f.Apply(image) 应用滤波器。校验信息与 Pillow 逐字一致。

预置滤波器 · Predefined Filters

All prebuilt filters are zero-argument factory functions returning a filter object.

所有预置滤波器都是无参工厂函数,返回滤波器对象。

BLUR / CONTOUR / DETAIL / EDGE_ENHANCE / EDGE_ENHANCE_MORE

Pillow.ImageFilter.BLUR()             ; 5×5 box blur
Pillow.ImageFilter.CONTOUR()          ; 3×3 edge contour
Pillow.ImageFilter.DETAIL()           ; 3×3 detail enhancement
Pillow.ImageFilter.EDGE_ENHANCE()     ; 3×3 edge enhancement
Pillow.ImageFilter.EDGE_ENHANCE_MORE()

Pillow's built-in convolution kernels, byte-for-byte identical coefficients.

Pillow 内置卷积核,系数逐字节一致。

EMBOSS / FIND_EDGES / SHARPEN / SMOOTH / SMOOTH_MORE

Pillow.ImageFilter.EMBOSS()
Pillow.ImageFilter.FIND_EDGES()
Pillow.ImageFilter.SHARPEN()
Pillow.ImageFilter.SMOOTH()
Pillow.ImageFilter.SMOOTH_MORE()

The remaining built-in kernels (emboss, edge find, sharpen, smooth).

其余内置核(浮雕、寻边、锐化、平滑)。

滤波器类 · Filter Classes

Filter / MultibandFilter abstract base

Pillow.ImageFilter.Filter()          ; abstract — raises
Pillow.ImageFilter.MultibandFilter() ; abstract — raises

Abstract bases. Instantiation raises Pillow's exact Can't instantiate abstract class Filter with abstract method filter (resp. MultibandFilter).

抽象基类。实例化抛 Pillow 原样的 Can't instantiate abstract class Filter with abstract method filter(MultibandFilter 同理)。

BuiltinFilter class

Pillow.ImageFilter.BuiltinFilter()

Concrete base for built-in kernels; its filter() raises Pillow's AttributeError for missing attributes.

内置核的具体基类;其 filter() 对缺失属性抛 Pillow 的 AttributeError。

Kernel

Pillow.ImageFilter.Kernel(size := unset, kernel := unset, scale := unset, offset := 0)

A user convolution kernel. size = [w, h], kernel = coefficient array, scale = divisor (sum by default).

自定义卷积核。size = [宽, 高],kernel = 系数数组,scale = 除数(默认取系数和)。

Parity: bad kernel size, not enough coefficients in kernel, and the string/float TypeErrors match Pillow; name/filterargs are exposed.对齐:bad kernel size、not enough coefficients in kernel 与字符串/浮点 TypeError 同 Pillow;name/filterargs 已暴露。

RankFilter / MinFilter / MedianFilter / MaxFilter / ModeFilter

Pillow.ImageFilter.RankFilter(size := unset, rank := unset, name := "Rank")
Pillow.ImageFilter.MinFilter(size := 3)
Pillow.ImageFilter.MedianFilter(size := 3)
Pillow.ImageFilter.MaxFilter(size := 3)
Pillow.ImageFilter.ModeFilter(size := 3)

Rank-order filters over a square window: Nth value, minimum, median, maximum, most frequent.

方形窗口上的排序滤波器:第 N 值、最小值、中值、最大值、众数。

Parity: bad rank value and bad filter size match Pillow exactly.对齐:bad rank value 与 bad filter size 同 Pillow。

BoxBlur / GaussianBlur / UnsharpMask

Pillow.ImageFilter.BoxBlur(radius := unset)
Pillow.ImageFilter.GaussianBlur(radius := 2)
Pillow.ImageFilter.UnsharpMask(radius := 2, percent := 150, threshold := 3)

Blur and sharpen filters. UnsharpMask = original + (original − GaussianBlur) × percent/100 for differences above threshold.

模糊与锐化滤波器。UnsharpMask = 原图 + (原图 − 高斯模糊) × percent/100,仅对超过 threshold 的差异生效。

Color3DLUT

Pillow.ImageFilter.Color3DLUT(size, table, channels := 3, targetMode := "")
lut.Apply(image)   ; alias: lut.Transform(image)

Applies a 3-D lookup table to an image.

对图像应用三维查找表。

内部辅助 · Internal helpers

ApplyKernelArgs, RadiusPair, SumCoefficients, CheckSize and FlattenTable are kernel-argument plumbing shared by the filter classes — public for the facade's own use, not part of the Pillow-style user API.ApplyKernelArgs、RadiusPair、SumCoefficients、CheckSize 与 FlattenTable 是滤波器类共用的核参数管道——对门面内部公开,不属于 Pillow 风格的用户 API。

示例 · Examples

img := Pillow.Image.Open("photo.jpg")
blurred := img.Filter(Pillow.ImageFilter.GaussianBlur(2))
sharp   := img.Filter(Pillow.ImageFilter.UnsharpMask(2, 150, 3))
k := Pillow.ImageFilter.Kernel([3, 3], [-1,-1,-1, -1,8,-1, -1,-1,-1], 1, 0)
edges := img.Filter(k)
img.Close()
